Mezod is de referentie-implementatie van de client voor de Mezo-chain, een Bitcoin-first blockchain die is ontworpen voor eigenaarschap door gebruikers, betrouwbaar bridgen met tBTC, BTC als gas, een dubbel stakingmodel en EVM-compatibiliteit.

## Overzicht

Mezo is een op de Cosmos SDK gebaseerde chain met EVM-compatibiliteit die draait op de consensusengine Comet BFT. De codebase van de Mezod-client is geforkt van de LGPL-versie van Evmos en sterk aangepast aan de specifieke eisen van Mezo.

### Belangrijkste functies

- **Bitcoin-first ontwerp**: native integratie van BTC en betaling van gas in BTC
- **EVM-compatibiliteit**: volledige ondersteuning van de Ethereum Virtual Machine
- **Bridgen met tBTC**: betrouwbare cross-chain overdrachten van Bitcoin
- **Dubbel stakingmodel**: mechanismen voor beloningen en validatie
- **Eigenaarschap door gebruikers**: gedecentraliseerde governance en controle

## Structuur van de repository

De [Mezod-repository](https://github.com/mezo-org/mezod.git) bevat:

- **[Go-modules](https://github.com/mezo-org/mezod/tree/main)**: implementatie van de kernclient van de blockchain

## Ontwikkelomgeving instellen

### Vereisten

- Go 1.21+ (zie [`go.mod`](https://github.com/mezo-org/mezod/blob/main/go.mod) voor de exacte versie)
- Git
- Make
- Docker (optioneel, voor ontwikkeling in containers)

### Installatie

<Steps>
1. Kloon de repository:
   ```bash
   git clone https://github.com/mezo-org/mezod.git
   cd mezod
   ```

2. Installeer de Go-dependencies:
   ```bash
   go mod download
   ```

3. Build de client:
   ```bash
   make build
   ```
</Steps>

### Ontwikkelomgeving

<Steps>
1. **Lokale ontwikkeling**:
   ```bash
   # Start local development node
   make dev

   # Run tests
   make test

   # Lint code
   make lint
   ```

2. **Ontwikkeling met Docker**:
   ```bash
   # Build Docker image
   docker build -t mezod .

   # Run containerized node
   docker run -p 26657:26657 -p 8545:8545 mezod
   ```
</Steps>

## Configuratie van de chain

### Netwerkparameters

Mezod ondersteunt meerdere netwerkconfiguraties:

- **Mainnet**: het Mezo-productienetwerk
- **Testnet**: openbaar testnetwerk
- **Local**: ontwikkelnetwerk

### Configuratiebestanden

Belangrijkste configuratiebestanden:
- `config.toml`: configuratie van de node
- `app.toml`: applicatiespecifieke instellingen
- `client.toml`: configuratie van de client

Voorbeeldconfiguratie:

```toml
# config.toml
[consensus]
timeout_commit = "1s"
timeout_propose = "3s"

[p2p]
laddr = "tcp://0.0.0.0:26656"
external_address = "YOUR_EXTERNAL_IP:26656"
persistent_peers = "peer1@ip1:26656,peer2@ip2:26656"

[api]
enable = true
address = "tcp://0.0.0.0:1317"
```

## EVM-integratie

### Compatibiliteit met Ethereum

Mezod biedt volledige EVM-compatibiliteit, zodat je:

- Ethereum-smart contracts kunt deployen
- Ethereum-tooling kunt gebruiken (Hardhat, Truffle, enzovoort)
- Met contracten kunt werken via Web3-libraries

### Verbinden via Web3

```javascript
import { ethers } from 'ethers';

// Connect to Mezo network
const provider = new ethers.JsonRpcProvider('https://rpc.mezo.org');

// Get network info
const network = await provider.getNetwork();
console.log('Network:', network);

// Deploy contract
const factory = new ethers.ContractFactory(abi, bytecode, signer);
const contract = await factory.deploy();
await contract.waitForDeployment();
```

### Gas en kosten

- **BTC als gas**: betaal transactiekosten in Bitcoin
- **Dynamische prijzen**: gasprijzen passen zich aan de netwerkomstandigheden aan
- **EVM-gasmodel**: compatibel met de gasberekeningen van Ethereum

### Full node

Een volledige node die de hele blockchain opslaat:

```bash

```

### Light client

Een lichtgewicht client voor mobiele omgevingen en omgevingen met beperkte middelen:

```bash
# Start light client
mezod start --mode light
```

### Archiefnode

Een node die alle historische gegevens opslaat:

```bash
# Start archive node
mezod start --mode archive
```

## RPC-endpoints

### Cosmos SDK-RPC

- **Poort**: 26657
- **Endpoints**: standaard RPC-methoden van de Cosmos SDK
- **WebSocket**: realtime updates

```bash
# Query node status
curl http://localhost:26657/status
```

### EVM-RPC

- **Poort**: 8545
- **Endpoints**: Ethereum-compatibele JSON-RPC
- **Methoden**: eth_getBalance, eth_sendTransaction, enzovoort

```bash
# Query EVM balance
curl -X POST -H "Content-Type: application/json" \
  --data '{"jsonrpc":"2.0","method":"eth_getBalance","params":["0x...", "latest"],"id":1}' \
  http://localhost:8545
```
