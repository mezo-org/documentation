## Veelgestelde vragen

**Kan ik mijn BTC eerder ontgrendelen?**

Nee. Vergrendelingen staan vast tot de vervaldatum. Kies je duur dus zorgvuldig.

**Wat gebeurt er als ik niet stem?**

Je verdient dan geen vergoedingen of emissies uit gauges. Je ontvangt wel nog steeds de bridgevergoedingen die onder alle veBTC-houders worden verdeeld.

**Kan ik meerdere veBTC-posities hebben?**

Ja. Elke vergrendeling maakt een aparte veBTC-NFT aan. Als je wilt, kun je ze later samenvoegen.

**Kan ik mijn vergrendelde BTC als onderpand gebruiken?**

Nee. Je veBTC-NFT kan niet als onderpand worden gebruikt in het MUSD-leensysteem van Mezo zonder de onderliggende BTC te ontgrendelen.
