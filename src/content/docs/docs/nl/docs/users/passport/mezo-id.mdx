Een Mezo ID is een leesbare identificatie die is gekoppeld aan een wallet op het Mezo-netwerk. In plaats van een volledig `0x…`-walletadres te delen, kunnen gebruikers hun Mezo ID delen om activa te ontvangen.

## Hoe het werkt

Wanneer iemand je Mezo ID invoert in het [verzendformulier](/docs/nl/docs/users/passport/send-assets), zet Mezo dit automatisch om naar je walletadres. Het gevonden adres wordt ter bevestiging weergegeven, zodat de verzender de bestemming kan controleren voordat de transactie wordt voltooid.

Hetzelfde proces geldt wanneer een Bitcoin-adres wordt ingevoerd: Mezo koppelt het aan de bijbehorende wallet op het netwerk.

## Je Mezo ID gebruiken

- **Activa ontvangen**: deel je Mezo ID met andere Mezo-gebruikers in plaats van je volledige walletadres.
- **Activa versturen**: voer de Mezo ID van een ontvanger in het verzendformulier van Passport in. Controleer het gevonden walletadres voordat je bevestigt.
