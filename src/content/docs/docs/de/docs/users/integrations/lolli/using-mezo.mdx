# Auf Mezo verdienen, ausgeben und sparen

## Option 1: Einfach HODLn (die einfachste Wahl)

Ihre Sats bleiben in Ihrer Wallet und unter Ihrer vollständigen Kontrolle.

## Option 2: Kredit gegen Ihre Bitcoin aufnehmen

Erhalten Sie Zugang zu Dollar, ohne Ihre BTC zu verkaufen. Behalten Sie Ihr Bitcoin-Exposure und verschaffen Sie sich gleichzeitig Liquidität.

:::note[Wichtige Details]
- Feste Zinssätze ab 1 % APR
- Kein Rückzahlungstermin – schließen Sie Ihre Position, wann Sie möchten
- Keine Bonitätsprüfung, alles onchain
- Mindestkreditbetrag von $2.000 MUSD
- Sie müssen eine Besicherung von mindestens 110 % aufrechterhalten (um $1.000 MUSD zu leihen, benötigen Sie BTC im Wert von $1.100)
:::

### So nehmen Sie einen Kredit auf:

<Steps>
1. Rufen Sie mezo.org/borrow auf und verbinden Sie Ihre Wallet

2. Geben Sie den gewünschten Kreditbetrag in MUSD ein

3. Prüfen Sie Ihre Kreditbedingungen:
   * Zinssatz (derzeit 1 % fest)
   * Besicherungsquote
   * Liquidationspreis
   * Gebühren: 0,5 % Ausgabegebühr + 200 MUSD Gas-Kaution (wird beim Schließen zurückerstattet)

4. Klicken Sie auf „Borrow“ und bestätigen Sie die Transaktion

5. Die MUSD erscheinen in Ihrer Wallet – Ihre BTC sind als Sicherheiten gesperrt
</Steps>

**Was Sie mit MUSD tun können:**

* Sie über Bitrefill im Mezo Market ausgeben
* Sie gegen andere Vermögenswerte tauschen
* Sie in DeFi-Protokollen verwenden

### Ihren Kredit verwalten:

Überwachen Sie Ihre Besicherungsquote unter mezo.org/borrow. Fällt der BTC-Preis, sinkt Ihre Quote – halten Sie sie über 110 %, um eine Liquidation zu vermeiden. Um Ihren Kredit zu schließen, kehren Sie zu mezo.org/borrow zurück, klicken auf „Repay“, zahlen den vollständigen MUSD-Betrag zuzüglich der aufgelaufenen Zinsen zurück und bestätigen. Ihre BTC-Sicherheiten und die Gas-Kaution von 200 MUSD werden Ihnen zurückgegeben.

## Option 3: Ihre Sats ausgeben

Verwenden Sie Ihre Bitcoin, um Geschenkkarten bei Hunderten von Händlern zu kaufen, darunter Amazon, Airbnb, Uber, DoorDash und Visa-Prepaidkarten. Der Mindestkaufbetrag liegt bei $25 MUSD.

### Schritt 1: BTC in MUSD tauschen

<Steps>
1. Rufen Sie mezo.org/swap auf

2. Wählen Sie BTC → MUSD aus und geben Sie den Betrag ein

3. Behalten Sie BTC im Wert von etwa $2 für Gasgebühren

4. Prüfen Sie den Wechselkurs und klicken Sie auf „Swap“

5. Bestätigen Sie in Ihrer Wallet
</Steps>

### Schritt 2: Geschenkkarte kaufen

<Steps>
1. Rufen Sie mezo.org/market auf

2. Klicken Sie auf „Bitrefill Gift Cards“

3. Wählen Sie den Betrag (mindestens $25)

4. Klicken Sie auf „Purchase“ und bestätigen Sie mit MUSD

5. Sie erhalten Ihren Gutscheincode
</Steps>

### Schritt 3: Geschenkkarte einlösen

<Steps>
1. Kopieren Sie Ihren Gutscheincode

2. Rufen Sie Bitrefill.com auf und suchen Sie die gewünschte Geschenkkarte

3. Wählen Sie an der Kasse „Pay with voucher code“

4. Fügen Sie Ihren Code ein und schließen Sie den Kauf ab
</Steps>

## Option 4: Mit MUSD-Vaults verdienen

Zahlen Sie Ihre MUSD ein, um Rendite zu erzielen. So machen Sie Ihren Stablecoin am einfachsten produktiv und behalten dennoch Zugriff auf Ihre Mittel.

### So geht's:

<Steps>
1. Rufen Sie mezo.org/vaults auf und sehen Sie sich die verfügbaren MUSD-Vaults an

2. Prüfen Sie für jeden Vault:
   * Sperrfrist (falls vorhanden)
   * Belohnungsrate
   * Kapazität

3. Klicken Sie auf den gewünschten Vault

4. Klicken Sie auf „Deposit“ und geben Sie den MUSD-Betrag ein

5. Bestätigen Sie die Transaktion

6. Sie verdienen jetzt automatisch
</Steps>

:::note[Wichtig]
Prüfen Sie, ob der gewählte Vault eine Sperrfrist hat. Stellen Sie sicher, dass Sie die Mittel in diesem Zeitraum nicht benötigen.
:::
