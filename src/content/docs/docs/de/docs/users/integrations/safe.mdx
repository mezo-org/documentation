[Safe](https://safe.global/) (ehemals Gnosis Safe) ist die meistgenutzte Multisig-Wallet im Kryptobereich. Mezo verfügt über ein natives Safe-Deployment unter [safe.mezo.org](https://safe.mezo.org), das von [Den](https://www.onchainden.com/) verwaltet wird.

Bei einer Multisig-Wallet (Mehrfachsignatur-Wallet) müssen mehrere Personen eine Transaktion genehmigen, bevor sie ausgeführt wird. Statt dass eine einzelne Person die Mittel mit einem einzigen privaten Schlüssel kontrolliert, legt eine Gruppe Regeln fest, etwa „3 von 5 Unterzeichnern müssen zustimmen“.

<LinkButton href="https://safe.mezo.org" target="_blank">Safe auf Mezo öffnen</LinkButton>

## Erste Schritte

<Steps>

1. Rufen Sie [safe.mezo.org](https://safe.mezo.org) auf.

2. Verbinden Sie Ihre Wallet.

3. Klicken Sie auf **Create new Safe Account**.

4. Fügen Sie die Wallet-Adressen Ihrer Mitunterzeichner hinzu.

5. Legen Sie den Bestätigungsschwellenwert fest – die Anzahl der Genehmigungen, die zum Ausführen einer Transaktion erforderlich sind (z. B. 2 von 3).

6. Prüfen und deployen Sie Ihren Safe.

</Steps>

Nach dem Deployment können Sie über Ihren Safe BTC und andere Token auf Mezo senden und empfangen, wobei jede Transaktion den von Ihnen konfigurierten Genehmigungsschwellenwert erfordert.

## Funktionen

- **Mehrfachsignatur-Sicherheit** – Legen Sie fest, dass mehrere Unterzeichner Transaktionen vor der Ausführung genehmigen müssen.
- **Module und Guards** – Passen Sie Ihren Safe mit steckbaren Modulen für Ausgabenlimits, Wiederherstellung, automatisierte Transaktionen und mehr an.
- **Zugang zum Ökosystem** – Interagieren Sie direkt aus Ihrem Safe mit dApps auf Mezo, über den integrierten App-Browser.
- **Beobachtungskonten** – Überwachen Sie jedes Safe-Konto, ohne eine Wallet zu verbinden.
