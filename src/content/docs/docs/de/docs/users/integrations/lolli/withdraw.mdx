## Mindestbeträge für Abhebungen
### Von Lolli zu Mezo:
Mindestabhebung: 0,0003 BTC (30.000 Sats)

### Von Mezo zu Bitcoin Layer 1:
Mindestabhebung: 0,01 BTC (1.000.000 Sats)

:::note[Wichtig]
Solange Sie nicht 1 Mio. Sats in Ihrer Mezo-Wallet angesammelt haben, können Sie nicht auf Bitcoin Layer 1 abheben. Ihre Mittel bleiben innerhalb des Mezo-Ökosystems zugänglich – zum Ausgeben, zum Erzielen von Rendite oder für Kredite.
:::


## Schritt 1: Abhebung starten

<Steps>
1. Melden Sie sich bei Ihrem Lolli-Konto an

2. Rufen Sie „Rewards“ auf

3. Klicken Sie auf „Withdraw to Mezo“

4. Wählen Sie „sats to BTC“ (die USD-Option folgt in Kürze)
</Steps>

## Schritt 2: Wallet erstellen oder verbinden

**Wenn Sie noch keine Wallet haben:**

<Steps>
1. Klicken Sie auf „Create new wallet“. Sie werden zu einem Wallet-Anbieter weitergeleitet (für Einsteiger empfehlen wir Taho)

2. Folgen Sie den Anweisungen zur Einrichtung
   :::danger[KRITISCH: Schützen Sie Ihre Wiederherstellungsphrase]
   Sie erhalten eine Wiederherstellungsphrase (12–24 Wörter).
   - Schreiben Sie diese Wörter in der richtigen Reihenfolge auf
   - Bewahren Sie das Papier an einem sicheren Ort auf (nicht auf Ihrem Computer)
   - Machen Sie niemals einen Screenshot davon und geben Sie sie an niemanden weiter
   :::

3. Schließen Sie die Einrichtung der Wallet ab
</Steps>

**Wenn Sie bereits eine Wallet haben:**

<Steps>
1. Klicken Sie auf „Connect existing wallet“

2. Wählen Sie Ihre Wallet aus der Liste aus

3. Genehmigen Sie die Verbindung
</Steps>

## Schritt 3: Mit Ihrem Mezo-Konto verbinden

<Steps>
1. Klicken Sie auf „Connect your Mezo account“ – Sie werden zu mezo.org weitergeleitet

2. Klicken Sie auf „Sign In“ und verbinden Sie sich mit Ihrer Wallet

3. Genehmigen Sie die Lolli-Verbindung, wenn Sie dazu aufgefordert werden
</Steps>

## Schritt 4: Abhebung bestätigen

<Steps>
1. Prüfen Sie die Details Ihrer Abhebung (Betrag, Zieladresse, Gebühren)

2. Klicken Sie auf „Withdraw to Mezo“

3. Bestätigen Sie die Transaktion in Ihrer Wallet

4. Warten Sie auf die Bestätigung (in der Regel 5–30 Minuten)
</Steps>

## Schritt 5: Eingang Ihrer Mittel überprüfen

Rufen Sie mezo.org/overview auf und verbinden Sie Ihre Wallet. Dort sollte Ihr BTC-Guthaben angezeigt werden. Herzlichen Glückwunsch! Sie verwahren Ihre Mittel jetzt selbst und können Mezo nutzen.
