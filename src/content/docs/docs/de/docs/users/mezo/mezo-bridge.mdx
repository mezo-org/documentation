Die MEZO Bridge ermöglicht Übertragungen zwischen Mezo und mehreren Netzwerken, darunter Ethereum, Base, BSC und Solana, über das Native-Token-Transfer-Protokoll (NTT) von Wormhole. Diese Bridge erhält die Fungibilität des Tokens und bietet zugleich sichere Cross-Chain-Funktionalität.

## So funktioniert es

Die MEZO Bridge nutzt das Native-Token-Transfer-Protokoll von Wormhole, um Cross-Chain-Übertragungen abzuwickeln:

- **Von Mezo zu anderen Chains**: MEZO-Token werden auf Mezo gesperrt, und die entsprechenden Token werden auf der Ziel-Chain (Ethereum, Base, BSC oder Solana) gemintet
- **Von anderen Chains zu Mezo**: MEZO-Token werden auf der Quell-Chain verbrannt, und die entsprechenden Token werden auf Mezo entsperrt

Dieser Mechanismus stellt sicher, dass das Gesamtangebot über alle Chains hinweg konstant bleibt, während Nutzer ihre Token frei zwischen Netzwerken bewegen können.

## Bridge-Optionen

Für das Bridging von MEZO-Token stehen zwei Benutzeroberflächen zur Verfügung:

### Mezo dApp

Die [Mezo dApp](https://mezo.org) bietet ein natives Bridging-Erlebnis für die Übertragung von MEZO-Token ausschließlich zwischen Mezo und Ethereum.

**Bridging von Mezo zu Ethereum (Abhebung):**

<Steps>
1. **Verbinden Sie Ihre Wallet** mit der Mezo dApp

2. **Klicken Sie auf „Withdraw“**, um Token aus Mezo zu bridgen

3. **Wählen Sie den MEZO-Token aus** und geben Sie den Betrag ein, den Sie abheben möchten

4. **Bestätigen Sie die Transaktion** in Ihrer Wallet

5. **Warten Sie auf die Bestätigung** auf beiden Chains
</Steps>

**Bridging von Ethereum zu Mezo (Einzahlung):**

<Steps>
1. **Verbinden Sie Ihre Wallet** mit der Mezo dApp

2. **Klicken Sie auf „Deposit“**, um Token zu Mezo zu bridgen

3. **Wählen Sie den MEZO-Token aus** und geben Sie den Betrag ein, den Sie einzahlen möchten

4. **Bestätigen Sie die Transaktion** in Ihrer Wallet

5. **Warten Sie auf die Bestätigung** auf beiden Chains
</Steps>

### Wormhole Portal Bridge UI

Um MEZO-Token zu Base, BSC, Solana oder Ethereum zu bridgen, verwenden Sie die [Portal-Oberfläche](https://portalbridge.com/):

<Steps>
1. **Verbinden Sie Ihre Wallet** mit der Portal-Oberfläche

2. **Wählen Sie Quell- und Ziel-Chain aus** (Mezo ↔ Ethereum, Base, BSC oder Solana)

3. **Wählen Sie MEZO** als zu bridgenden Token

4. **Geben Sie den Betrag ein**, den Sie bridgen möchten

5. **Prüfen Sie die Transaktionsdetails**, einschließlich Gebühren und geschätzter Dauer

6. **Bestätigen Sie die Transaktion** in Ihrer Wallet

7. **Warten Sie auf die Bestätigung** auf beiden Chains
</Steps>

Beide Oberflächen bieten eine benutzerfreundliche Bedienung und übernehmen alle komplexen Interaktionen mit den zugrunde liegenden NTT-Contracts.
