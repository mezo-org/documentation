Eine Mezo ID ist eine menschenlesbare Kennung, die mit einer Wallet im Mezo-Netzwerk verknüpft ist. Statt eine vollständige `0x…`-Wallet-Adresse weiterzugeben, können Nutzer ihre Mezo ID teilen, um Vermögenswerte zu empfangen.

## So funktioniert es

Wenn jemand Ihre Mezo ID in das [Sendeformular](/docs/de/docs/users/passport/send-assets) eingibt, löst Mezo sie automatisch in Ihre Wallet-Adresse auf. Die aufgelöste Adresse wird als Bestätigungsschritt angezeigt, damit der Absender das Ziel überprüfen kann, bevor er die Transaktion abschließt.

Derselbe Auflösungsablauf gilt, wenn eine Bitcoin-Adresse eingegeben wird – Mezo ordnet sie der zugehörigen Wallet im Netzwerk zu.

## Ihre Mezo ID verwenden

- **Vermögenswerte empfangen** – Teilen Sie anderen Mezo-Nutzern Ihre Mezo ID statt Ihrer vollständigen Wallet-Adresse mit.
- **Vermögenswerte senden** – Geben Sie im Sendeformular von Passport die Mezo ID des Empfängers ein. Überprüfen Sie die aufgelöste Wallet-Adresse, bevor Sie bestätigen.
