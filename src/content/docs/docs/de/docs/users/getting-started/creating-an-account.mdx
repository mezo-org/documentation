Sie können in der Mezo App ein Konto erstellen, um Belohnungen zu verwalten, Vermögenswerte zu bridgen, MUSD zu leihen und zu minten sowie auf den Mezo Market zuzugreifen.

<YouTube id="b7SnEPSZjFE" title="So erstellen Sie Ihr Konto auf Mezo" />

<Steps>
1. Rufen Sie die [Mezo App](https://mezo.org/overview) auf.

2. Klicken Sie auf die Schaltfläche **Sign in**.

3. Klicken Sie auf **Sign up** und melden Sie sich mit Ihrer Browser-Wallet an. Wenn Sie eine Ethereum-Wallet verwenden möchten, klicken Sie unten im Anmeldefenster auf **Sign in with Ethereum instead**.

4. Verbinden Sie Ihre Wallet und bestätigen Sie die Transaktion, um die Registrierung abzuschließen.
</Steps>

Nachdem Sie sich angemeldet und die Transaktion signiert haben, ist Ihre Wallet mit dem Konto verbunden. Sie können BTC von anderen Adressen bridgen, das Konto wird jedoch über Ihre verbundene Wallet verwaltet.
