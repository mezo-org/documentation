## FAQ

**Kann ich meine BTC vorzeitig entsperren?**

Nein. Sperrungen sind bis zum Ablauf unwiderruflich. Wählen Sie Ihre Sperrdauer daher sorgfältig.

**Was passiert, wenn ich nicht abstimme?**

Sie verdienen dann keine Gebühren oder Emissionen aus Gauges. Sie erhalten jedoch weiterhin die Bridging-Gebühren, die an alle veBTC-Inhaber verteilt werden.

**Kann ich mehrere veBTC-Positionen haben?**

Ja. Jede Sperrung erzeugt ein eigenes veBTC-NFT. Sie können diese später bei Bedarf zusammenführen.

**Kann ich meine gesperrten BTC als Sicherheit verwenden?**

Nein. Ihr veBTC-NFT kann im MUSD-Kreditsystem von Mezo nicht als Sicherheit verwendet werden, ohne die zugrunde liegenden BTC zu entsperren.
