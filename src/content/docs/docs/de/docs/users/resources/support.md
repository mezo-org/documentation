## Schritt 1

Markieren Sie im allgemeinen Chat einen Moderator, digijoe oder lowpolyduck und bitten Sie um die Rolle „open-ticket“, um den Kanal für Support-Tickets freizuschalten.

## Schritt 2

Durchlaufen Sie den Ablauf, um Ihr Ticket an die zuständige Abteilung weiterzuleiten.

  ![](/docs/images/portal/support-intro.png)

Teilen Sie uns mit, ob Sie für Ihr Anliegen Unterstützung durch das Engineering, durch unser BD-/Partnerships-Team oder durch eine andere Stelle benötigen.

### Engineering-Support

Teilen Sie uns mit, ob Sie als Nutzer oder als Partner/Validator Engineering-Support benötigen.

### Engineering-Support (Weg für Nutzer)

Wenn Sie als Nutzer Engineering-Support benötigen, teilen Sie uns mit, ob Ihr Anliegen einen Fehler betrifft, den Sie melden möchten, ein Problem beim Bridgen von Guthaben zu Mezo, ein Problem mit MUSD-Krediten oder etwas anderes.

  ![](/docs/images/portal/user-engineering-support.png)

Wenn bei Ihnen eines der oben genannten Probleme auftritt, müssen Sie abschließend Folgendes angeben:

* Ihre Wallet-Adresse
* den Transaktions-Hash bzw. einen Link zum Block-Explorer (falls zutreffend)
* alle weiteren Informationen, die zusätzlichen Kontext liefern

### Engineering-Support (Weg für Partner/Validatoren)

Zunächst werden Sie gefragt, ob Sie als Partner, Validator oder Entwickler Engineering-Support benötigen.

Als Ökosystempartner teilen Sie uns mit, ob Sie bereits auf Mezo deployt sind oder sich gerade im Deployment befinden.

  ![](/docs/images/portal/ecosystem-partner-deployment-status.png)

Unabhängig davon, ob Sie bereits deployt sind oder sich noch im Deployment befinden, werden Sie anschließend gebeten, weitere Details zu Ihrem Anliegen anzugeben. Das zuständige Team meldet sich so schnell wie möglich bei Ihnen.

Validatoren und Entwickler werden direkt gebeten, weitere Details zu ihrem Anliegen anzugeben. Das zuständige Team meldet sich so schnell wie möglich bei Ihnen.

### BD-/Partnership-Anfragen

Teilen Sie uns mit, ob Sie eine dApp bzw. ein Protokoll sind, die oder das mit Mezo zusammenarbeiten möchte, ein Validator, der einen Node auf Mezo deployen möchte, ein KOL, der eine Partnerschaft sucht, oder etwas anderes.

### dApps/Protokolle

Als dApp bzw. Protokoll werden Sie gebeten, folgende Informationen anzugeben:

* Name Ihres Protokolls bzw. Ihrer App
* Offizielle Website
* Aktuelle Deployments auf Chains (falls vorhanden)
* X-Account
* Alle weiteren Informationen, die für Ihre Anfrage relevant sind

Nachdem Sie diese Informationen angegeben haben, prüft das zuständige Teammitglied die Angaben und meldet sich so schnell wie möglich bei Ihnen.

  ![](/docs/images/portal/eco-partner-team-info.png)

### Validatoren

Als Validator werden Sie gebeten, folgende Informationen anzugeben:

* Den Namen Ihres Dienstes (falls zutreffend)
* Eine Liste der Netzwerke, auf denen Sie einen aktiven Node betreiben
* X-Account
* Alle weiteren Informationen, die für Ihre Anfrage relevant sind

Nachdem Sie diese Informationen angegeben haben, prüft das zuständige Teammitglied die Angaben und meldet sich so schnell wie möglich bei Ihnen.

### KOLs

Als KOL werden Sie gebeten, folgende Informationen anzugeben:

* Links zu Ihren offiziellen Social-Media-Accounts
* Website (falls zutreffend)
* Wer Sie empfohlen hat (falls zutreffend)
* Alle weiteren Informationen, die für Ihre Anfrage relevant sind

Nachdem Sie diese Informationen angegeben haben, prüft das zuständige Teammitglied die Angaben und meldet sich so schnell wie möglich bei Ihnen.

Bei allen sonstigen Anliegen rund um BD/Partnerships werden Sie gebeten, weitere Details anzugeben. Das zuständige Teammitglied prüft die Angaben und meldet sich so schnell wie möglich bei Ihnen.

### Sonstiges

Wenn Ihr Anliegen keine Unterstützung durch das Engineering oder BD/Partnerships erfordert, werden Sie gebeten anzugeben, ob es sich um ein technisches oder ein nicht technisches Anliegen handelt.

  ![](/docs/images/portal/support-something-else.png)

Machen Sie anschließend bitte weitere Angaben. Das zuständige Team meldet sich so schnell wie möglich bei Ihnen.
