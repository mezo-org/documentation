## Was ist Mezo?

Mezo ist eine Bitcoin-Finanz-App, mit der Menschen von ihren Bitcoin leben können, ohne sie auszugeben. Zu den Kernfunktionen gehören Mezo Borrow und MUSD.

## Was kann ich mit Mezo machen?

Mezo entwickelt Produkte, die BTC einen Nutzen verleihen, ohne dass Sie Ihre BTC ausgeben müssen. Mit Mezo Borrow können Sie einen Kredit aufnehmen, um MUSD zu minten, die sich für vielfältige Zwecke ausgeben lassen. Die Vision ist es, letztlich die Bitcoin-Kreislaufwirtschaft zu schaffen und anzuführen, in der MUSD sowohl für größere Anschaffungen wie ein Eigenheim als auch für alltägliche Einkäufe wie Lebensmittel oder den täglichen Kaffee verwendet werden kann.

## Warum sollte ich Mezo nutzen?

Wenn Sie endlich von Ihren Bitcoin leben möchten, ohne sie auszugeben, ist Mezo der richtige Ort für Sie. Indem Sie Ihre Bitcoin als Sicherheit verwenden, können Sie mit Mezo Borrow eine Kreditlinie einrichten und von den niedrigsten Zinssätzen der Branche (1–5 %) zu einem festen Satz profitieren. So erhalten Sie Zugang zu BitcoinFi sowie zu Alltagsprodukten, die Sie im Mezo Market finden.

## Was sind die Kernfunktionen von Mezo?

Die Produkte von Mezo folgen der Mission, ein Bitcoin-gedecktes Finanzparadigma für die vielen statt für die wenigen aufzubauen. Mezo entwickelt Produkte, um diese Zukunft gemeinsam mit der Community zu gestalten. Vor diesem Hintergrund unterstützen die folgenden Produkte diesen Ansatz:

* Mezo Borrow
* MUSD
* Mezo Earn (demnächst verfügbar)

## Wie nehme ich einen Kredit gegen meine Bitcoin auf?

MUSD ist der Bitcoin-gedeckte Stablecoin von Mezo; 1 MUSD kann gegen BTC im Wert von 1 $ eingelöst werden. Um MUSD zu leihen, sperren Sie BTC als Sicherheit.

* Solange die Gesamtbesicherungsquote des Protokolls solide bleibt (über 150 % Deckung):
  * Neue Kredite benötigen eine Besicherung von mindestens 110 % (z. B. BTC im Wert von 110 $ pro 100 MUSD Schulden).
  * Fällt Ihre Besicherung unter 110 %, kann Ihre Position liquidiert werden.
* Fällt die Gesamtdeckung unter 150 %:
  * Neue Kredite müssen mit 150 % besichert werden.

## Wie kann ich Mezo für meine dApp bzw. mein Projekt nutzen?

Mit Passport können Entwickler ganz einfach Unterstützung für Bitcoin-Wallets in dApps integrieren, die auf Mezo aufbauen. Passport basiert auf RainbowKit und unterstützt beliebte Bitcoin-Wallets wie Unisat, Xverse und OKX sowie EVM-kompatible Wallets wie Taho und MetaMask. Das Paket enthält Hilfs-Hooks zum Auslesen von Guthaben, zur Verwaltung von Wallet-Verbindungen und zum Senden von Bitcoin- und Mezo-Transaktionen. Wenn Sie RainbowKit oder wagmi bereits verwendet haben, wird Ihnen die Einrichtung vertraut vorkommen. Folgen Sie den Schritten in der README von Mezo Passport, um loszulegen.

## Welche Wallets kann ich mit Mezo verwenden?

Sie können die folgenden Bitcoin- und EVM-kompatiblen Wallets auf Mezo verwenden:

Bitcoin-kompatibel:

* Unisat
* OKX (Ledger wird nicht unterstützt)
* Xverse

EVM-kompatibel:

* Taho
* MetaMask
* Zerion
* OKX

## Mit welchem Token werden Transaktionsgebühren bezahlt?

Transaktionsgebühren auf Mezo werden in BTC bezahlt. Sie erhalten BTC auf Mezo, indem Sie BTC direkt aus Ihrer Bitcoin-Wallet oder tBTC aus Ihrer Ethereum-Wallet einzahlen.

## Warum werden einige meiner Token im Mezo Explorer nicht angezeigt?

Dies ist eine bekannte Einschränkung des BlockScout-Indexers bei Token, die einen Proxy-Contract haben. Diese Token sind im [Mezo Explorer](https://explorer.mezo.org/) bei Ihrem EOA erst sichtbar, nachdem Sie Ihre erste Übertragung und Freigabe für den jeweiligen Token durchgeführt haben.
