Verfolgen Sie die Aktivität im Mezo-Netzwerk, MUSD-Kennzahlen und Token-Daten über diese offiziellen und Community-Ressourcen.

## Offizielle Dashboards

- [MUSD auf Mezo (Dune)](https://dune.com/scoffie/musd-on-mezo) – MUSD-Angebot, Minting-Aktivität und Nutzungskennzahlen
- [Chain-Übersicht (Dune)](https://dune.com/scoffie/chainoverviewmezo) – Statistiken und Aktivität auf Netzwerkebene
- [DexScreener](https://dexscreener.com/search?q=0xdD468A1DDc392dcdbEf6db6e34E89AA338F9F186) – Token-Paare und Handelsdaten

## Aggregatoren

- [DefiLlama](https://defillama.com/chain/mezo) – Total Value Locked (TVL), Marktkapitalisierung der Stablecoins und Volumen
- **CoinGecko:** Demnächst verfügbar
- **CoinMarketCap:** Demnächst verfügbar

## Von der Community betrieben

Dashboards, die von der Mezo-Community erstellt und/oder gepflegt werden. Melden Sie sich auf Discord, wenn Sie ein Dashboard haben, das auf dieser Seite ergänzt werden soll, oder erstellen Sie einen PR mit der Ergänzung.

- [MezoTools](https://mezotools.cc/) – Detaillierte MUSD-Analysen, Besicherung des Systems, Details einzelner Troves, MUSD-Preis, eine Seite zu Einlösungen und mehr.
