---
title: Wormhole MUSD Bridge
description: Wie die MUSD Bridge mit Wormhole Native Token Transfer sichere Cross-Chain-Transfers ermöglicht und dabei die Fungibilität wahrt.
topic: developers
---

Die MUSD Bridge basiert auf dem Native-Token-Transfer-Protokoll (NTT) von Wormhole, das sichere Cross-Chain-Transfers bei gleichzeitiger Wahrung der Token-Fungibilität ermöglicht. Weitere Informationen zur MUSD Bridge finden Sie auf der Seite [MUSD Bridge](/docs/de/docs/users/borrow/musd-bridge).
