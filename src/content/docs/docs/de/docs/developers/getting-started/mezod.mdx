Mezod ist die Referenzimplementierung des Clients für die Mezo-Chain – eine Bitcoin-first-Blockchain, die auf Nutzereigentum, zuverlässiges Bridging mit tBTC, BTC als Gas, ein duales Staking-Modell und EVM-Kompatibilität ausgelegt ist.

## Übersicht

Mezo ist eine auf dem Cosmos SDK basierende Chain mit EVM-Kompatibilität, die auf der Konsens-Engine Comet BFT läuft. Die Codebasis des Mezod-Clients ist ein Fork der LGPL-Version von Evmos und wurde für die spezifischen Anforderungen von Mezo stark angepasst.

### Wichtige Funktionen

- **Bitcoin-first-Design**: native BTC-Integration und Gaszahlungen in BTC
- **EVM-Kompatibilität**: volle Unterstützung der Ethereum Virtual Machine
- **tBTC-Bridging**: zuverlässige chainübergreifende Bitcoin-Übertragungen
- **Duales Staking-Modell**: Belohnungs- und Validierungsmechanismen
- **Nutzereigentum**: dezentrale Governance und Kontrolle

## Einrichtung der Entwicklungsumgebung

### Voraussetzungen

- Go 1.21+ (die genaue Version finden Sie in [`go.mod`](https://github.com/mezo-org/mezod/blob/main/go.mod))
- Git
- Make
- Docker (optional, für containerisierte Entwicklung)

### Installation

<Steps>
1. Klonen Sie das Repository:
   ```bash
   git clone https://github.com/mezo-org/mezod.git
   cd mezod
   ```

2. Installieren Sie die Go-Abhängigkeiten:
   ```bash
   go mod download
   ```

3. Bauen Sie den Client:
   ```bash
   make build
   ```
</Steps>

### Entwicklungsumgebung

<Steps>
1. **Lokale Entwicklung**:
   ```bash
   # Start local development node
   make dev

   # Run tests
   make test

   # Lint code
   make lint
   ```

2. **Entwicklung mit Docker**:
   ```bash
   # Build Docker image
   docker build -t mezod .

   # Run containerized node
   docker run -p 26657:26657 -p 8545:8545 mezod
   ```
</Steps>

## Chain-Konfiguration

### Netzwerkparameter

Mezod unterstützt mehrere Netzwerkkonfigurationen:

- **Mainnet**: produktives Mezo-Netzwerk
- **Testnet**: öffentliches Testnetzwerk
- **Lokal**: Entwicklungsnetzwerk

### Konfigurationsdateien

Wichtige Konfigurationsdateien:
- `config.toml`: Node-Konfiguration
- `app.toml`: anwendungsspezifische Einstellungen
- `client.toml`: Client-Konfiguration

Beispielkonfiguration:

```toml
# config.toml
[consensus]
timeout_commit = "1s"
timeout_propose = "3s"

[p2p]
laddr = "tcp://0.0.0.0:26656"
external_address = "YOUR_EXTERNAL_IP:26656"
persistent_peers = "peer1@ip1:26656,peer2@ip2:26656"

[api]
enable = true
address = "tcp://0.0.0.0:1317"
```

## EVM-Integration

### Ethereum-Kompatibilität

Mezod bietet volle EVM-Kompatibilität. Damit können Sie:

- Ethereum-Smart-Contracts deployen
- Ethereum-Tools verwenden (Hardhat, Truffle usw.)
- mit Web3-Bibliotheken mit Contracts interagieren

### Verbindung über Web3

```javascript
import { ethers } from 'ethers';

// Connect to Mezo network
const provider = new ethers.JsonRpcProvider('https://rpc.mezo.org');

// Get network info
const network = await provider.getNetwork();
console.log('Network:', network);

// Deploy contract
const factory = new ethers.ContractFactory(abi, bytecode, signer);
const contract = await factory.deploy();
await contract.waitForDeployment();
```

### Gas und Gebühren

- **BTC als Gas**: Transaktionsgebühren in Bitcoin bezahlen
- **Dynamische Preisgestaltung**: Gaspreise passen sich an die Netzwerkbedingungen an
- **EVM-Gasmodell**: kompatibel mit den Gasberechnungen von Ethereum

## Node-Typen

### Full Node

Ein vollständiger Node, der die gesamte Blockchain speichert:

```bash
# Start full node
mezod start
```

### Light Client

Ein schlanker Client für mobile Geräte und Umgebungen mit begrenzten Ressourcen:

```bash
# Start light client
mezod start --mode light
```

### Archive Node

Ein Node, der alle historischen Daten speichert:

```bash
# Start archive node
mezod start --mode archive
```

## RPC-Endpoints

### Cosmos-SDK-RPC

- **Port**: 26657
- **Endpoints**: Standard-RPC-Methoden des Cosmos SDK
- **WebSocket**: Echtzeit-Updates

```bash
# Query node status
curl http://localhost:26657/status
```

### EVM-RPC

- **Port**: 8545
- **Endpoints**: Ethereum-kompatibles JSON-RPC
- **Methoden**: eth_getBalance, eth_sendTransaction usw.

```bash
# Query EVM balance
curl -X POST -H "Content-Type: application/json" \
  --data '{"jsonrpc":"2.0","method":"eth_getBalance","params":["0x...", "latest"],"id":1}' \
  http://localhost:8545
```

## Deployment

### Deployment in der Produktion

**Hardwareanforderungen**:
- Minimum: 8 GB RAM, 100 GB SSD
- Empfohlen: 16 GB RAM, 500 GB NVMe-SSD

**Schritte**:

<Steps>
1. Konfigurieren Sie Firewall und Netzwerkports

2. Richten Sie geeignete Zugriffskontrollen ein

3. Deployen Sie den Monitoring-Stack

4. Starten Sie den Node mit der Produktionskonfiguration
</Steps>

### Deployment mit Docker

```bash
# Production Docker deployment
docker run -d \
  --name mezod \
  -p 26657:26657 \
  -p 8545:8545 \
  -v /data:/root/.mezod \
  mezod:latest start
```

## Fehlerbehebung

### Häufige Probleme

1. **Verbindungsprobleme**: Prüfen Sie die RPC-Endpoints und die Netzwerkverbindung
2. **Synchronisierungsprobleme**: Überprüfen Sie die Synchronisierung der Blockchain
3. **Gasprobleme**: Beobachten Sie die Gaspreise und passen Sie sie entsprechend an

### Debug-Befehle

```bash
# Check node status
mezod status

# View logs
mezod logs

# Reset node (caution: deletes data)
mezod unsafe-reset-all
```
