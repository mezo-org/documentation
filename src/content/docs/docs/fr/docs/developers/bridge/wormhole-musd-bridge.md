---
title: Wormhole MUSD Bridge
topic: developers
---

Le pont MUSD repose sur le protocole Native Token Transfer (NTT) de Wormhole, qui permet des transferts inter-chaînes sécurisés tout en maintenant la fongibilité des jetons. Pour plus d'informations sur le pont MUSD, consultez la page [MUSD Bridge](/docs/fr/docs/users/borrow/musd-bridge).
