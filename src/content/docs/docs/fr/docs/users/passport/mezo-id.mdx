Un Mezo ID est un identifiant lisible par un humain, associé à un portefeuille sur le réseau Mezo. Au lieu de communiquer une adresse de portefeuille `0x…` complète, les utilisateurs peuvent partager leur Mezo ID pour recevoir des actifs.

## Fonctionnement

Lorsque quelqu'un saisit votre Mezo ID dans le [formulaire Send](/docs/fr/docs/users/passport/send-assets), Mezo le convertit automatiquement en votre adresse de portefeuille. L'adresse résolue s'affiche lors d'une étape de confirmation afin que l'expéditeur puisse vérifier la destination avant de finaliser la transaction.

Le même processus de résolution s'applique lorsqu'une adresse Bitcoin est saisie : Mezo l'associe au portefeuille correspondant sur le réseau.

## Utiliser votre Mezo ID

- **Recevoir des actifs** : partagez votre Mezo ID avec d'autres utilisateurs de Mezo au lieu de votre adresse de portefeuille complète.
- **Envoyer des actifs** : saisissez le Mezo ID d'un destinataire dans le formulaire Send de Passport. Vérifiez l'adresse de portefeuille résolue avant de confirmer.
