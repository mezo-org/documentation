## Étape 1

Mentionnez un modérateur, digijoe ou lowpolyduck dans le canal de discussion général pour demander le rôle « open-ticket », qui débloque le canal des tickets de support.

## Étape 2

Suivez le parcours pour orienter votre ticket vers le service approprié

  ![](/docs/images/portal/support-intro.png)

Indiquez-nous si votre problème nécessite l'aide de l'équipe d'ingénierie, celle de notre équipe BD/Partenariats, ou autre chose.

### Support d'ingénierie

Indiquez-nous si vous êtes un utilisateur ou un partenaire/validateur à la recherche d'un support d'ingénierie

### Support d'ingénierie (parcours utilisateur)

Si vous êtes un utilisateur à la recherche d'un support d'ingénierie, indiquez-nous si votre problème concerne un bug que vous souhaitez signaler, un transfert de fonds vers Mezo via le pont, un emprunt de MUSD ou autre chose.

  ![](/docs/images/portal/user-engineering-support.png)

Enfin, si vous rencontrez un problème lié à l'un des sujets mentionnés ci-dessus, vous devrez fournir :

* Votre adresse de portefeuille
* Le hash de la transaction ou le lien vers l'explorateur de blocs (le cas échéant)
* Toute information complémentaire permettant de mieux comprendre le contexte

### Support d'ingénierie (parcours partenaire/validateur)

Vous serez d'abord invité à nous indiquer si vous êtes un partenaire, un validateur ou un développeur à la recherche d'un support d'ingénierie.

Si vous êtes un partenaire de l'écosystème, indiquez-nous si vous êtes actuellement déployé sur Mezo ou en cours de déploiement.

  ![](/docs/images/portal/ecosystem-partner-deployment-status.png)

Enfin, que vous soyez déjà déployé ou en cours de déploiement, vous serez invité à fournir des détails supplémentaires sur le problème pour lequel vous sollicitez de l'aide, et l'équipe concernée reviendra vers vous dans les meilleurs délais.

Si vous êtes un validateur ou un développeur, vous serez immédiatement invité à fournir des détails supplémentaires sur le problème pour lequel vous sollicitez de l'aide, et l'équipe concernée reviendra vers vous dans les meilleurs délais.

### Demandes BD/Partenariats

Indiquez-nous si vous êtes une dApp ou un protocole souhaitant établir un partenariat avec Mezo, un validateur souhaitant déployer un nœud sur Mezo, un KOL à la recherche d'un partenariat, ou autre chose.

### dApps/Protocoles

Si vous êtes une dApp ou un protocole, vous serez invité à fournir les informations suivantes :

* Nom de votre protocole ou de votre application
* Site web officiel
* Chaînes sur lesquelles vous êtes actuellement déployé (le cas échéant)
* Compte X
* Toute information complémentaire utile à votre demande

Une fois ces informations fournies, le membre de l'équipe concerné les examinera et reviendra vers vous dans les meilleurs délais.

  ![](/docs/images/portal/eco-partner-team-info.png)

### Validateurs

Si vous êtes un validateur, vous serez invité à fournir les informations suivantes :

* Le nom de votre service (le cas échéant)
* La liste des réseaux sur lesquels vous avez un nœud actif déployé
* Compte X
* Toute information complémentaire utile à votre demande

Une fois ces informations fournies, le membre de l'équipe concerné les examinera et reviendra vers vous dans les meilleurs délais.

### KOL

Si vous êtes un KOL, vous serez invité à fournir les informations suivantes :

* Les liens vers vos comptes officiels sur les réseaux sociaux
* Site web (le cas échéant)
* La personne qui vous a recommandé (le cas échéant)
* Toute information complémentaire utile à votre demande

Une fois ces informations fournies, le membre de l'équipe concerné les examinera et reviendra vers vous dans les meilleurs délais.

Pour toute autre demande liée au BD/Partenariats, vous serez invité à fournir des détails supplémentaires, et le membre de l'équipe concerné les examinera et reviendra vers vous dans les meilleurs délais.

### Autre chose

Si votre problème ne nécessite pas l'aide de l'équipe d'ingénierie ni de l'équipe BD/Partenariats, vous serez invité à préciser s'il s'agit d'un problème technique ou non technique

  ![](/docs/images/portal/support-something-else.png)

Une fois cette précision apportée, veuillez fournir des détails supplémentaires : l'équipe concernée reviendra vers vous dans les meilleurs délais.
