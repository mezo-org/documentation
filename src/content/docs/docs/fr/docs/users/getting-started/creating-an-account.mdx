Vous pouvez créer un compte dans l'application Mezo pour gérer vos récompenses, transférer des actifs via un pont, emprunter et frapper des MUSD, et accéder à Mezo Market.

<YouTube id="b7SnEPSZjFE" title="Comment créer votre compte sur Mezo" />

<Steps>
1. Rendez-vous sur l'[application Mezo](https://mezo.org/overview).

2. Cliquez sur le bouton **Sign in**.

3. Cliquez sur **Sign up** et connectez-vous avec votre portefeuille de navigateur. Si vous souhaitez utiliser un portefeuille Ethereum, cliquez sur **Sign in with Ethereum instead** en bas de la fenêtre de connexion.

4. Connectez votre portefeuille et confirmez la transaction pour terminer l'inscription.
</Steps>

:::tip[Vous souhaitez effectuer un dépôt ?]
Inscrivez-vous avec un portefeuille Ethereum (EVM). Le Native BTC Bridge-in a pris fin : les portefeuilles Bitcoin ne peuvent donc plus effectuer de dépôt sur Mezo. Consultez [Déposer des actifs](/docs/fr/docs/users/getting-started/deposit-assets).
:::

Une fois que vous êtes connecté et que vous avez signé la transaction, votre portefeuille est associé au compte. C'est votre portefeuille connecté qui gère le compte.
