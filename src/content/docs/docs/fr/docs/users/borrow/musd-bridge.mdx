Le pont [MUSD](https://mezo.org/feature/musd) permet d'effectuer des transferts entre les réseaux Mezo, Ethereum et Base grâce au protocole Native Token Transfer (NTT) de Wormhole. Ce pont préserve la fongibilité du jeton tout en offrant des fonctionnalités inter-chaînes sécurisées.

## Fonctionnement

Le pont MUSD utilise le protocole Native Token Transfer de Wormhole pour faciliter les transferts inter-chaînes :

- **De Mezo vers Ethereum/Base** : les jetons MUSD sont verrouillés sur Mezo et l'équivalent en jetons est frappé sur la chaîne de destination
- **D'Ethereum/Base vers Mezo** : les jetons MUSD sont brûlés sur la chaîne source et l'équivalent en jetons est déverrouillé sur Mezo

Ce mécanisme garantit que l'offre totale reste constante sur l'ensemble des chaînes, tout en permettant aux utilisateurs de déplacer librement leurs jetons d'un réseau à l'autre.

## Options de pont

Deux interfaces utilisateur sont disponibles pour transférer des jetons MUSD via un pont :

### dApp Mezo

La [dApp Mezo](https://mezo.org) offre une expérience de pont native pour transférer des jetons MUSD entre les réseaux Mezo et Ethereum.

<Steps>
1. **Connectez votre portefeuille** à la dApp Mezo

2. **Cliquez sur « Withdraw »** pour transférer des jetons depuis Mezo, ou sur **« Deposit »** pour les transférer vers Mezo

3. **Sélectionnez le jeton MUSD** et saisissez le montant

4. **Confirmez la transaction** dans votre portefeuille

5. **Attendez la confirmation** sur les deux chaînes
</Steps>

### Interface Portal Bridge

Pour transférer des jetons MUSD vers Base ou Ethereum, vous pouvez également utiliser l'[interface Portal](https://portalbridge.com/) :

<Steps>
1. **Connectez votre portefeuille** à l'interface Portal

2. **Sélectionnez les chaînes source et de destination** (Mezo ↔ Ethereum ↔ Base)

3. **Choisissez MUSD** comme jeton à transférer

4. **Saisissez le montant** que vous souhaitez transférer

5. **Vérifiez les détails de la transaction**, notamment les frais et la durée estimée

6. **Confirmez la transaction** dans votre portefeuille

7. **Attendez la confirmation** sur les deux chaînes
</Steps>

Ces deux interfaces offrent une expérience conviviale et prennent en charge toutes les interactions complexes avec les contrats NTT sous-jacents.
