# Comment générer du rendement, dépenser et épargner sur Mezo

## Option 1 : simplement HODL (le choix le plus simple)

Vos sats restent dans votre portefeuille, sous votre contrôle total.

## Option 2 : emprunter avec vos bitcoins en garantie

Accédez à des dollars sans vendre vos BTC. Conservez votre exposition au Bitcoin tout en obtenant de la liquidité.

:::note[Points clés]
- Taux d'intérêt fixes à partir de 1 % par an (APR)
- Aucune échéance de remboursement : clôturez votre prêt quand vous le souhaitez
- Aucune vérification de solvabilité, tout se passe onchain
- Montant d'emprunt minimum de 2 000 $ en MUSD
- Vous devez maintenir une collatéralisation d'au moins 110 % (pour emprunter 1 000 $ en MUSD, vous avez besoin de 1 100 $ de BTC)
:::

### Comment emprunter :

<Steps>
1. Rendez-vous sur mezo.org/borrow et connectez votre portefeuille

2. Saisissez le montant du prêt souhaité en MUSD

3. Vérifiez les conditions de votre prêt :
   * Taux d'intérêt (actuellement 1 % fixe)
   * Ratio de collatéralisation
   * Prix de liquidation
   * Frais : frais d'émission de 0,5 % + dépôt de gaz de 200 MUSD (restitué à la clôture)

4. Cliquez sur « Borrow » et confirmez la transaction

5. Les MUSD apparaissent dans votre portefeuille : vos BTC sont verrouillés en garantie
</Steps>

**Ce que vous pouvez faire avec vos MUSD :**

* Les dépenser via Bitrefill dans Mezo Market
* Les échanger contre d'autres actifs
* Les utiliser dans des protocoles DeFi

### Gérer votre prêt :

Surveillez votre ratio de garantie sur mezo.org/borrow. Si le prix du BTC baisse, votre ratio diminue : maintenez-le au-dessus de 110 % pour éviter la liquidation. Pour clôturer votre prêt, retournez sur mezo.org/borrow, cliquez sur « Repay », remboursez la totalité du montant en MUSD ainsi que les intérêts accumulés, puis confirmez. Votre garantie en BTC et votre dépôt de gaz de 200 MUSD vous sont restitués.

## Option 3 : dépenser vos sats

Utilisez vos bitcoins pour acheter des cartes cadeaux auprès de centaines de commerçants, notamment Amazon, Airbnb, Uber, DoorDash, ainsi que des cartes prépayées Visa. L'achat minimum est de 25 $ en MUSD.

### Étape 1 : échanger des BTC contre des MUSD

<Steps>
1. Rendez-vous sur mezo.org/swap

2. Sélectionnez BTC → MUSD et saisissez le montant

3. Conservez environ 2 $ de BTC pour les frais de gaz

4. Vérifiez le taux de change et cliquez sur « Swap »

5. Confirmez dans votre portefeuille
</Steps>

### Étape 2 : acheter votre carte cadeau

<Steps>
1. Rendez-vous sur mezo.org/market

2. Cliquez sur « Bitrefill Gift Cards »

3. Choisissez le montant (minimum 25 $)

4. Cliquez sur « Purchase » et confirmez en MUSD

5. Recevez votre code de bon d'achat
</Steps>

### Étape 3 : utiliser votre carte cadeau

<Steps>
1. Copiez votre code de bon d'achat

2. Rendez-vous sur Bitrefill.com et trouvez la carte cadeau souhaitée

3. Au moment du paiement, sélectionnez « Pay with voucher code »

4. Collez votre code et finalisez l'achat
</Steps>

## Option 4 : générer du rendement avec les coffres MUSD

Déposez vos MUSD pour générer du rendement. C'est le moyen le plus simple de faire fructifier votre stablecoin tout en gardant vos fonds accessibles.

### Comment procéder :

<Steps>
1. Rendez-vous sur mezo.org/vaults et parcourez les coffres MUSD disponibles

2. Vérifiez pour chaque coffre :
   * La période de verrouillage (le cas échéant)
   * Le taux de récompense
   * La capacité

3. Cliquez sur le coffre de votre choix

4. Cliquez sur « Deposit » et saisissez le montant de MUSD

5. Confirmez la transaction

6. Vous générez désormais du rendement automatiquement
</Steps>

:::note[Important]
Vérifiez si le coffre choisi comporte une période de verrouillage. Assurez-vous de ne pas avoir besoin de ces fonds pendant cette période.
:::
