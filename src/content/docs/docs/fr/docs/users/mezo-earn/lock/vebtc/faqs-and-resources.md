## FAQ

**Puis-je déverrouiller mes BTC de manière anticipée ?**

Non. Les verrouillages sont définitifs jusqu'à leur expiration. Choisissez votre durée avec soin.

**Que se passe-t-il si je ne vote pas ?**

Vous ne gagnerez ni frais ni émissions provenant des gauges. Vous recevrez toutefois les frais de pont distribués à tous les détenteurs de veBTC.

**Puis-je détenir plusieurs positions veBTC ?**

Oui. Chaque verrouillage crée un NFT veBTC distinct. Vous pourrez les fusionner ultérieurement si vous le souhaitez.

**Puis-je utiliser mes BTC verrouillés comme garantie ?**

Non. Votre NFT veBTC ne peut pas servir de garantie dans le système d'emprunt de MUSD de Mezo sans déverrouiller les BTC sous-jacents.
