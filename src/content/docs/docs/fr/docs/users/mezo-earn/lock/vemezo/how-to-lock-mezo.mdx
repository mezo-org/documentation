Verrouiller des MEZO vous permet d'obtenir un NFT veMEZO, qui booste jusqu'à 5x le pouvoir de vote de vos veBTC. Consultez l'[aperçu de veMEZO](/docs/fr/docs/users/mezo-earn/lock/vemezo) pour savoir en détail ce que vous gagnez.

## Prérequis

Avant de verrouiller des MEZO, assurez-vous de disposer :

- de jetons MEZO dans votre portefeuille ;
- d'un portefeuille connecté ;
- de suffisamment de BTC pour payer les frais de gaz.

Consultez la section [Premiers pas](/docs/fr/docs/users/getting-started/deposit-assets) pour obtenir de l'aide.

:::note[Remarque]
veMEZO ne vote pas seul sur les **gauges de staking** : il y multiplie le pouvoir de vote de votre position veBTC. Sans veBTC, vous pouvez tout de même gagner des récompenses de rebase, voter sur des gauges de boost veBTC et voter sur les [MEZO Gauges](/docs/fr/docs/users/mezo-earn/vote/mezo-gauges).
:::

---

## Accéder à la page Lock

<Steps>
1. Ouvrez l'application Mezo

2. Cliquez sur **Lock** dans la barre latérale gauche (sous « Earn »)

3. Vos actifs éligibles s'affichent
</Steps>

---

## Lancer le verrouillage

Repérez la carte de l'actif MEZO qui affiche votre solde disponible, puis cliquez sur **Lock**. Une fenêtre de configuration du verrouillage s'ouvre, dans laquelle vous allez configurer votre position.

**Montant :** saisissez le montant de MEZO que vous souhaitez verrouiller. Vous pouvez verrouiller n'importe quel montant, dans la limite de votre solde disponible.

**Durée :** sélectionnez une durée de verrouillage comprise entre 1 semaine et 4 ans. Les verrouillages plus longs offrent un poids veMEZO plus élevé, ce qui se traduit par un potentiel de boost plus important. L'interface affiche votre poids veMEZO initial estimé.

:::note[Remarque]
Les durées de verrouillage sont alignées sur les limites des époques et arrondies à la semaine complète inférieure. Consultez la section [Époques](/docs/fr/docs/users/mezo-earn/lock/vebtc#époques) pour en savoir plus.
:::

---

## Confirmer la transaction

Vérifiez les détails de votre verrouillage :

- le montant de MEZO ;
- la durée de verrouillage ;
- le poids veMEZO initial ;
- la date d'expiration du verrouillage.

Cliquez sur **Confirm Lock**, approuvez la transaction dans votre portefeuille et attendez la confirmation sur la blockchain.

---

## Consulter votre position

Après la confirmation, consultez les détails de votre verrouillage sur la page Lock, notamment :

- le poids veMEZO actuel (qui décroît au fil du temps) ;
- la date d'expiration du verrouillage ;
- les options permettant de prolonger votre verrouillage.
