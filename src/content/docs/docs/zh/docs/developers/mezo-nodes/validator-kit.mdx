Mezo Validator Kit 为运行 Mezo 节点（包括验证者节点、RPC 节点和种子节点）提供了一套完整的解决方案。本指南涵盖 Mezo 基础设施的设置、配置和维护。

## 概览

[Validator Kit](https://github.com/mezo-org/validator-kit.git) 提供多种部署方式，简化了 Mezo 节点的部署：

- **Docker**：容器化部署
- **原生守护进程**：直接安装到系统
- **Kubernetes**：使用 Helm chart 进行编排
- **云端部署**：支持 AWS、GCP、Azure

### 节点类型

1. **验证者节点**：参与共识和出块
2. **RPC 节点**：为 dApp 提供 API 端点
3. **种子节点**：协助网络完成引导

## 仓库结构

[Validator Kit 仓库](https://github.com/mezo-org/validator-kit.git)包括：

- **[Docker 配置](https://github.com/mezo-org/validator-kit/tree/main/docker)**：容器设置与编排
- **[Kubernetes 清单](https://github.com/mezo-org/validator-kit/tree/main/kubernetes)**：Helm chart 和 K8s 资源

- **[脚本](https://github.com/mezo-org/validator-kit/tree/main/scripts)**：自动化与维护工具

- CPU：2 核

**种子节点**：
- CPU：1 核
- 内存：2GB

- 网络：10 Mbps

**验证者节点**：
- CPU：8 核

- 网络：1 Gbps

## 安装方式

### Docker 部署

<Steps>
1. **克隆仓库**：
   ```bash
   git clone https://github.com/mezo-org/validator-kit.git
   cd validator-kit
   ```

2. **配置环境**：
   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

3. **启动节点**：
   ```bash
   docker-compose up -d
   ```
</Steps>

### 原生安装

<Steps>
1. **安装依赖项**：
   ```bash
   # Ubuntu/Debian
   sudo apt update
   sudo apt install -y curl git make build-essential

   # Install Go
   curl -fsSL https://go.dev/dl/go1.21.0.linux-amd64.tar.gz | sudo tar -xzC /usr/local
   ```

2. **构建 Mezod**：
   ```bash
   git clone https://github.com/mezo-org/mezod.git
   cd mezod
   make build
   ```

3. **配置节点**：
   ```bash
   ./mezod init mynode --chain-id mezo-testnet
   ```
</Steps>

### Kubernetes 部署

<Steps>
1. **安装 Helm**：
   ```bash
   curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
   ```

2. **使用 Helm 部署**：
   ```bash
   helm install mezo-node ./helm/mezo-node \
     --set node.type=validator \
     --set node.name=my-validator
   ```
</Steps>

## 配置

### 节点配置

**config.toml**：
```toml
[consensus]
timeout_commit = "1s"
timeout_propose = "3s"

[p2p]
laddr = "tcp://0.0.0.0:26656"
external_address = "YOUR_EXTERNAL_IP:26656"
persistent_peers = "peer1@ip1:26656,peer2@ip2:26656"
```

**app.toml**：
```toml
[api]
enable = true
address = "tcp://0.0.0.0:1317"

[grpc]
enable = true
address = "0.0.0.0:9090"

[evm]
rpc_address = "0.0.0.0:8545"
ws_address = "0.0.0.0:8546"
```

### 环境变量

```bash
# Node configuration
NODE_TYPE=validator
CHAIN_ID=mezo-mainnet
MONIKER=my-validator

# Network configuration
P2P_PORT=26656
RPC_PORT=26657
API_PORT=1317
GRPC_PORT=9090
EVM_RPC_PORT=8545

# Security
PRIV_VALIDATOR_KEY_FILE=/config/priv_validator_key.json
NODE_KEY_FILE=/config/node_key.json
```

## 验证者设置

### 前提条件

1. **权威证明（PoA）**：申请验证者资格
2. **质押要求**：最低质押数量
3. **技术要求**：满足硬件规格

### 验证者配置

```bash
# Initialize validator
./mezod init validator --chain-id mezo-mainnet

# Create validator key
./mezod keys add validator --keyring-backend file

# Create validator transaction
./mezod tx staking create-validator \
  --amount=1000000umezo \
  --pubkey=$(./mezod tendermint show-validator) \
  --moniker="My Validator" \
  --chain-id=mezo-mainnet \
  --from=validator
```

## RPC 节点设置

### 用途

RPC 节点提供：
- **API 端点**：REST 和 gRPC API
- **EVM RPC**：兼容以太坊的 JSON-RPC
- **WebSocket**：实时数据流
- **负载均衡**：在多个节点之间分配流量

### 配置

```yaml
# docker-compose.yml
version: '3.8'
services:
  rpc-node:
    image: mezod:latest
    ports:
      - "26657:26657"  # Tendermint RPC
      - "1317:1317"    # Cosmos API
      - "9090:9090"    # gRPC
      - "8545:8545"    # EVM RPC
    environment:
      - NODE_TYPE=rpc
      - CHAIN_ID=mezo-mainnet
    volumes:
      - ./data:/root/.mezod
```

### Grafana 仪表板

- **区块高度**：当前区块链高度
- **验证者状态**：活跃/非活跃状态
- **网络连接**：对等节点连接
- **资源使用**：CPU、内存、磁盘
- **交易吞吐量**：TPS 指标

```yaml
  - name: mezod
    rules:
      - alert: NodeDown
        expr: up{job="mezod"} == 0
        for: 1m
        labels:
          severity: critical
        annotations:
          summary: "Mezod node is down"
```

## 安全最佳实践

### 网络安全

1. **防火墙配置**：
```bash
# Allow only necessary ports
ufw allow 26656/tcp  # P2P
ufw allow 26657/tcp  # RPC
ufw allow 1317/tcp   # API
ufw allow 8545/tcp   # EVM RPC
```

2. **访问控制**：
```bash
# Restrict RPC access
iptables -A INPUT -p tcp --dport 26657 -s TRUSTED_IP -j ACCEPT
iptables -A INPUT -p tcp --dport 26657 -j DROP
```

### 密钥管理

1. **安全存储**：使用硬件安全模块（HSM）
2. **备份策略**：定期备份密钥
3. **访问控制**：限制密钥的访问权限

**重要提示**：切勿将验证者密钥提交到版本控制系统！

## 维护

### 日常任务

1. **软件更新**：
```bash
# Update mezod
git pull origin main
make build
systemctl restart mezod
```

2. **数据库维护**：
```bash
# Prune old data (use with caution)
./mezod tendermint unsafe-reset-all
```

3. **日志轮转**：
```bash
# Configure logrotate
cat > /etc/logrotate.d/mezod << EOF
/var/log/mezod/*.log {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
}
EOF
```

### 备份策略

1. **配置备份**：
```bash
tar -czf config-backup.tar.gz ~/.mezod/config/
```

2. **密钥备份**（请安全存储）：
```bash
# Backup validator keys to secure location
cp ~/.mezod/config/priv_validator_key.json /secure/backup/
```
