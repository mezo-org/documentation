---
title: dApp 要求
topic: developers
---


尽管该网络无需许可，任何人都可以部署到 Mezo 主网，但 Mezo 上的 dApp 必须满足以下要求，才能在 Mezo Market 中展示并获得推广支持：
* **MUSD 集成：** dApp 必须集成 [MUSD](https://mezo.org/feature/musd)，即 Mezo 生态的原生抵押型稳定币。集成方式可以包括支持使用 MUSD 进行支付、将其作为主要流动性资产，或在 dApp 的其他核心功能中使用 MUSD。
* **审计报告：** dApp 必须已完成第三方安全审计。审计报告必须提交给 [Supernormal Foundation](https://www.supernormal.foundation/page)。
* **主网功能：** dApp 必须已在 Mezo 主网上完成全面部署并可正常运行。
