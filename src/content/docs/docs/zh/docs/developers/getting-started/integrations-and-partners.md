多家机构正与 Mezo 合作，将其 dApp 和服务引入该网络。

## Goldsky

Goldsky 是面向 web3 构建者的索引器，提供子图托管和实时数据复制管道。Goldsky [已在 Mezo 测试网上可用](https://docs.goldsky.com/chains/supported-networks)，对应的标识符（slug）为 `mezo-testnet`。

- **[Goldsky 文档](https://docs.goldsky.com/)**

## Stork

Stork 是一个预言机协议，可在数据提供方与链上及链下应用之间实现超低延迟连接。Stork 最常见的用例是以实时价格数据源的形式拉取并使用市场数据，服务于 DeFi。Stork [已在 Mezo 测试网上可用](https://docs.stork.network/resources/contract-addresses/evm#mezo)。

- **[Stork 文档](https://docs.stork.network/)**
- **[Mezo 测试网上已部署的合约](https://docs.stork.network/resources/contract-addresses/evm#mezo)**

## Supra 

Supra 是一个跨链预言机网络，旨在通过快速、安全、去中心化且可扩展的数据解决方案，为各区块链生态中的 dApp 提供支持。Supra 的[分布式预言机协议（DORA）](https://docs.supra.com/oracles/data-feeds#distributed-oracle-agreement-dora)已在 Mezo 测试网上可用。请参阅 Supra 的[可用网络](https://docs.supra.com/oracles/data-feeds/pull-oracle/networks)页面，查找正确的拉取合约和存储合约地址。

- **[Supra 文档](https://docs.supra.com/)**

## Pyth

[Pyth Network](https://pyth.network/) 是规模最大的第一方预言机网络之一，可在包括 Mezo 在内的多条链上提供实时数据。Pyth 引入了一种创新的低延迟[拉取式预言机设计](https://docs.pyth.network/documentation/pythnet-price-feeds/on-demand)，用户可以在需要时将价格更新拉取到链上。这使链上环境中的所有人都能高效获取数据点。Pyth 网络每 400ms 更新一次价格，使 Pyth 成为速度最快的链上预言机之一。

Pyth 合约：
- Mezo 主网（代理）：[0x2880aB155794e7179c9eE2e38200202908C17B43](https://explorer.mezo.org/address/0x2880aB155794e7179c9eE2e38200202908C17B43)
- Mezo 测试网（代理）：[0x2880aB155794e7179c9eE2e38200202908C17B43](https://explorer.test.mezo.org/address/0x2880aB155794e7179c9eE2e38200202908C17B43)

请参阅 [Pyth 文档](https://docs.pyth.network/home)，了解如何在您的 dApp 中使用 Pyth。

## Onchain Den

Den 为链上组织提供自托管的多签钱包，并已在 Mezo 上可用。Onchain Den 还与 Mezo 合作，在 [safe.mezo.org](http://safe.mezo.org/) 提供 SAFE 基础设施。

- **[Den 文档](https://docs.onchainden.com/overview/den)**
