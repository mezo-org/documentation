Mezo ID 是与 Mezo 网络上某个钱包关联的易读标识符。用户无需分享完整的 `0x…` 钱包地址，只需分享自己的 Mezo ID 即可接收资产。

## 运作原理

当有人在[发送表单](/docs/zh/docs/users/passport/send-assets)中输入您的 Mezo ID 时，Mezo 会自动将其解析为您的钱包地址。解析出的地址会作为确认步骤显示出来，以便发送方在完成交易前核实目标地址。

输入比特币地址时也适用同样的解析流程——Mezo 会将其映射到网络上关联的钱包。

## 使用您的 Mezo ID

- **接收资产**——与其他 Mezo 用户分享您的 Mezo ID，而无需提供完整的钱包地址。
- **发送资产**——在 Passport 的发送表单中输入接收方的 Mezo ID。确认之前，请核实解析出的钱包地址。
