## 什么是 MUSD？

长期以来，比特币持有者一直面临两难的选择：要么出售 BTC 来支付开销，要么信任中心化借贷机构托管您的比特币，要么无限期持有而错失维持生活所需的流动性。

MUSD 改变了这一切。它是一种无需许可的稳定币，由比特币储备 100% 支持，旨在与美元保持 1:1 锚定。您可以存入 BTC 作为抵押品来铸造 MUSD，在任何接受美元的地方使用它，并始终保留完整的比特币敞口。用完之后，归还借入的 MUSD 及利息，即可取回您的 BTC。

![MUSD 让您既能持有又能使用 BTC](/docs/images/musd/musd-keep-and-spend-btc.png)

### 为什么选择 MUSD？

1. **无需出售比特币**——您最多可借入持有 BTC 价值的 90%。保留您的聪（sats），释放比特币资产的价值，并随时按您的意愿偿还贷款。
2. **1–5% 的固定利率**——您的利率在开立贷款时锁定，且永远不会改变。没有浮动利率，没有意外。相比之下，传统银行的年化利率为 7–20%，其他 DeFi 平台则为 8–9%。
3. **完全链上、可验证**——每一笔贷款和每一美元的抵押品都 24/7 全天候在链上可见。没有不透明的储备，没有托管方——只有存放在智能合约金库中的比特币。[在 Mezo 区块浏览器上实时查看抵押品](https://explorer.mezo.org/address/0x3012C2fE1240e3754E5C200A0946bb0E07474876)。
4. **无需许可**——无需信用审查，无需申请，除 1,800 MUSD 的最低借款额外没有其他最低要求。只要您持有 BTC，就可以借款。

## MUSD 的运作方式

![MUSD 的生命周期](/docs/images/musd/musd-lifecycle.png)

MUSD 采用 CDP（抵押债务仓位）模型。每一枚流通中的 MUSD 都可以赎回为比特币，价值 \$1 的 BTC 抵押品可用于铸造 1 MUSD。

正是这种“铸造-赎回”模型让 MUSD 即使在市场剧烈波动时也能维持 \$1 锚定：

* **MUSD 交易价格低于 \$1 时**——套利者在市场上买入折价的 MUSD，并将其赎回为价值 \$1 的底层 BTC，同时支付 0.75% 的赎回费；在 MUSD 价格回升至 \$0.995 之前，这一操作都有利可图。
* **MUSD 交易价格高于 \$1 时**——套利者向协议提供 BTC 来铸造新的 MUSD，并在市场上出售获利。在 MUSD 价格回落至 \$1.005 之前，这一操作都有利可图。

![](/docs/images/musd/musd-redemption-and-peg-process.png)

为确保锚定在市场波动期间依然稳固，所有贷款仓位都必须将抵押率维持在 110% 以上。系统内置了清算机制和稳定池来保障这一点——因此即使在高 LTV 下，协议依然安全且具有韧性。

有关这些安全机制如何运作的详细信息，请参阅 [MUSD 清算与赎回](/docs/zh/docs/users/borrow/liquidation-mechanics)。

### MUSD 模型的优势

**供给侧流动性**

传统的双边借贷协议需要一个预先存在的美元资金池，并通过浮动利率来平衡供需；而 MUSD 则直接由比特币抵押品铸造。随着越来越多的用户存入 BTC，流动性会自然增长——系统自行生成供应，因此新借款人始终可以获得流动性。

**固定的低借款利率**

由于 MUSD 是铸造出来的，而不是从资金池中借出，因此不存在推高成本的利率竞争。其结果是：固定利率低至 1%，并在贷款存续期内保持锁定。这使得 MUSD 比利率浮动且可能出现不可预测飙升的传统借贷市场便宜得多。

**资本效率**

MUSD 支持低至 110% 的最低抵押率，这意味着借款人最多可以获得其比特币价值 90% 的资金。对于比特币持有者来说，这是在不出售的情况下释放流动性最具资本效率的方式。尽管如此，更高的抵押率能提供更大的安全缓冲——请始终考虑您仓位的风险状况。

## MUSD 与传统金融对比

对于比特币持有者来说，金融体系一直意味着妥协：高昂的费用、不透明的托管、浮动的利率以及中心化的中介机构。MUSD 将链上金融的优势——透明、低成本、自我托管——直接带给您的比特币。

## MUSD 与现有稳定币的比较

稳定币市场种类繁多，涵盖法币支持的稳定币（USDT 和 USDC）、合成稳定币（USDe）以及其他算法型 CDP（Liquity、Sky）。尽管这些稳定币在过去几年中增长显著，但市场上仍缺少专为比特币持有者打造的产品。

MUSD 旨在以纯比特币支持来应对这些风险。

**法币支持的稳定币**

USDT 和 USDC 等法币支持的稳定币占据了当前稳定币市场 90% 以上的份额。它们由美元支持，这不仅与加密货币的精神完全背道而驰，而且美元储备还必须由单一实体安全保管。

USDT 的发行方 Tether（供应量约 \$150B）从未发布过储备证明审计。该公司在 2024 年录得 \$13B 的利润。

发行 USDC 的美国公司 Circle 能够[自行决定将地址列入黑名单](https://www.circle.com/legal/usdc-risk-factors)，并且会[付费让交易所持有其资产](https://x.com/inkymaze/status/1907187020293980599?s=46)。随着美国经济向链上迁移，这将成为一个危险的中心化节点。

**合成稳定币**

合成稳定币（例如 USDe）通常依赖中心化交易所和托管方案来维持其价值。随着 [Bybit 近期遭遇有史以来最大规模的黑客攻击](https://apnews.com/article/bybit-exchange-crypto-hack-north-korea-7c8335c1397261554138090c2c38f457)，这种敞口的风险已暴露无遗。

此外，由基差交易收益合成支持的稳定币难以预测，也未经充分检验。资金费率是浮动的，而且这些系统尚未经受过各种外部市场压力的考验。

**USDS 等 CDP 型稳定币**

基于 CDP 的稳定币通常以一篮子代币作为仓位抵押品，其中包括法币支持的稳定币和各种山寨币。

虽然这种多元化可以分散风险，但也带来了重大挑战。抵押品通常由 ETH 相关代币或其他稳定币等波动性资产构成，在市场承压时可能出现不可预测的反应，而且其波动性往往明显高于 BTC。这可能会损害稳定币的锚定，并使赎回和清算流程变得更加复杂。
