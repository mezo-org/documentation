## 费用汇总

| 费用 | 金额 | 收取时机 |
| --- | --- | --- |
| **发行费** | 借入 MUSD 的 0.1% | 开立贷款或增加贷款时 |
| **利息** | 1–5% 年化利率（开仓时固定） | 按未偿债务累计 |
| **赎回费** | 0.75% | 用 MUSD 兑换 BTC 抵押品时 |
| **再融资费** | 债务的 0.02% | 将贷款再融资为新利率时 |
| **Gas 押金** | 200 MUSD（固定） | 开立贷款时（关闭时退还） |

## 费用分配

:::note
费用会分配到两个去向：**（1）** 偿还协议启动贷款，以及 **（2）** MUSD Savings Vault。初始分配比例为 50/50，可通过 MUSD Splitter 进行治理调整。在启动贷款全部还清之前，至少 50% 的费用必须用于偿还贷款。还清之后，所有费用都将流入 Savings Vault。
:::

## 利息费用（1–5% 年化利率）

[MUSD](https://mezo.org/feature/musd) 贷款的利息在贷款存续期内固定不变。增加信用额度时，新增部分将按当前利率计息。

在上线初期，利息费用用于充实 MUSD 财库稳定池，该稳定池用于覆盖清算和坏账。

## 赎回费（0.75%）

在[赎回](/docs/zh/docs/users/borrow/liquidation-mechanics#赎回-%EF%B8%8F)过程中，当赎回人用 MUSD 兑换抵押品时，会从其收到的 BTC 中扣除 0.75% 的费用。该费用由赎回人支付，而不是由贷款被赎回的借款人支付。

在上线初期，赎回费用于充实 MUSD 财库稳定池，该稳定池用于覆盖清算和坏账。

## 发行费（0.1%）

发行费在开立 MUSD 贷款或贷款持有人借入更多 MUSD 时支付。费用为借款金额的 0.1%，以 MUSD 支付。一笔 \$10,000 MUSD 的贷款需以 MUSD 支付 \$10 的发行费。如果您增加贷款，则需就新借入的 MUSD 支付发行费。

## 再融资费（债务的 0.02%）

当 MUSD 贷款持有人申请更新贷款利率时，会产生再融资费。如果新贷款的利率优于自己贷款的固定利率，借款人可能会希望为贷款再融资。再融资可以将贷款利率更新为新利率。每次再融资申请都会产生债务 0.02% 的再融资费，以 MUSD 支付。

## Gas 押金（`200 MUSD` 固定费用）

200 MUSD 的押金用于确保清算可行，并会在贷款关闭时退还。Gas 押金作为额外债务铸造到贷款中，并在贷款关闭前一直处于托管状态。这笔债务会计入抵押率的计算。

## 其他 Gas 费与交易费

与 MUSD 系统交互的用户，需要为广播到 Mezo 网络的每笔交易支付交易费。这包括铸造、赎回、质押和领取等操作。

## 需要了解的风险

:::caution
借入 MUSD 存在风险。了解这些风险有助于保护您的仓位。

**赎回风险**——为维持 MUSD 锚定，协议可以用 MUSD 赎回抵押品，从**抵押率最低**（但仍高于 110% 清算阈值）的贷款开始。如果您的贷款被赎回，您将失去 BTC 价格上涨带来的敞口收益，并可能面临税务影响。为降低这一风险，请让您的抵押率高于其他借款人。

**清算风险**——如果您贷款的抵押率**低于 110%**，您的仓位可能会被清算。您将失去抵押品，但保留已借入的 MUSD。为降低这一风险，请定期监控您的贷款，并在需要时追加抵押品。详情请参阅 [MUSD 清算与赎回](/docs/zh/docs/users/borrow/liquidation-mechanics)。
:::
