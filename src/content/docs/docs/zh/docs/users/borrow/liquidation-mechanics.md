## 概览
当您以比特币为抵押品借款时，会创建一个贷款仓位（也称为“Trove”）。有两类关键的系统事件可能影响您的贷款：

- **清算**：强制关闭您的贷款，仅在贷款健康度（以抵押率衡量）跌破 110% 这一临界最低值时才会发生。发生清算时，您会失去抵押品。
- **赎回**：任何持有 MUSD 的人都可以按每 MUSD \$1 的价格向协议兑换 BTC（需扣除赎回费，目前为 0.75%），借助套利使 MUSD 的价格保持在 \$1 附近。赎回会优先从抵押率最低的 Trove 中提取 BTC（只要其仍高于 110% 清算阈值），因此即使您的 Trove 没有清算风险，赎回也可能使您的贷款缩小。如果赎回金额小于该 Trove 的债务，则按部分赎回处理——即只抵消部分债务。如果赎回金额更大，该 Trove 会被全额赎回，剩余金额将顺延至抵押率次低的 Trove。无论哪种情况，债务和抵押品都会按相等的美元金额扣除，从而提高受影响 Trove 的抵押率——但借款人在此过程中会失去 BTC 敞口。

---

## 清算 ⚠️

### 什么是清算？
清算是一种安全机制，会在贷款风险过高时自动将其关闭，以防止整个系统变得不稳定。

### 清算何时发生？

:::danger
如果您贷款的抵押率跌破 110%，您的贷款就面临被清算的风险。您可以将其理解为贷款所需的绝对最低安全缓冲。
:::

### 清算期间会发生什么？
系统有两种处理清算的方式：

#### 使用稳定池（默认方式）：
- 系统使用其安全储备——稳定池（Stability Pool）——中的稳定币全额偿还您的债务。
- 触发清算的个人或机器人会获得一小笔奖励（200 MUSD 的 Gas 费以及您抵押品的 0.5%）。
- 您其余的抵押品（99.5%）将转入稳定池，用于偿付其存款人。
- 您的贷款被关闭，您将失去全部抵押品。

#### 重新分配（备用方式）：
- 如果稳定池为空，系统会将您的债务和抵押品分摊给所有其他活跃贷款持有人。
- 这是一种备用方式，用于确保系统始终保持平衡。

### 清算示例：
- 假设您的贷款有 10,000 MUSD 的债务。
- 您的 BTC 抵押品价值跌至 \$10,900。
- 您的抵押率现在为 109%，低于 110% 的最低要求。
- 结果：您的贷款被清算。您 10,000 MUSD 的债务被清除，但您将失去价值 \$10,900 的全部 BTC 抵押品。

## 赎回 🛡️

### 什么是赎回？
赎回是一项功能，允许任何持有稳定币的人直接从协议中将其兑换为等值美元的 BTC（需扣除赎回费）。这一过程有助于让稳定币维持在 \$1 锚定价格附近。赎回并不是惩罚，也不代表您的贷款不安全。

### 赎回何时发生？
赎回随时都可能发生。当用户想要将其稳定币赎回为 BTC 时，系统会寻找可提取抵押品的贷款。

### 哪些贷款会被选中进行赎回？
系统始终从抵押率最低、但仍高于 110% 清算阈值的贷款开始——即使该抵押率处于健康水平且远高于 110%。如果您的贷款抵押程度低于其他贷款，就更有可能被选中赎回。

### 赎回期间会发生什么？

#### 全额赎回：
- 如果一次赎回还清了您的全部债务，您的贷款将被关闭。
- 等值的 BTC 将转给赎回人。
- 剩余的 BTC 仍归您所有。这部分称为盈余抵押品，会被转入一个专门的托管账户，供您领取。

#### 部分赎回（更常见）：
- 赎回人偿还您的部分债务。
- 等值的 BTC 抵押品将转给赎回人。
- 结果：您的贷款仍保持开放，但规模更小、状况更健康，抵押率也更高。

### 赎回示例：
- 假设您的贷款有 10,000 MUSD 的债务和价值 \$13,000 的 BTC 抵押品（抵押率为健康的 130%）。
- 另一位用户赎回 5,000 MUSD，您的贷款被选中。
- 结果：
  - 您的债务减少至 5,000 MUSD。
  - 您的抵押品减少至 \$8,000。
  - 您的新抵押率为 160%（\$8,000 / 5,000 MUSD），您的贷款因此安全得多！

### 全额赎回后如何取回剩余抵押品
如果您的贷款通过赎回被全部还清，您的盈余抵押品是安全的。您可以随时通过 Mezo App 取回。

重要提示：当前的用户界面可能不会显示您可领取的盈余。如果您在 Borrow 页面上没有看到 “Loan redeemed” 提醒，请按照我们的[如何在全额赎回后领取抵押品](/docs/zh/docs/users/borrow/claim-collateral-after-redemption/)指南，通过 Mezo Explorer 手动领取。

## 主要区别一览

| 特性 | 清算（强制关闭） | 赎回（偿还债务） |
| --- | --- | --- |
| 发生时机 | 仅在您的抵押率低于 110% 时 | 可能在您的抵押率高于 110% 时发生 |
| 由谁发起？ | 任何人（通常是机器人） | 任何持有 MUSD 的用户 |
| 对债务的影响 | 全部清除 | 减少或清除 |
| 对抵押品的影响 | 全部损失 | 部分扣除，任何盈余均可由您领取 |
| 对您的影响 | 负面事件；贷款被关闭，资产损失 | 中性或正面；贷款规模变小、状况更健康 |

## 什么是恢复模式？

:::note
恢复模式是一种临时安全状态，会在整个系统的总抵押率（TCR）跌破 150% 时启动。它是一种特殊的系统状态，借款规则更为严格。
:::

在恢复模式期间：
- **清算不受影响。** 清算阈值仍为 110%——与正常模式相同。与 Liquity v1 不同，MUSD 不会在恢复模式期间将清算范围扩大到更高的抵押率。
- 不能以低于 150% 的抵押率开立新贷款。
- 再融资将被阻止。
- 系统会鼓励用户追加抵押品或偿还债务，以使 TCR 恢复到 150% 以上。

## 如何确保贷款安全

:::tip
同时防范清算和赎回的最佳方法是保持较高的抵押率——目标是远高于 150%。
:::

### 避免清算：
- 保持充足的缓冲。将抵押率维持在远高于 110% 的水平，以抵御市场波动。抵押率高于 150% 还能确保即使系统进入恢复模式，您也可以自由借款和再融资。
- 定期监控贷款的健康状况，尤其是在 BTC 价格下跌时。
- 主动应对：如果抵押率过低，请追加抵押品或偿还部分债务。

### 降低被赎回的可能性：
- 保持较高的抵押率。与在固定阈值触发的清算不同，赎回是相对的——系统会优先选择抵押率最低的 Trove。您的抵押率相对其他 Trove 越高，您的 Trove 被赎回的可能性就越小。虽然 150% 通常是一个不错的基准目标，但最合适的抵押率取决于当前的市场状况以及其他未关闭 Trove 的抵押率。建议定期关注现有的 Trove，并相应调整您的抵押率，使其始终远离排名末尾。

### 使用 MUSD Monitor 随时掌握贷款状况
如需高级监控，您可以使用 [mezotools.cc](https://mezotools.cc)。

该工具可以帮助您：
- 实时查看 Trove 健康状况和抵押率。
- 查看近期全系统范围内的赎回和清算情况。
- 直接通过 Mezo 链上预言机追踪 BTC 和稳定币价格。
