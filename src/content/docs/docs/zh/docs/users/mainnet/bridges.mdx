您可以使用 Mezo 原生跨链桥（Mezo Native Bridge）向 Mezo 存入资产，或从 Mezo 提取资产。
# 存款

## Mezo 原生跨链桥存款

Mezo App 内置原生跨链桥，您可以通过它将多种资产存入 Mezo 主网。请参阅[存入资产](/docs/zh/docs/users/getting-started/deposit-assets)指南了解具体流程，或直接前往 [mezo.org/overview](https://mezo.org/overview)，登录后点击 **Deposit Bitcoin** 开始操作。

:::note[注意]
Mezo 主网上的所有交易均使用存入的原生 BTC 或 tBTC 支付。在使用网络之前，建议您先向账户充入 BTC 或 tBTC，以确保有足够的 Gas 支付交易费用。
:::


## 原生 BTC 存款

您可以直接从比特币钱包将 BTC 存入 Mezo App。资产会被自动桥接为 tBTC，并桥接到 Mezo 主网。

原生 BTC 会先被桥接为 tBTC，然后再桥接到 [Mezo App 合约](/docs/zh/docs/users/resources/contracts-reference)中。

对于 BTC 钱包，您可以使用 UniSat、OKX 和 Xverse 登录。请使用以下类型的地址：

| 名称           | 脚本类型    | 地址前缀       |
| -------------- | ----------- | -------------- |
| Legacy         | P2PKH       | 1              |
| Native SegWit  | P2WPKH      | bc1q           |
| Nested SegWit  | P2SH-P2WPKH | 3              |

# 提取

## 将资产从 Mezo 转移到其他网络

*最后更新：2026 年 9 月*

本指南介绍如何将资产从 Mezo 桥出，转回以太坊或比特币网络。我们将介绍可以桥接哪些资产、如何操作、所使用的跨链桥、涉及的费用，以及整个过程中需要注意的事项。目前，最低桥接金额如下：提取到原生比特币为 0.01 BTC；将 BTC 提取到以太坊为 0.0002 BTC；通过原生跨链桥桥接的美元代币（USDC、USDT、USDe、DAI）为 20 个该代币；通过 Wormhole 跨链桥桥接的代币（MEZO、MUSD、sUSDat）为 0.01 个该代币；T 代币为 1,500 T。更多详情请参阅[此处。](#桥接到以太坊)

### 从 Mezo 到其他网络

| 您在 Mezo 上的资产 | 目标网络 | 您将收到 | 说明 |
|-------------------|-------------------|-------------------|--------|
| **BTC** | 以太坊 | tBTC（ERC-20 代币） | 您在以太坊上收到的始终是 tBTC，而不是 WBTC 或其他包装版本 |
| **BTC** | 比特币 | 原生 BTC | 真正的比特币，发送到您的比特币钱包 |
| **mERC-20 代币** | 以太坊 | 原始 ERC-20 代币 | 取回您最初桥入的相同代币（如 USDC、USDT 等） |
| **MUSD** | 以太坊、Base | MUSD | 可在 Mezo、Base 和以太坊之间桥接，最低仅需 0.01 MUSD。跨链桥由 Wormhole 提供支持。 |
| **MEZO** | 以太坊、Base、BSC、Solana | MEZO | 跨链桥由 Wormhole NTT 提供支持。详情请参阅 [MEZO 跨链桥指南](/docs/zh/docs/users/mezo/mezo-bridge)。 |
| **mERC-20 代币** | 比特币 | 不可用 | ERC-20 代币无法发送到比特币 |

:::note[要点]
- 您可以在 Mezo 与比特币主网、以太坊和 Base 网络之间桥接资产。
- BTC 可以转到以太坊（以 tBTC 形式）或比特币（以原生 BTC 形式）。
- USDC 或 T 等代币（在 Mezo 上以 m 代币形式表示）只能转回以太坊。
- MEZO 和 MUSD 可以通过 [Wormhole NTT](/docs/zh/docs/users/mezo/mezo-bridge) 在 Mezo 与 Base 网络之间双向桥接。
- MEZO 代币还可以通过 [Wormhole NTT](/docs/zh/docs/users/mezo/mezo-bridge) 桥接到 BSC 和 Solana。
- 暂不支持比特币 Taproot 地址（以 `bc1p` 开头）。
:::

## 如何桥出

### 桥接到以太坊（适用于 tBTC 或 ERC-20 代币）

<Steps>
1. 在 Mezo App 右上角**点击 “Withdraw” 按钮**。

2. **选择您的资产：**
   - 选择 BTC，以在以太坊上收到 tBTC。
   - 选择任意 mERC-20 代币，以在以太坊上收到原始代币。

3. **输入**您要桥接的**数量**。

4. **查看**屏幕上显示的**费用**。

5. **确认并提交**交易。

6. **如果桥接的是 mERC-20 代币**，您可能需要先授权该交易。
</Steps>

### 桥接到比特币（仅适用于原生 BTC）

<Steps>
1. 在 Mezo App 右上角**点击 “Withdraw” 按钮**。

2. **选择 BTC** 作为您的资产。

3. **选择比特币**作为目标网络。

4. **输入**要桥接的**数量**。

5. **粘贴您的比特币地址**——支持的格式：
   - Legacy 地址（以 `1` 开头）
   - SegWit 地址（以 `3` 或 `bc1q` 开头）
   - **不支持：** Taproot 地址（以 `bc1p` 开头）

6. **查看费用**并确认。

7. **提交**交易。
</Steps>

## 了解跨链桥路由

从 Mezo 提取资产时，系统会自动确定使用哪个跨链桥。该信息会显示在提取弹窗的 “Bridge” 一行中。

-   **Mezo 原生跨链桥：** 用于 BTC 和 mERC-20 代币等资产的所有标准提取。
-   **Wormhole 跨链桥：** 一个第三方跨链桥，用于将 MUSD 提取到以太坊，以及将 [MEZO 代币转移](/docs/zh/docs/users/mezo/mezo-bridge)到以太坊、Base、BSC 和 Solana。
-   **Super Bridge（即将推出）：** 一个 Mezo 原生跨链桥，将支持小额资产的存款和提取。

App 会根据您具体交易所使用的跨链桥路由，准确显示相应费用。

## 了解费用

桥出时，您需要为跨链桥服务和网络操作支付费用。在您确认任何交易之前，所有费用都会清晰地显示出来。

### 原生跨链桥的费用结构（v2）

从 Mezo 提取资产时只收取一项简单的费用：

- 固定费用——一笔固定金额，相当于价值约 $3 USD 的该代币。

#### 桥接到以太坊

最低提取金额

- 基于 BTC 的代币（BTC、mcbBTC、mFBTC、mSolvBTC、mswBTC、mxSolvBTC）：0.0002
- 通过原生跨链桥桥接的基于美元的代币（mUSDC、mUSDT、mDAI、mUSDe）：20
- mT 代币：1,500

费用

- Mezo Bridge 服务费：≈ $3 USD（以目标代币计算）
- 网络费用（Gas）：以 BTC 支付，随网络状况变化

示例：

提取 1,000 USDC → $3 服务费 + 可变 Gas 费 → 收到约 997 USDC。

#### 桥接到比特币

最低提取金额：0.01 BTC

费用

- 网络费用（Gas）：以 BTC 支付，金额不定
- Mezo Bridge 服务费：≈ 0.000027 BTC
- tBTC 跨链桥服务费：0.2%（在扣除 Mezo Bridge 服务费之后计算）
- tBTC 跨链桥最高网络费用：最高 0.001 BTC（但通常 < $1）

##### 示例：

提取金额：1 BTC

费用：
  - 0.000027 BTC（Mezo Bridge 服务费）
  - 0.001999946 BTC（tBTC 跨链桥服务费）
  - 可变的 tBTC 跨链桥网络费用和 Gas 费

到账金额：约 0.997973 BTC。

## 提交之后会发生什么

发起桥出交易后，流程如下：

<Steps>
1. **验证：** 系统核实您的请求是否满足所有要求。

2. **代币销毁：** 您在 Mezo 上的代币将被销毁（永久退出流通）。

3. **认证：** Mezo 验证者确认您的提取请求。

4. **交付：** 您的资产被发送到目标地址。
</Steps>

### 时间线与状态更新

您的跨链桥交易将显示以下状态更新：

-   **Created：** 您的请求已被记录。
-   **Attesting：** 验证者正在确认您的提取。
-   **Ready to Withdraw：** 确认已完成，资产正在发送中。
-   **Withdrawn/Redeemed：** 资产已成功送达您的目标地址。

您可以使用界面中提供的交易哈希追踪您的交易。

## 重要的地址要求

### 以太坊目标地址
-   必须是有效的以太坊地址（`0x` 后跟 40 个字符）。
-   可以是普通钱包，也可以是接受标准代币转账的智能合约。
-   交易所充值地址如果接受直接的代币转账，也可以使用。

### 比特币目标地址
支持的地址类型：
-   Legacy 地址（以 `1` 开头）
-   SegWit 包装地址（以 `3` 开头）
-   Native SegWit 地址（以 `bc1q` 开头）

**不支持：** Taproot 地址（以 `bc1p` 开头）

## 安全提醒

在确认任何跨链桥交易之前：

-   ✅ **仔细核对目标地址**——交易无法撤销。
-   ✅ **确认您选择了正确的网络**（以太坊还是比特币）。
-   ✅ **确认 App 中显示的费用金额**。
-   ✅ **请记住，桥出交易一经提交便无法取消**。
-   ✅ **确保您的目标地址格式受支持。**

:::danger[警告]
如果您将资金发送到格式有效但错误的地址，您的资金将永久丢失。请始终复制粘贴地址，并仔细核实。
:::


### 常见问题排查

#### “Approval Required” 提示
**对于 mERC-20 代币：** 您需要先授权跨链桥合约花费您的代币。在出现提示时点击 “Approve”，确认交易，然后即可继续桥接。

#### “Unsupported Asset for Destination”
请记住：
-   mERC-20 代币和 MUSD 只能转到以太坊。
-   BTC 可以转到以太坊（以 tBTC 形式）或比特币。

#### “Invalid Recipient Address”
请检查：
-   以太坊地址以 `0x` 开头，总共 42 个字符。
-   比特币地址使用受支持的格式（不支持 `bc1p` Taproot 地址）。
-   您没有在主网交易中使用测试网地址。

#### 交易似乎卡住了
请在交易历史记录中查看状态：
-   如果显示 “Created” 或 “Attesting”——验证者仍在处理中。
-   如果显示 “Ready to Withdraw”——转账正在目标网络上进行中。
-   如果交易待处理时间异常长，请携带您的交易 ID 联系支持团队。

### 常见问题

**问：Mezo 上的 BTC 和以太坊上的 tBTC 有什么区别？**
答：当您将 BTC 从 Mezo 桥接到以太坊时，它会变成 tBTC，这是一种在以太坊网络上代表比特币的 ERC-20 代币。tBTC 由原生比特币 1:1 支撑，并可赎回为原生比特币。

**问：我可以将 mERC-20 代币桥接到比特币吗？**
答：不可以，ERC-20 代币原生于兼容以太坊的网络。您只能将它们桥接回以太坊。

**问：为什么我不能使用 Taproot 比特币地址？**
答：跨链桥目前支持标准的比特币地址格式。对 Taproot（`bc1p`）的支持计划在未来的更新中提供。

**问：我可以取消跨链桥交易吗？**
答：不可以，跨链桥交易一经提交便无法取消。作为该流程的一部分，您的 Mezo 代币会被立即销毁。

**问：桥接需要多长时间？**
答：通过原生跨链桥将资金桥接到以太坊的交易，大多数会在 30-60 分钟内完成，具体取决于网络状况和验证者的认证速度。通过 Wormhole 跨链桥路由的提取通常需要约 5 分钟即可处理完毕。将资金提取到比特币的交易通常需要几个小时才能最终完成。

**问：我可以桥接到哪些网络？**
答：资产可以在以太坊、Mezo、Base 和比特币之间桥接。未来还将增加对更多网络的支持。

**问：我的原生比特币存款还没有到账。如何查看其状态？**
答：请参阅[追踪您的原生比特币存款](/docs/zh/docs/users/mainnet/track-your-native-bitcoin-deposit)，了解如何使用 tBTCScan 核实存款状态的分步指南。

**问：目标网络上的 Gas 由谁支付？**
答：对于以太坊，由跨链桥系统承担最终交付的 Gas 成本。对于比特币，tBTC 跨链桥网络费用涵盖链上交易的成本。

## 安全模型

您的跨链桥交易需要获得至少三分之二的 Mezo 跨链桥验证者的批准，您的资产才会被释放。这种多重签名方式确保任何单一方都无法授权提取，从而在整个桥接过程中保障您的资金安全。

## 需要帮助？

如果您遇到本指南未涵盖的问题：

<Steps>
1. 记下您的交易 ID 或解锁序列号。

2. 截取所有错误消息的屏幕截图。

3. 携带这些信息联系 Mezo 支持团队。
</Steps>

请记住：在确认任何跨链桥交易之前，请务必仔细核实地址并了解相关费用。

## 存款 Portal

作为早期存款计划的一部分、仍存放在 Portal 中的存款，可以提取回用户的 BTC 钱包。从 Portal 提取 BTC 的费用将取决于 tBTC 跨链桥中设置的参数。目前，tBTC 收取 0.2% 的 tBTC 跨链桥服务费，以及最高 0.001 BTC（通常远低于此）的 tBTC 跨链桥网络费用，这些参数由治理控制，可在 [tBTC 费用文档](https://docs.threshold.network/tbtc-v2#fees)中查看。
