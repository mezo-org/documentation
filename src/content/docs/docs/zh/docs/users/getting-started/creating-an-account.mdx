您可以在 Mezo App 中创建账户，用于管理奖励、桥接资产、借入并铸造 MUSD，以及访问 Mezo Market。

<YouTube id="b7SnEPSZjFE" title="如何在 Mezo 上创建账户" />

<Steps>
1. 前往 [Mezo App](https://mezo.org/overview)。

2. 点击 **Sign in** 按钮。

3. 点击 **Sign up**，然后使用您的浏览器钱包登录。如果您想使用以太坊钱包，请点击登录窗口底部的 **Sign in with Ethereum instead**。

4. 连接您的钱包并确认交易，完成注册流程。
</Steps>

登录并签署交易后，您的钱包将与该账户关联。您可以从其他地址桥接 BTC，但账户由您已连接的钱包管理。
