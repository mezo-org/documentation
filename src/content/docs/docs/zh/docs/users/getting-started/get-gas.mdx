借助 **Get Gas** 功能，即使您的钱包中没有任何 BTC，也可以获取少量 BTC 来支付 Mezo 上的交易（Gas）费用。该功能通过执行一笔**免 Gas 兑换**，将少量 MUSD 或 MEZO 兑换为恰好 **0.0001 BTC**，足以支付网络上的多笔交易。

由于这笔兑换无需 Gas（由元交易提供支持），您无需事先持有任何 BTC 即可使用。

## 何时显示？

当您钱包的 BTC 余额低于 **0.000001 BTC** 时，Mezo App 中会自动显示 **"Get Gas"** 按钮。这样，您始终可以补充 Gas，而无需桥入更多 BTC 或使用外部交易所。

## 支持的代币

Get Gas 兑换支持的代币为 **MUSD** 和 **MEZO**。这意味着，仅持有 MEZO 来到链上的用户也可以免费兑换 BTC 作为 Gas，无需桥接其他资产。

## 如何获取 Gas

<Steps>

1. **打开 Get Gas 弹窗**

   当您的 BTC 余额不足时，点击 App 中显示的 **"Get Gas"** 按钮。

2. **选择代币**

   选择 MUSD 或 MEZO 作为源代币。弹窗中将显示这笔兑换的预估成本。

3. **查看报价**

   App 会报出获得恰好 **0.0001 BTC** 所需的 MUSD 或 MEZO 数量。输出数量是固定的，因此无论代币价格如何，您获得的 Gas 数量始终可预期。

4. **确认兑换**

   点击 **"Get Gas"** 发起兑换。钱包将提示您签署两条消息：
   - 一个 **permit 签名**（代币授权）
   - 一个 **execute 签名**（兑换授权）

   这些签名无需支付任何 Gas 费。

5. **等待确认**

   App 将提交您的交易，并自动轮询确认状态。交易确认后，您将看到显示交易哈希的成功页面。

</Steps>

## 运作原理

Get Gas 功能使用**元交易**执行兑换，用户无需支付 Gas：

1. **Permit（许可）**：您签署一条链下消息，授权中继花费您所选代币中所需的数量。
2. **Relay（中继）**：后端中继服务代您提交兑换交易，并承担 Gas 成本。
3. **Swap（兑换）**：交易在链上执行，将您的代币兑换为 **0.0001 BTC**，并直接存入您的钱包。

这种设计意味着，只要您持有 MUSD 或 MEZO，就始终可以获取 Gas——无需 BTC 即可开始使用。

## 关键信息

| 项目 | 值 |
|---|---|
| **输出数量** | 0.0001 BTC（固定） |
| **支持的代币** | MUSD、MEZO |
| **所需 Gas** | 无（通过元交易实现免 Gas） |
| **触发条件** | BTC 余额低于 0.000001 BTC |

:::note
所需的 MUSD 或 MEZO 数量会随当前流动性池价格而变化。弹窗中显示的报价反映兑换时的实时汇率。
:::
