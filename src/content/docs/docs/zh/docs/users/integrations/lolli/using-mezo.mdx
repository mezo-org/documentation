# 如何在 Mezo 上赚取收益、消费和储蓄

## 选项 1：长期持有（最简单的选择）

您的 sats 存放在您的钱包中，完全由您掌控。

## 选项 2：以比特币为抵押借款

无需出售 BTC 即可获得美元。在获得流动性的同时，保留您的比特币敞口。

:::note[关键信息]
- 固定利率，年化利率（APR）低至 1%
- 无还款期限——想何时关闭就何时关闭
- 无需信用审查，一切都在链上完成
- 最低借款金额为 $2,000 MUSD
- 您必须保持至少 110% 的抵押率（要借入 $1,000 MUSD，您需要价值 $1,100 的 BTC）
:::

### 如何借款：

<Steps>
1. 前往 mezo.org/borrow 并连接您的钱包

2. 输入期望的 MUSD 贷款金额

3. 检查您的贷款条款：
   * 利率（目前为 1% 固定利率）
   * 抵押率
   * 清算价格
   * 费用：0.5% 发行费 + 200 MUSD Gas 押金（关闭仓位时退还）

4. 点击 “Borrow” 并确认交易

5. MUSD 会出现在您的钱包中——您的 BTC 将被锁定为抵押品
</Steps>

**您可以用 MUSD 做什么：**

* 在 Mezo Market 中通过 Bitrefill 消费
* 兑换为其他资产
* 在 DeFi 协议中使用

### 管理您的贷款：

在 mezo.org/borrow 上监控您的抵押率。如果 BTC 价格下跌，您的抵押率也会随之降低——请将其保持在 110% 以上，以免被清算。要关闭贷款，请返回 mezo.org/borrow，点击 “Repay”，偿还全部 MUSD 金额及累计利息，然后确认。您的 BTC 抵押品和 200 MUSD Gas 押金将被退还。

## 选项 3：消费您的 sats

使用您的比特币在数百家零售商处购买礼品卡，包括 Amazon、Airbnb、Uber、DoorDash 以及 Visa 预付卡。最低购买金额为 $25 MUSD。

### 第 1 步：将 BTC 兑换为 MUSD

<Steps>
1. 前往 mezo.org/swap

2. 选择 BTC → MUSD 并输入数量

3. 保留价值约 $2 的 BTC 用于支付 Gas 费

4. 检查汇率，然后点击 “Swap”

5. 在钱包中确认
</Steps>

### 第 2 步：购买礼品卡

<Steps>
1. 前往 mezo.org/market

2. 点击 “Bitrefill Gift Cards”

3. 选择金额（最低 $25）

4. 点击 “Purchase” 并使用 MUSD 确认

5. 获取您的兑换码
</Steps>

### 第 3 步：兑换礼品卡

<Steps>
1. 复制您的兑换码

2. 前往 Bitrefill.com，找到您想要的礼品卡

3. 结账时，选择 “Pay with voucher code”

4. 粘贴兑换码并完成购买
</Steps>

---

## 选项 4：通过 MUSD 金库赚取收益

存入您的 MUSD 以赚取收益。这是让您的稳定币产生收益、同时保持资金可随时取用的最简单方式。

### 操作方法：

<Steps>
1. 前往 mezo.org/vaults，浏览可用的 MUSD 金库

2. 查看每个金库的：
   * 锁定期（如有）
   * 奖励率
   * 容量

3. 点击您想要的金库

4. 点击 “Deposit” 并输入 MUSD 数量

5. 确认交易

6. 您现在就开始自动赚取收益了
</Steps>

:::note[重要]
请检查您所选的金库是否有锁定期。确保在此期间您不需要动用这些资金。
:::
