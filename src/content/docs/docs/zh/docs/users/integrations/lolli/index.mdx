这意味着：您的 sats 将从 Lolli 托管转为由您自己托管。您将获得完整的所有权，并可使用以比特币为支撑的银行服务——在保留 BTC 敞口的同时赚取收益、在零售商处消费或借入美元。

## 开始之前：了解自托管

自托管意味着，当您从 Lolli 提现到 Mezo 后，您将自行掌控自己的资金。

您完全拥有自己的比特币；任何人都无法冻结或没收您的资金，您可以随时随地访问它们。但这也意味着，您需要对自己的资金承担全部责任。如果您无法访问自己的钱包，Lolli 和 Mezo 都无法帮您找回资金。

### 助记词就是一切

创建钱包时，您会获得一组助记词（也称为恢复短语），通常由 12 或 24 个随机单词组成。

这是您比特币的主密钥。任何拥有您助记词的人都可以完全访问您的资金。一旦丢失，您的比特币将永远无法找回。

:::tip[请这样做]
- 将助记词写在纸上（或刻在金属上）
- 将其存放在安全的地方——防火保险箱、银行保管箱等
- 考虑在多个安全地点保存副本
- 切勿拍照
- 切勿以数字形式保存（不截图、不存云盘、不存密码管理器）
- 切勿与任何人分享，永远不要
:::

:::danger[切勿这样做]
- 在任何网站或 App 中输入您的助记词（正规钱包绝不会要求您这样做）
- 将其保存在电子邮件、笔记应用或云存储中
- 与任何自称“客服”的人分享（这一定是诈骗）
:::

### 防范诈骗

真正的钱包提供商、Lolli 和 Mezo 绝不会索要您的助记词。如果有人向您索要，那就是诈骗。没有例外。

如有疑问，请自行输入网址，直接访问官方网站。不要点击电子邮件或消息中的链接。

## 选择钱包类型

连接 Mezo 时，您有两种选择。

### 比特币钱包（有一些限制）

**最适合：** 持有 BTC、通过 Bitrefill 消费、在 Mezo 生态系统内进行交互

**限制：** 您只能将 BTC 从 Mezo 提取回比特币地址，且功能可能较为有限。

**支持的钱包：** Xverse、Unisat、OKX Wallet

如果您主要想持有或消费 sats，并不需要更复杂的功能，请选择此类钱包。

### 以太坊钱包（更灵活，推荐）

**最适合：** 走出 Mezo 生态系统

**优势：** 可将 BTC 和其他代币提取到以太坊并在各种 EVM 链之间桥接，可完整使用 Mezo 的所有功能，并且可以更轻松地在 BTC 和 MUSD 之间兑换

**推荐的钱包：** MetaMask、Taho、Zerion

如果您希望在 Mezo 上最大限度地灵活赚取收益、消费和借款，请选择此类钱包。

**我们对新用户的建议：** 从 Taho 等以太坊钱包开始，获得完整体验。

欢迎来到链上比特币银行。
