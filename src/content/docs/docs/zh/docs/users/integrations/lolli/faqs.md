# Lolli x Mezo 常见问题

## 什么是 Mezo？

Mezo 是由 Thesis 打造的比特币银行，让您无需出售比特币即可将其用于日常金融。在 Mezo 上，比特币持有者可以借款、赚取收益和消费——这一切都由以比特币为支撑的稳定币 MUSD 提供支持。它的设计初衷是让您在保留比特币的同时，也能利用比特币的价值。请访问 mezo。

## Mezo 在哪些地区运营？

Mezo 是一个无需许可的区块链平台，这意味着全球任何拥有比特币和 EVM 钱包的人都可以使用。

## 为什么提现到 Mezo 的最低金额是 30,000 sats？

**Lolli → Mezo：** 您可以从 Lolli 向 Mezo 提现 0.0003 BTC（30,000 sats）或更多。设置这一最低金额，是为了确保您可以在 Mezo Market 上购买至少 $25 的 Bitrefill 礼品卡，并留有足够的 sats 支付交易费用。

**Mezo → 比特币 Layer 1：** Mezo 目前要求提现回比特币 Layer 1 的最低金额为 0.01 BTC（1 million sats）。在您的 Mezo 钱包中有 1M sats 之前，您将无法提现到您的比特币 L1 钱包。

我们正在努力降低 Mezo 的最低提现金额。

## 我必须连接 Mezo 才能使用 Lolli 吗？

不需要，Lolli 可以独立运行。不过，我们建议您连接 Mezo，因为它能提供更快的提现速度（通常为 10 秒，取代了以往 60-90 天的等待期），让您的 sats 赚取收益，提供借款功能（您可以以 1% 的固定利率用 BTC 作抵押获得贷款），并与更广泛的比特币金融生态系统集成。

## 使用 Mezo 需要钱包吗？

是的，您需要一个比特币钱包或 EVM 钱包才能使用 Mezo。支持的比特币钱包包括 Unisat、OKX 和 Xverse。支持的 EVM 钱包包括 Taho、Metamask、Zerion 和 OKX。使用 Lolli 并不一定需要连接 Mezo，但您需要一个账户和钱包，才能在 Mezo 上接收提现的 BTC。

## Lolli 和 Mezo 之间是什么关系？

Lolli 和 Mezo 均归 Thesis* 所有，共同构成一个一体化的比特币生态系统。您在 Lolli 上完成操作以赚取 sats，然后将其转入 Mezo 以使用金融功能，从而在更广泛的比特币金融生态系统中探索机会。您可以使用 Mezo 的 MUSD 进行消费或赚取收益，然后将这些收益重新投入这一循环。

## 这一合作如何释放价值？

这一合作带来了：速度——快速提现取代了 60-90 天的等待；灵活性——多种提现选项（BTC，以及即将推出的 MUSD）；增长——赚取的 sats 可以立即在 Mezo 上开始赚取收益；实用性——比特币不再只是被存储，而是变得可消费、可使用；生态系统访问——可使用借款、收益和兑换等集成的 DeFi 功能。

## 什么是 Mezo 的 MUSD 稳定币？

MUSD 是一种无需许可的稳定币，由比特币储备 100% 支撑，旨在与美元保持 1:1 锚定。它是 Mezo 的原生稳定币，可通过 Mezo 的 “Borrow” 功能或 Mezo 网络上的去中心化交易所获取。

## 我可以用 MUSD 进行真实消费吗？

可以。通过 Mezo 与 Bitrefill 的合作，您可以购买满足日常需求的礼品卡。未来的集成将进一步扩展现实世界的使用场景。

## 风险与安全

比特币通过 Threshold Network 的去中心化托管网络持有，这是规模最大的去中心化比特币跨链桥。所有储备均可在 tbtcscan.com 上全天候公开验证。智能合约审计已经完成。您始终保有对 BTC 的托管权——Mezo 不持有您的密钥。
