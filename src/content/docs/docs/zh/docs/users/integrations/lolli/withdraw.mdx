## 最低提现金额
### 从 Lolli 到 Mezo：
最低提现金额：0.0003 BTC（30,000 sats）

### 从 Mezo 到比特币 Layer 1：
最低提现金额：0.01 BTC（1,000,000 sats）

:::note[重要]
在您的 Mezo 钱包中累积到 1M sats 之前，您无法提现到比特币 Layer 1。您的资金仍可在 Mezo 生态系统内用于消费、赚取收益或借款。
:::


## 第 1 步：开始提现

<Steps>
1. 登录您的 Lolli 账户

2. 前往 “Rewards”

3. 点击 “Withdraw to Mezo”

4. 选择 “sats to BTC”（USD 选项即将推出）
</Steps>

## 第 2 步：创建或连接钱包

**如果您还没有钱包：**

<Steps>
1. 点击 “Create new wallet”，您将被引导至钱包提供商（我们建议新手使用 Taho）

2. 按照设置说明操作
   :::danger[关键：保护好您的恢复短语]
   您将获得一组恢复短语（12-24 个单词）。
   - 按顺序写下这些单词
   - 将这张纸存放在安全的地方（不要存放在电脑上）
   - 切勿截图或与任何人分享
   :::

3. 完成钱包设置
</Steps>

**如果您已有钱包：**

<Steps>
1. 点击 “Connect existing wallet”

2. 从列表中选择您的钱包

3. 确认连接
</Steps>

## 第 3 步：连接您的 Mezo 账户

<Steps>
1. 点击 “Connect your Mezo account”——您将被重定向到 mezo.org

2. 点击 “Sign In”，并使用您的钱包连接

3. 在出现提示时确认与 Lolli 的连接
</Steps>

## 第 4 步：确认提现

<Steps>
1. 检查您的提现详情（金额、目标地址、费用）

2. 点击 “Withdraw to Mezo”

3. 在钱包中确认交易

4. 等待确认（通常需要 5-30 分钟）
</Steps>

## 第 5 步：确认资金已到账

前往 mezo.org/overview，连接您的钱包，您应该就能看到显示的 BTC 余额。恭喜！您现在已实现自托管，可以开始使用 Mezo 了。
