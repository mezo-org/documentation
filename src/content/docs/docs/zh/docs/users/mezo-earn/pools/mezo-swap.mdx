# 概览

[Mezo Swap](https://mezo.org/overview?modal=swap) 是 Mezo 生态系统内置的去中心化交易所（DEX）。它让用户可以在 BTC、MUSD 和 USDC 等资产之间无缝交易，无需中介、无需订单簿，也无需离开 BitcoinFi 经济。该功能由 [Mezo Pools](/docs/zh/docs/users/mezo-earn/pools) 提供支持，利用基于智能合约的流动性储备实现即时、去中心化的代币兑换。

## 主要功能

- **无需许可**：24/7 全天候在支持的资产之间兑换，无需依赖中介或审批。
- **低滑点**：稳定型池（例如 MUSD 和 USDC）使用专门的曲线，最大限度地降低同类资产之间交易的价格影响。
- **即时流动性**：借助自动做市商（AMM）模型，交易始终可用，无需订单簿或做市商。
- **LP 奖励**：为流动性池提供流动性，赚取一部分兑换手续费。LP 代币会记录您按比例应得的收益。
- **链上透明**：每一笔兑换、费用和流动性仓位都记录在链上，任何人都可以查看。

## 支持的资产

Mezo Swap 目前支持以下资产之间的交易。随着更多代币的加入，此列表将持续更新：

- BTC
- MUSD
- USDC
- USDT

## 运作原理

### 定价机制

Mezo Swap 采用自动做市商（AMM）模型，并使用两种不同的定价曲线：

- **波动型池**：对 BTC/USDC 等资产使用恒定乘积公式 `(x × y = k)`，针对不相关资产之间的价格发现进行了优化。
- **稳定型池**：对 MUSD/USDC 等同类资产使用专门的稳定兑换曲线 `(x³y + y³x ≥ k)`，旨在最大限度地降低价值相近的代币之间交易的滑点。

价格由每个池中代币的比例决定，并随每笔交易自动更新。

### 滑点

当实际兑换价格与报价不一致时，就会产生滑点，原因可能是：

- 有其他交易在您的交易之前完成
- 所选资产的流动性不足

使用 Mezo Swap 时，您可以设置最大滑点容差（默认值：稳定交易对为 0.5%，波动交易对为 1%）。

![滑点示例](/docs/images/mainnet/slippage-example.png)

如果市场条件的变化超出您的容差，交易将会回滚，以保护您免受不利交易的影响。大额交易会对池价格产生较大影响，因此会面临更大的滑点。

要查看可用流动性总量，请前往 [Mezo Pools](https://mezo.org/explore/pools)，您可以在那里找到所有流动性池及其相关数据，包括总流动性（TVL）。

## 费用

- **协议费用**：稳定型池为 0.02%，波动型池为 0.3%（支付给流动性提供者）
- **网络费用**：在链上执行兑换交易所需的标准 Gas 费

在 Mezo App 中预览兑换时，您会看到相关的费用、滑点、网络成本和兑换汇率。
