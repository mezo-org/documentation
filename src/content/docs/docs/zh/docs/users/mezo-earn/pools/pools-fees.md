## 费用

[Mezo Pools](https://mezo.org/explore/pools) 采用针对不同交易对优化的动态费用模型：

### 标准费率

- **波动池**：0.30%
- **稳定池**：0.02%

### 自定义流动性池费用

部分流动性池可能采用由治理设定的自定义费率。这些特殊费率通常适用于：

- **战略合作伙伴流动性池**
- **上线期间的推广流动性池**
- **高交易量的机构交易对**

### 费用的收取方式

当交易者通过 Mezo Pool 执行兑换时：

1. **扣除费用**：费用会自动从输入代币数量中扣除。
   - 示例：在稳定池中兑换 1,000 MUSD，会扣除 0.2 MUSD 作为费用。
2. **立即隔离**：收取的费用会立即转入专用的 PoolFees 合约。
   - 费用永远不会与池的核心流动性储备混合

### 费用以哪种代币支付？

每次兑换时，费用始终以被卖出的代币（输入代币）收取。作为 LP，您会以交易对中的两种代币赚取费用：

- 当交易者将代币 A 兑换为代币 B 时，费用以代币 A 收取
- 当交易者将代币 B 兑换为代币 A 时，费用以代币 B 收取
- 您会根据自己在池中的份额，以两种代币累积并领取费用

示例：在 MUSD/tBTC 池中：

- 交易者将 MUSD 兑换为 BTC：以 MUSD 收取费用（归所有 LP）
- 交易者将 BTC 兑换为 MUSD：以 BTC 收取费用（归所有 LP）
- 作为 LP，您可以获得 MUSD 和 BTC 两种费用中的一部分

### 领取您的费用

1. 在 Mezo Pools 界面中进入您的仓位
2. 点击 “Claim Fees”
3. 确认交易
4. 费用将直接发送到您的钱包

### 费用计算示例

#### 示例 1：波动池（BTC/MUSD）

- **日交易量**：$1,000,000
- **费率**：0.30%
- **每日产生的费用**：$3,000
- **您的份额**：池的 5%
- **您的每日费用**：约 $150

#### 示例 2：稳定池（MUSD/USDC）

- **日交易量**：$5,000,000
- **费率**：0.02%
- **每日产生的费用**：$1,000
- **您的份额**：池的 2%
- **您的每日费用**：约 $20

### 常见问题

#### 费用以哪种货币/代币支付？
费用以每次兑换的输入代币（即被卖出的代币）支付。在 USDC/MEZO 池中，从 USDC 兑换为 MEZO 会产生 USDC 费用，而从 MEZO 兑换为 USDC 会产生 MEZO 费用。作为 LP，您会以两种代币累积并领取费用。

#### 我累积的费用会丢失吗？
不会。费用单独存放在 PoolFees 合约中，并且只能由 LP 代币持有者领取。

#### 费用会自动复利吗？
不会。您必须手动领取并重新存入费用，才能实现复利。
