veBTC 是在 Mezo 网络上锁定的 BTC 的代币化（NFT）表示。锁定 BTC 可让您获得治理权，并分享协议费用。

## 什么是 veBTC？

在 Mezo 上锁定 BTC 后，您会收到一个代表您锁仓仓位的 veBTC NFT。该 NFT 为您提供：

- **投票权**：引导整个生态系统中的排放分配
- **协议费用**：来自链上活动和跨链桥接
- **治理权**：参与塑造 Mezo 的经济未来

---

## 投票权的运作方式

您的 veBTC 权重取决于两个因素：锁定的 BTC 数量（BTC 越多，投票权越大）和锁定期限（锁定越久，可持续的权重越高）。

您的投票权会随时间线性衰减。例如，用户锁定 1 BTC 28 天，初始拥有 1 veBTC，14 天后衰减至 0.5，到期时降为 0。您可以随时延长锁定期限，以保持完整的投票权。

### 锁仓参数

| 参数 | 值 |
|-----------|-------|
| 最短锁定期限 | 1 天 |
| 最长锁定期限 | 28 天 |
| 锁仓衰减 | 线性——权重持续下降，直至归零 |

## 您的收益

### 被动收益（所有 veBTC 持有者）

所有 veBTC 持有者都会按其投票权重自动获得一部分**链上费用和跨链桥费用**。这是只需持有 veBTC 即可累积的被动收益，无需投票。

### 主动收益（需要投票）

通过[为 Gauge 投票](/docs/zh/docs/users/mezo-earn/vote)，您可以根据自己的投票分配获得额外奖励：

- 来自您所投票的流动性池的**兑换手续费**（当 LP 在这些 Gauge 中质押时）
- 如果您为 MUSD Savings Rate Gauge 投票，可获得 **MUSD 利息/费用收入**
- 协议或用户为吸引投票流向特定 Gauge 而发布的**激励**

您分配给某个 Gauge 的投票权重越多，您在该 Gauge 的费用和激励中所占的份额就越大。

:::note[重要]
您的投票分配会跨周期保留，并持续产生收益，直到您更改为止——您无需每周重新投票。请参阅下方的[周期](#周期)。
:::

## 周期

Mezo Earn 以 **7 天为一个周期**（epoch）运行。每个周期从周四 00:00 UTC 开始。

### 为什么周期很重要

- **投票会保留。** 您的投票分配会跨周期延续，直到您更改或重置为止。每个锁仓在每个周期只能投票一次，因此已确认的投票分配要到下一次周期切换后才能更改。
- **在第 N 个周期投出的票**决定第 N+1 个周期的排放分配
- **在第 N 个周期产生的费用**根据第 N 个周期的投票进行分配

### 锁定期限与周期对齐

锁定期限按周期边界对齐，而不是按日历天数计算。创建锁仓时，**您的锁定时间会向下取整到最近的完整周**。

这意味着：

- 在周期中途创建的 28 天锁仓，其有效期限约为 21–28 天，具体取决于您的锁定时间
- 锁仓总是在周期切换时（周四 00:00 UTC）到期

**示例：** 如果您在周期中途选择 28 天的最长锁定期限，有效锁定期限会根据本周剩余时间相应缩短，最终约为 21–28 天，具体取决于您的锁定时间。

这种标准化处理确保所有锁仓都在周期边界准时到期，并简化了整个系统的投票权重计算。

| 周期参数 | 值 |
|-----------------|-------|
| 时长 | 7 天 |
| 开始时间 | 周四 00:00 UTC |
| 锁仓对齐 | 向下取整到完整周 |
