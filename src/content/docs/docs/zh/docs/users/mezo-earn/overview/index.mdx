Mezo Earn 是驱动 Mezo 网络运转的经济引擎。它让比特币持有者能够在 BTC 上赚取收益，同时参与治理决策，共同决定网络如何分配资源和奖励。

通过将 BTC 锁定到系统中，用户可以获得投票权，从网络活动中赚取被动收益，并帮助引导整个 Mezo 生态系统的流动性。

## 收益从何而来？

Mezo Earn 的收益来自网络上真实的经济活动，主要有三个来源：

### 1. 兑换手续费

当用户在 Mezo 的 DEX 上交易资产时，每次兑换都会产生一笔手续费。这些手续费在流动性池中累积，并分配给为这些流动性池投票的参与者。

### 2. MUSD 借贷收入

Mezo 允许用户以 BTC 作为抵押品借入 MUSD（一种比特币支持的稳定币）。这些贷款产生的利息、开仓费和再融资费用会回流到系统中，并分配给积极参与者。

### 3. 跨链桥费用与交易费用

将资产转入 Mezo、执行交易以及其他链上活动都会产生费用。这些费用作为被动收益直接分配给 veBTC 持有者——**无需投票**。

## 双代币模型

Mezo Earn 采用双代币系统，在以比特币为治理核心的同时，利用 MEZO 来放大并引导影响力。

![双代币模型](/docs/images/mezo-token/EARN%20Chart%207.png)

### veBTC：锚点

veBTC（投票托管 BTC）是投票权的基础。锁定 BTC 后，您会收到一个 veBTC NFT，它为您提供：

- 基础投票权重（1x 倍数）
- 来自跨链桥费用和链上费用的被动收益
- 为 Gauge 投票并引导排放的权利

**参数：**
- 最长锁定期限：28 天
- 最短锁定期限：1 天
- 衰减：线性（投票权重随锁仓临近到期而减少）

### veMEZO：加成

veMEZO（投票托管 MEZO）可放大 veBTC 的投票权，但本身不具备独立的治理权重。将 MEZO 锁定为 veMEZO 后，您可以：

- 为 veBTC 仓位提供加成，最高可达其基础权重的 5x
- 通过将投票引导至 veBTC Gauge 来赚取激励
- 获得可防止稀释的 Rebase 分配

**参数：**
- 最长锁定期限：4 年
- 最短锁定期限：1 周
- 衰减：线性

**关键原则：** MEZO 无法形成独立的治理权，它只能放大已锁定比特币的权重。

## 关键概念

### 加成后权重

veBTC 与 veMEZO 配对后，会形成合并的“加成后权重”，它决定您可获得的费用份额以及您对排放的影响力。加成取决于您在系统中 veBTC 总量和 veMEZO 总量中所占的相对份额。

- 没有 veMEZO 的 veBTC 仓位以 1x（基础权重）运作
- 添加 veMEZO 最高可将其提升至 5x
- BTC 仓位越大，达到最大加成所需的 MEZO 也按比例越多

### 周期

Mezo Earn 以 7 天为一个循环运行，称为**周期**（epoch）。每个周期从周四 00:00 UTC 开始。

**每个周期会发生什么：**

- 在第 N 个周期投出的票决定第 N+1 个周期的排放分配
- 在第 N 个周期产生的费用根据第 N 个周期投出的票进行分配
- 锁定期限按周期边界对齐（始终向下取整到完整周）

这种结构让投票者可以先观察费用的产生情况，再决定下一个周期将投票分配到哪里。

### Gauge

Gauge 是根据投票接收并分配经济价值的智能合约。您可以把它们看作投票权的去向——某个 Gauge 获得的投票越多，它获得的奖励份额就越大。

**Gauge 类型：**

| Gauge 类型 | 作用 |
| --- | --- |
| **质押 Gauge** | 与 DEX 流动性池或 MUSD 储蓄金库关联。质押者赚取 MEZO 排放，投票者赚取费用。 |
| **验证者 Gauge** | 将奖励引导给保障链安全的网络验证者。 |
| **生态系统 Gauge** | 支持合作协议和生态系统发展。 |
| **veBTC Boost Gauge** | 每个 veBTC NFT 都有自己的 Gauge，veMEZO 持有者可以在其上投票以提供加成。 |

## 配对市场

Mezo Earn 通过加成机制，在 BTC 持有者与 MEZO 持有者之间建立了一个明确的市场。

![配对市场](/docs/images/mezo-token/EARN%20Chart%205.png)

**运作方式：**

1. 锁定 BTC 时，系统会为您的 veBTC 仓位创建一个专属的 Boost Gauge
2. veMEZO 持有者可以在您的 Gauge 上投票，为您提供加成
3. 作为交换，您可以在自己的 Gauge 上发布激励，以吸引 veMEZO 投票
4. 在一笔“Poke”交易刷新您的仓位后，加成才会生效

这使加成成为一种可交易的服务。希望获得更高倍数的 BTC 持有者可以自行购入 MEZO，也可以支付激励来吸引 veMEZO 投票。MEZO 持有者则可以将投票引导至激励有吸引力的 Gauge 来赚取收益。

## 奖励如何流动

**被动收益：** 所有 veBTC 持有者都会按其加成后投票权重获得一部分跨链桥费用和链上费用——除锁定外无需任何操作。

**主动收益：** 通过为特定 Gauge 投票，您可以从所支持的流动性池和协议中赚取额外的费用和激励。

**veMEZO 收益：** veMEZO 持有者可赚取其所投票的 veBTC Gauge 上发布的激励，以及可防止稀释的 Rebase 分配。

## 入门指南

<Steps>
1. **锁定 BTC** → 获得具有基础投票权的 veBTC NFT
2. **为 Gauge 投票** → 引导排放流向并赚取费用
3. **领取奖励** → 每个周期领取费用和激励
4. **（可选）锁定 MEZO** → 创建 veMEZO，为您的 veBTC 提供加成，或通过为他人的 Boost Gauge 投票来赚取收益
5. **延长或管理锁仓** → 长期保持您的投票权
</Steps>
