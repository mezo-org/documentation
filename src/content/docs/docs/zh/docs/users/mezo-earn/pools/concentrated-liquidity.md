集中流动性（CL）池允许您在特定价格区间内存入流动性，而不是覆盖所有可能的价格。通过将资金集中在实际发生交易的区间，与[基础池](/docs/zh/docs/users/mezo-earn/pools)相比，您每存入一美元可以赚取显著更多的费用。

## 集中流动性与基础池的区别

在**基础池**中，您的流动性均匀分布在从零到无穷大的整条价格曲线上。这意味着您的大部分资金闲置在永远不会发生交易的价格区间中。

在**集中流动性池**中，您可以选择一个价格区间——例如，BTC 价格在 80,000 至 120,000 MUSD 之间。您的全部资金都在该区间内处于活跃状态，资金效率因此大幅提高。代价是，如果价格移出您的区间，您的仓位将停止赚取费用，直到价格回到区间内。

| | 基础池 | CL 池 |
|---|---|---|
| **流动性区间** | 整条价格曲线（0 到无穷大） | 由您自定义的价格区间 |
| **资金效率** | 较低——大部分资金闲置 | 较高——全部资金在区间内活跃 |
| **仓位类型** | 同质化 LP 代币（ERC-20） | NFT 仓位（ERC-721） |
| **管理方式** | 一次设置，无需操心 | 需要监控和再平衡 |
| **无常损失** | 标准 | 在所选区间内被放大 |

## Tick 间距

CL 池使用 **Tick 间距**（tick spacing）来定义您可设置的价格区间的精细程度。Tick 间距越小，可设置的区间越窄（精度更高）；Tick 间距越大，最小区间就越宽。

按照 Aerodrome 采用的相同惯例，流动性池分为**稳定型**池（Tick 间距小于 100）和**波动型**池（Tick 间距为 100 或以上）。

| Tick 间距 | 默认费率 | 分类 |
|---|---|---|
| 1 | 0.01% | 稳定型 |
| 10 | 0.05% | 稳定型 |
| 50 | 0.05% | 稳定型 |
| 100 | 0.05% | 波动型 |
| 200 | 0.30% | 波动型 |
| 2,000 | 1.00% | 波动型 |

BTC/MUSD-200 池的 Tick 间距为 200，兑换手续费为 0.30%。

## 快速开始（即将推出）

1. 前往 [Mezo Pools](https://mezo.org/explore/pools)，选择您要为其提供流动性的 CL 池。
2. 选择价格区间——设置您的流动性处于活跃状态的最低价格和最高价格。
3. 输入每种代币的存入数量。两者的比例取决于当前价格相对于您所选区间的位置。
4. 检查并确认交易。您将收到一个代表您仓位的 NFT。

### 选择价格区间（即将推出）

- **较宽的区间**——赚取费用更稳定，但资金效率较低。更适合不想频繁操作的方式。
- **较窄的区间**——处于区间内时赚取的费用更多，但需要主动监控和再平衡。超出区间的风险更高。
- **当前价格应位于您的区间内**——如果当前价格在您的区间之外，您的仓位将完全由一种代币构成，并且在价格回到区间内之前不会赚取费用。

## 质押以获取排放（即将推出）

CL 仓位可以质押到 Gauge 中，在交易手续费之外额外赚取 MEZO 排放。通过未质押费用机制，已质押的仓位可获得更大份额的兑换手续费——该机制会将未质押仓位的一部分费用重新分配给已质押的仓位。

质押步骤：

1. 进入您的 CL 仓位。
2. 点击 **Stake**，将您的仓位 NFT 存入 Gauge。
3. 当您的流动性处于区间内时，即可赚取 MEZO 排放。

排放按已质押且处于区间内的流动性按比例分配。如果您的仓位超出区间，您将停止赚取排放，直到价格回到区间内。

## 费用

CL 池的费用与基础池的费用运作方式相同——每次兑换时从输入代币中扣除，并累积起来供流动性提供者领取。

关键区别在于：在 CL 池中，只有在兑换发生时**处于区间内**的仓位才能赚取费用。处于活跃价格区间之外的仓位在价格回到区间内之前没有任何收益。

有关费用模型的更多详情，请参阅[流动性池费用](/docs/zh/docs/users/mezo-earn/pools/pools-fees)。

## 风险

### 无常损失

与基础池相比，集中流动性会**放大**无常损失。由于您的资金集中在一个较窄的区间内，该区间内的价格变动会对您仓位中的代币比例产生更大的影响。区间越窄，潜在的无常损失就越大。

### 超出区间风险

如果市场价格移出您所选的区间，您的仓位将完全转换为一种代币，并停止赚取费用或排放。您需要等待价格回到区间内，或者提取流动性并重新设置仓位。

### 智能合约风险

与所有智能合约一样，固有风险依然存在。请在 [mezo.org/audits](https://mezo.org/audits) 查看审计报告，并且只存入您能够承受的金额。
