## 常见问题

**我可以提前解锁 BTC 吗？**

不可以。锁仓在到期前永久有效，请谨慎选择锁定期限。

**如果我不投票会怎样？**

您将无法从 Gauge 中赚取任何费用或排放。不过，您仍会获得分配给所有 veBTC 持有者的跨链桥费用。

**我可以拥有多个 veBTC 仓位吗？**

可以。每次锁定都会创建一个单独的 veBTC NFT。如有需要，您之后可以将它们合并。

**我可以将锁定的 BTC 用作抵押品吗？**

不可以。如果不解锁底层 BTC，您的 veBTC NFT 无法在 Mezo 的 MUSD 借款系统中用作抵押品。
