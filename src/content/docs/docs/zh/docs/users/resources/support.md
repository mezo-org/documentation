## 第 1 步

在 general 频道中 @ 一位版主、digijoe 或 lowpolyduck，申请 “open-ticket” 角色，以解锁支持工单频道。

## 第 2 步

按照流程操作，将您的工单转至相应部门

  ![](/docs/images/portal/support-intro.png)

请告诉我们，您需要协助的问题是需要工程支持、需要 BD/合作伙伴团队的支持，还是其他问题。

### 工程支持

请告诉我们，您是寻求工程支持的用户，还是合作伙伴/验证者

### 工程支持（用户路径）

对于寻求工程支持的用户，请告诉我们您的问题是与想要报告的漏洞有关、与将资金桥接到 Mezo 有关、与 MUSD 借款有关，还是其他问题。

  ![](/docs/images/portal/user-engineering-support.png)

最后，如果您遇到上述任何问题，需要提供：

* 您的钱包地址
* 交易哈希/区块浏览器链接（如适用）
* 任何有助于说明情况的补充信息

### 工程支持（合作伙伴/验证者路径）

首先，系统会提示您说明自己是寻求工程支持的合作伙伴、验证者还是开发者。

对于生态系统合作伙伴，请告诉我们您目前已部署在 Mezo 上，还是正在部署中。

  ![](/docs/images/portal/ecosystem-partner-deployment-status.png)

最后，无论您是已部署还是正在部署，系统都会提示您提供有关所需支持问题的更多详情，相应团队会尽快回复您。

对于验证者和开发者，系统都会立即提示您提供有关所需支持问题的更多详情，相应团队会尽快回复您。

### BD/合作咨询

请告诉我们，您是希望与 Mezo 合作的 dApp/协议、希望在 Mezo 上部署节点的验证者、寻求合作的 KOL，还是其他情况。

### dApp/协议

对于 dApp/协议，系统会提示您提供以下信息：

* 您的协议/应用名称
* 官方网站
* 当前已部署的链（如有）
* X 账号
* 与您的咨询相关的任何补充信息

提供这些信息后，相应的团队成员将审核信息并尽快回复您。

  ![](/docs/images/portal/eco-partner-team-info.png)

### 验证者

对于验证者，系统会提示您提供以下信息：

* 您的服务名称（如适用）
* 您已部署活跃节点的网络列表
* X 账号
* 与您的咨询相关的任何补充信息

提供这些信息后，相应的团队成员将审核信息并尽快回复您。

### KOL

对于 KOL，系统会提示您提供以下信息：

* 您官方社交账号的链接
* 网站（如适用）
* 推荐人（如适用）
* 与您的咨询相关的任何补充信息

提供这些信息后，相应的团队成员将审核信息并尽快回复您。

对于其他任何与 BD/合作相关的事宜，系统会提示您提供更多详情，相应的团队成员将审核信息并尽快回复您。

### 其他问题

如果您的问题既不需要工程支持，也不需要 BD/合作支持，系统会提示您说明问题属于技术类还是非技术类

  ![](/docs/images/portal/support-something-else.png)

说明之后，请提供更多详情，相应团队会尽快回复您。
