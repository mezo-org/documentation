## 代币合约

您可以在 Mezo Explorer 中将这些代币添加到钱包。在区块浏览器中打开代币地址，然后点击 MUSD 代币地址旁边的 **Add token to MetaMask** 按钮。

部分代币合约是 `TransparentUpgradableProxy` 合约。请将代理地址（而不是代理背后的代币地址）手动添加到您的浏览器钱包。例如，在 MetaMask 中，请按照[导入代币](https://support.metamask.io/manage-crypto/portfolio/how-to-import-a-token-in-metamask-portfolio/)的说明操作。在您针对该代币完成首次转账和授权之前，这些代币不会显示在 [Mezo Explorer](https://explorer.mezo.org/) 中您的 EOA 下。
