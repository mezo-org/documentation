MEZO 是 Mezo 的原生代币——用于为投票权提供加成，并影响协议费用和激励的流向。

📄 **[下载代币披露文件（PDF）](/docs/MEZO_Disclosure.pdf)**

## 代币分配

**创世总供应量：1,000,000,000 MEZO**

| 分配对象 | 数量 | 占比 |
|---|---|---|
| 社区 | 400M | 40% |
| 投资者与合作伙伴 | 300M | 30% |
| Mezo 团队 | 200M | 20% |
| 基金会 | 100M | 10% |

![MEZO 代币分配](/docs/images/mezo-token/tokenomics-donut.png)

## 分配明细

**社区（40%）**——生态系统参与者、空投、面向 dApp 的 LP 激励、验证者以及资助计划。

**投资者与合作伙伴（30%）**——早期支持者和战略合作伙伴。

**Mezo 团队（20%）**——构建 Mezo 的核心贡献者。

**基金会（10%）**——Supernormal Foundation 储备，用于合作伙伴关系、生态系统发展、应急储备以及协议的长期可持续发展。于 TGE 时解锁。

## 归属计划

所有归属均在 TGE 后 36 个月内完成。投资者和团队自 TGE 起有 1 年（12 个月）的悬崖期，随后在 2 年（24 个月）内按月线性解锁代币。

| 分配对象 | 悬崖期 | 归属方式 |
|---|---|---|
| 社区 | 无 | 立即 |
| 基金会 | 无 | 立即 |
| 团队 | 1 年 | 3 年线性 |
| 投资者 | 1 年 | 3 年线性 |
