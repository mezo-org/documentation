MEZO 是 Mezo 的原生代币。它可以影响激励的流向，并捕获链上产生的价值。

## 什么是 MEZO？

MEZO 是 Mezo 网络的战略协调资产。它并不取代 BTC 作为优质抵押品的角色——而是放大由比特币活动所创造的价值，并影响其流向。

MEZO 的用途：

- **提升投票权**——将 MEZO 锁定为 veMEZO，可将您的 veBTC 投票权重最高放大至 5x
- **赚取 Rebase 奖励**——veMEZO 持有者可从每周排放中获得反稀释 Rebase

## MEZO 与 veMEZO

|  | MEZO | veMEZO |
|---|---|---|
| 是什么 | 流动的、可转让的代币 | 代表已锁定 MEZO 的 NFT |
| 如何获得 | 购买、赚取或通过空投获得 | 将 MEZO 锁定 1 周至 4 年 |
| 有什么用 | 持有或交易 | 为 veBTC 投票权提供加成、对 MEZO Gauges 投票、赚取 Rebase |

## 主要特性

- **两项职能**——veMEZO 可放大 veBTC 在质押 Gauge 上的权重，同时还能以自身名义对 [veBTC Boost Gauge](/docs/zh/docs/users/mezo-earn/lock/vemezo/matching-market) 和 [MEZO Gauges](/docs/zh/docs/users/mezo-earn/vote/mezo-gauges) 投票。它本身不具备治理权重。
- **不能单独为质押 Gauge 投票**——没有 veBTC，veMEZO 无法对质押 Gauge 投票。
- **时间加权**——锁定期限越长 = veMEZO 权重越高
- **可作为 NFT 转让**——veMEZO 仓位是 ERC-721 NFT，可以转让或合并
