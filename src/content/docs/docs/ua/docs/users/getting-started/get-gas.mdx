Функція **Get Gas** дає змогу отримати невелику кількість BTC для оплати комісій за транзакції (газу) в Mezo — навіть якщо у вашому гаманці немає BTC. Вона виконує **обмін без газу**: невелика кількість MUSD або MEZO обмінюється рівно на **0,0001 BTC** — цього вистачить на кілька транзакцій у мережі.

Оскільки обмін не потребує газу (працює на метатранзакціях), для нього не потрібні наявні BTC.

## Коли вона з'являється?

Кнопка **«Get Gas»** автоматично з'являється в застосунку Mezo, коли баланс BTC у вашому гаманці опускається нижче **0,000001 BTC**. Так у вас завжди є спосіб поповнити газ без переказу додаткових BTC через міст чи використання зовнішньої біржі.

## Підтримувані токени

Для обмінів Get Gas підтримуються токени **MUSD** і **MEZO**. Тобто користувачі, які приходять у мережу лише з MEZO, можуть безкоштовно обміняти їх на BTC для газу, не переказуючи через міст інші активи.

## Як отримати газ

<Steps>

1. **Відкрийте вікно Get Gas**

   Коли баланс BTC низький, натисніть кнопку **«Get Gas»**, яка з'явиться в застосунку.

2. **Виберіть токен**

   Виберіть MUSD або MEZO як вихідний токен. У вікні буде показано орієнтовну вартість обміну.

3. **Перегляньте котирування**

   Застосунок показує, скільки MUSD або MEZO потрібно, щоб отримати рівно **0,0001 BTC**. Сума, яку ви отримуєте, фіксована, тож ви завжди отримуєте передбачувану кількість газу незалежно від ціни токена.

4. **Підтвердьте обмін**

   Натисніть **«Get Gas»**, щоб розпочати обмін. Гаманець попросить підписати два повідомлення:
   - **Підпис permit** (дозвіл на використання токена)
   - **Підпис execute** (авторизація обміну)

   Для цих підписів сплачувати газ не потрібно.

5. **Дочекайтеся підтвердження**

   Застосунок надішле вашу транзакцію й автоматично відстежуватиме її підтвердження. Після підтвердження ви побачите екран успішного завершення з хешем транзакції.

</Steps>

## Як це працює

Функція Get Gas використовує **метатранзакції**, щоб виконати обмін, не вимагаючи від користувача газу:

1. **Permit**: ви підписуєте офчейн-повідомлення, яке дозволяє ретранслятору витратити потрібну кількість вибраного вами токена.
2. **Relay**: бекенд-сервіс ретрансляції надсилає транзакцію обміну від вашого імені й покриває вартість газу.
3. **Swap**: транзакція виконується ончейн і обмінює ваш токен на **0,0001 BTC**, які надходять безпосередньо на ваш гаманець.

Завдяки такій схемі ви завжди можете отримати газ, якщо маєте MUSD або MEZO, — щоб почати, BTC не потрібні.

## Основні параметри

| Параметр | Значення |
|---|---|
| **Сума, яку ви отримуєте** | 0,0001 BTC (фіксовано) |
| **Підтримувані токени** | MUSD, MEZO |
| **Потрібний газ** | Не потрібен (без газу завдяки метатранзакціям) |
| **Умова появи** | Баланс BTC нижче 0,000001 BTC |

:::note
Вартість у MUSD або MEZO залежить від поточних цін у пулах. Котирування у вікні відображає курс у реальному часі на момент обміну.
:::
