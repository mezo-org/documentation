[Safe](https://safe.global/) (раніше Gnosis Safe) — найпоширеніший мультипідписний гаманець у криптоіндустрії. Mezo має нативне розгортання Safe на [safe.mezo.org](https://safe.mezo.org), яким керує [Den](https://www.onchainden.com/).

Мультипідписний (multi-signature) гаманець вимагає, щоб транзакцію схвалили кілька людей, перш ніж її буде виконано. Замість того щоб одна людина контролювала кошти за допомогою одного приватного ключа, група встановлює правила на кшталт «3 з 5 підписантів мають схвалити».

## Початок роботи

<Steps>

1. Перейдіть на [safe.mezo.org](https://safe.mezo.org).

2. Під'єднайте гаманець.

3. Натисніть **Create new Safe Account**.

4. Додайте адреси гаманців інших підписантів.

5. Встановіть поріг підтвердження — кількість схвалень, потрібну для виконання транзакції (наприклад, 2 з 3).

6. Перевірте налаштування й розгорніть свій Safe.

</Steps>

Після розгортання ви можете надсилати й отримувати BTC та інші токени в Mezo через свій Safe, причому кожна транзакція потребуватиме налаштованої вами кількості схвалень.

## Можливості

- **Захист за допомогою кількох підписів** — транзакції виконуються лише після схвалення кількома підписантами.
- **Модулі та обмежувачі (guards)** — налаштовуйте Safe за допомогою підключуваних модулів для лімітів витрат, відновлення, автоматизованих транзакцій тощо.
- **Доступ до екосистеми** — взаємодійте з dApps у Mezo безпосередньо зі свого Safe через вбудований браузер застосунків.
- **Відстеження облікових записів** — стежте за будь-яким обліковим записом Safe, не під'єднуючи гаманця.
