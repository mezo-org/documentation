import { Steps } from '@astrojs/starlight/components';

Коли інший користувач викуповує MUSD за рахунок вашої позики — Trove (позикової позиції) — і її повністю погашено, ваш борг анулюється, але залишок застави лишається в смарт-контрактах MUSD, доки ви його не заберете. Ваша застава в безпеці, і ви можете повернути її будь-коли.

Зазвичай на сторінці Borrow з'являється сповіщення «Loan redeemed», яке дає змогу повернути заставу безпосередньо з інтерфейсу. Для цього натисніть кнопку праворуч від сповіщення, як показано на знімку екрана нижче.

![Сповіщення «Loan redeemed» на сторінці Borrow](/docs/images/musd/loan-redeemed.webp)

Якщо ви не бачите цього сповіщення, можна повернути заставу вручну, викликавши функцію `claimCollateral` контракту BorrowerOperations через Mezo Explorer. Виконайте наведені нижче кроки.

<Steps>

1. **Перейдіть до контракту BorrowerOperations**

   Відкрийте [контракт BorrowerOperations у Mezo Explorer](https://explorer.mezo.org/address/0x44b1bac67dDA612a41a58AAf779143B181dEe031).

2. **Відкрийте вкладку «Contract»**

   На панелі вкладок поруч із Transactions, Token transfers і Tokens натисніть **Contract**.

   З'являться чотири підвкладки: **Code**, **Read proxy**, **Write contract** і **Write proxy**.

3. **Натисніть «Write proxy»**

   Натисніть вкладку **Write proxy**. Саме на цій вкладці доступні всі функції запису базового контракту реалізації BorrowerOperations.

   :::caution
   Обов'язково виберіть **Write proxy** (а не «Write contract») — вкладка проксі відображає фактичну логіку BorrowerOperations.
   :::

4. **Під'єднайте гаманець**

   Над функціями контракту ви побачите жовто-помаранчевий банер з написом «Disconnected» і кнопкою **Connect wallet**.

   Натисніть **Connect wallet** і підтвердьте під'єднання в гаманці (наприклад, MetaMask). Обов'язково під'єднайтеся з тієї самої адреси гаманця, якій належав викуплений Trove, оскільки лише ця адреса може повернути його заставу.

5. **Знайдіть функцію claimCollateral**

   Прокрутіть список функцій контракту донизу, доки не дійдете до:

   **7. claimCollateral**

   Натисніть на неї, щоб розгорнути функцію. Вхідні параметри не потрібні — функція просто повертає всю заставу, відкладену для вашої адреси після повного викупу.

6. **Натисніть «Write»**

   Під'єднавши гаманець, натисніть кнопку **Write** під функцією `claimCollateral`.

   Гаманець запропонує підтвердити транзакцію. Перевірте комісію за газ і підтвердьте. Після завершення транзакції вашу заставу (BTC) буде надіслано безпосередньо на ваш гаманець.

</Steps>
