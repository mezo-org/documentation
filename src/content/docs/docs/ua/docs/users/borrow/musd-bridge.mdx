Міст [MUSD](https://mezo.org/feature/musd) дає змогу переказувати токени між мережами Mezo, Ethereum і Base за допомогою протоколу Native Token Transfer (NTT) від Wormhole. Цей міст зберігає взаємозамінність токенів і водночас забезпечує безпечну міжмережеву функціональність.

## Як це працює

Міст MUSD використовує протокол Native Token Transfer від Wormhole для міжмережевих переказів:

- **З Mezo в Ethereum/Base**: токени MUSD блокуються в Mezo, а еквівалентна кількість токенів випускається в цільовому ланцюгу
- **З Ethereum/Base в Mezo**: токени MUSD спалюються в ланцюзі-джерелі, а еквівалентна кількість токенів розблоковується в Mezo

Цей механізм гарантує, що загальна пропозиція в усіх ланцюгах залишається незмінною, а користувачі можуть вільно переміщувати свої токени між мережами.

## Варіанти мосту

Для переказу токенів MUSD через міст доступні два інтерфейси:

### dApp Mezo

[dApp Mezo](https://mezo.org) надає вбудований механізм переказу токенів MUSD між мережами Mezo та Ethereum.

<Steps>
1. **Під'єднайте гаманець** до dApp Mezo

2. **Натисніть «Withdraw»**, щоб переказати кошти з Mezo, або **«Deposit»**, щоб переказати їх у Mezo

3. **Виберіть токен MUSD** і введіть суму

4. **Підтвердьте транзакцію** у своєму гаманці

5. **Дочекайтеся підтвердження** в обох ланцюгах
</Steps>

### Інтерфейс Portal Bridge

Для переказу токенів MUSD у Base або Ethereum можна також скористатися [інтерфейсом Portal](https://portalbridge.com/):

<Steps>
1. **Під'єднайте гаманець** до інтерфейсу Portal

2. **Виберіть ланцюг-джерело та цільовий ланцюг** (Mezo ↔ Ethereum ↔ Base)

3. **Виберіть MUSD** як токен для переказу

4. **Введіть суму**, яку хочете переказати

5. **Перегляньте дані транзакції**, зокрема комісії та орієнтовний час

6. **Підтвердьте транзакцію** у своєму гаманці

7. **Дочекайтеся підтвердження** в обох ланцюгах
</Steps>

Обидва інтерфейси зручні для користувача й беруть на себе всю складну взаємодію з базовими контрактами NTT.
