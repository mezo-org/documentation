Mezo ID — це зручний для читання ідентифікатор, пов'язаний із гаманцем у мережі Mezo. Замість того щоб передавати повну адресу гаманця `0x…`, користувачі можуть повідомити свій Mezo ID, щоб отримати активи.

## Як це працює

Коли хтось вводить ваш Mezo ID у [формі надсилання](/docs/ua/docs/users/passport/send-assets), Mezo автоматично перетворює його на адресу вашого гаманця. Отриману адресу показано як крок підтвердження, щоб відправник міг перевірити адресу призначення перед завершенням транзакції.

Так само це працює, коли вводять біткоїн-адресу: Mezo зіставляє її з пов'язаним гаманцем у мережі.

## Використання вашого Mezo ID

- **Отримання активів** — повідомляйте іншим користувачам Mezo свій Mezo ID замість повної адреси гаманця.
- **Надсилання активів** — введіть Mezo ID отримувача у формі Send у Passport. Перш ніж підтвердити, перевірте отриману адресу гаманця.
