Міст MEZO дає змогу здійснювати перекази між Mezo та кількома мережами, зокрема Ethereum, Base, BSC і Solana, за допомогою протоколу Native Token Transfer (NTT) від Wormhole. Цей міст зберігає взаємозамінність токена й водночас забезпечує безпечну кросчейн-функціональність.

## Як це працює

Міст MEZO використовує протокол Native Token Transfer від Wormhole для кросчейн-переказів:

- **З Mezo в інші ланцюги**: токени MEZO блокуються в Mezo, а еквівалентна кількість токенів випускається в цільовому ланцюзі (Ethereum, Base, BSC або Solana)
- **З інших ланцюгів у Mezo**: токени MEZO спалюються в ланцюзі-джерелі, а еквівалентна кількість токенів розблоковується в Mezo

Цей механізм гарантує, що загальна пропозиція в усіх ланцюгах залишається незмінною, а користувачі можуть вільно переміщувати свої токени між мережами.

## Варіанти переказу через міст

Для переказу токенів MEZO через міст доступні два інтерфейси:

### dApp Mezo

[dApp Mezo](https://mezo.org) забезпечує нативний переказ токенів MEZO через міст лише між мережами Mezo та Ethereum.

**Щоб переказати з Mezo в Ethereum (виведення):**

<Steps>
1. **Під'єднайте свій гаманець** до dApp Mezo

2. **Натисніть «Withdraw»**, щоб переказати токени з Mezo

3. **Виберіть токен MEZO** і введіть суму для виведення

4. **Підтвердьте транзакцію** у своєму гаманці

5. **Дочекайтеся підтвердження** в обох ланцюгах
</Steps>

**Щоб переказати з Ethereum у Mezo (депозит):**

<Steps>
1. **Під'єднайте свій гаманець** до dApp Mezo

2. **Натисніть «Deposit»**, щоб переказати токени в Mezo

3. **Виберіть токен MEZO** і введіть суму для внесення

4. **Підтвердьте транзакцію** у своєму гаманці

5. **Дочекайтеся підтвердження** в обох ланцюгах
</Steps>

### Інтерфейс Wormhole Portal Bridge

Щоб переказати токени MEZO в Base, BSC, Solana або Ethereum, скористайтеся [інтерфейсом Portal](https://portalbridge.com/):

<Steps>
1. **Під'єднайте свій гаманець** до інтерфейсу Portal

2. **Виберіть ланцюг-джерело та цільовий ланцюг** (Mezo ↔ Ethereum, Base, BSC або Solana)

3. **Виберіть MEZO** як токен для переказу

4. **Введіть суму**, яку хочете переказати

5. **Перегляньте подробиці транзакції**, зокрема комісії та орієнтовний час

6. **Підтвердьте транзакцію** у своєму гаманці

7. **Дочекайтеся підтвердження** в обох ланцюгах
</Steps>

Обидва інтерфейси зручні для користувачів і самі виконують усі складні взаємодії з базовими контрактами NTT.
