Врядування мережі Mezo дає власникам veBTC змогу впливати на параметри протоколу та потоки емісії. Врядування закріплене за BTC: veMEZO посилює силу голосу veBTC, а не має власної ваги у врядуванні.

## Параметри протоколу

Такі параметри визначають, як розподіляється емісія MEZO:

| Параметр | Опис | Статус |
|---|---|---|
| Співвідношення Chain Splitter | Частка емісії для валідаторів (20%) порівняно з екосистемою (80%) | Фіксоване, закріплене через врядування |
| Співвідношення Ecosystem Splitter | Частка емісії для gauges зі стейкінгом (90%) порівняно з екосистемними gauges (10%) | Фіксоване, закріплене через врядування |
| Максимальний множник boost | Максимальний boost veMEZO для veBTC | Наразі 5x |

Співвідношення Splitter наразі фіксовані, і їх не можна змінити голосуванням. У майбутньому ці співвідношення можуть стати регульованими завдяки новим механізмам врядування.

## Обмеження врядування

- **Голосування, закріплене за BTC** — голосувати за пропозиції врядування можуть лише власники veBTC. veMEZO посилює силу голосу veBTC, але не надає власних прав у врядуванні. Водночас veMEZO самостійно голосує за [gauges boost для veBTC](/docs/ua/docs/users/mezo-earn/lock/vemezo/matching-market) і [MEZO Gauges](/docs/ua/docs/users/mezo-earn/vote/mezo-gauges), які спрямовують емісію, а не встановлюють параметри протоколу.

## Подальший розвиток

Структури врядування можуть розвиватися й охоплювати:

- Формальні механізми пропозицій і голосування (наприклад, Governor Bravo)
- Додаткові параметри, що регулюються врядуванням
- Вибір валідаторів через голосування за gauges в умовах proof-of-stake

Подробиці буде оголошено, коли функції врядування буде остаточно сформовано.
