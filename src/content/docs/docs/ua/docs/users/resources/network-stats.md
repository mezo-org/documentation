Відстежуйте активність мережі Mezo, показники MUSD і дані токенів за допомогою цих офіційних і спільнотних ресурсів.

## Офіційні дашборди

- [MUSD on Mezo (Dune)](https://dune.com/scoffie/musd-on-mezo) - пропозиція MUSD, активність випуску та показники використання
- [Chain Overview (Dune)](https://dune.com/scoffie/chainoverviewmezo) - статистика й активність на рівні мережі
- [DexScreener](https://dexscreener.com/search?q=0xdD468A1DDc392dcdbEf6db6e34E89AA338F9F186) - торгові пари токенів і торгові дані

## Агрегатори

- [DefiLlama](https://defillama.com/chain/mezo) - загальна заблокована вартість (TVL), ринкова капіталізація стейблкоїнів та обсяг торгів
- **CoinGecko:** незабаром
- **CoinMarketCap:** незабаром

## Від спільноти

Дашборди, створені та/або підтримувані спільнотою Mezo. Якщо у вас є дашборд, який ви хотіли б додати на цю сторінку, напишіть нам у Discord або створіть PR із доповненням.

- [MezoTools](https://mezotools.cc/) - докладна аналітика MUSD, забезпечення системи, дані окремих Trove, ціна MUSD, сторінка викупів тощо.
