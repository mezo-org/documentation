## Часті запитання

**Чи можу я розблокувати свої BTC достроково?**

Ні. Блокування діє безповоротно до завершення строку. Вибирайте тривалість уважно.

**Що буде, якщо я не голосуватиму?**

Ви не отримуватимете жодних комісій чи емісії від gauges. Проте ви все одно отримуватимете комісії за переказ через міст, які розподіляються між усіма власниками veBTC.

**Чи можу я мати кілька позицій veBTC?**

Так. Кожне блокування створює окремий veBTC NFT. За бажання пізніше ви можете їх об'єднати.

**Чи можу я використовувати заблоковані BTC як заставу?**

Ні. Ваш veBTC NFT не можна використати як заставу в системі позик MUSD у Mezo без розблокування базових BTC.
