# Огляд

[Mezo Swap](https://mezo.org/overview?modal=swap) — це вбудована децентралізована біржа (DEX) екосистеми Mezo. Вона дає користувачам змогу безперешкодно обмінювати такі активи, як BTC, MUSD і USDC, без посередників, книг ордерів і не виходячи з економіки BitcoinFi. Функцію забезпечують [Mezo Pools](/docs/ua/docs/users/mezo-earn/pools), що дає змогу здійснювати миттєвий децентралізований обмін токенів за допомогою резервів ліквідності на основі смарт-контрактів.

## Ключові особливості

- **Без дозволів**: обмінюйте підтримувані активи в режимі 24/7 без посередників і схвалень.
- **Низьке прослизання**: стабільні пули (наприклад, MUSD і USDC) використовують спеціальну криву, щоб мінімізувати вплив на ціну під час обміну між подібними активами.
- **Миттєва ліквідність**: торгівля завжди доступна завдяки моделі автоматизованого маркетмейкера (AMM) — книги ордерів чи маркетмейкери не потрібні.
- **Винагороди LP**: надавайте ліквідність у пули й заробляйте частку комісій за обмін. LP-токени відстежують ваш пропорційний заробіток.
- **Ончейн-прозорість**: кожен обмін, комісія та позиція ліквідності записуються ончейн, і будь-хто може їх переглянути.

## Підтримувані активи

Наразі Mezo Swap підтримує обмін між такими активами. Цей список оновлюватиметься в міру додавання нових токенів:

- BTC
- MUSD
- USDC
- USDT

## Як це працює

### Механізм ціноутворення

Mezo Swap використовує модель автоматизованого маркетмейкера (AMM) із двома різними ціновими кривими:

- **Волатильні пули**: використовують формулу сталого добутку `(x × y = k)` для таких активів, як BTC/USDC, оптимізовану для визначення ціни між некорельованими активами.
- **Стабільні пули**: використовують спеціальну криву stable swap `(x³y + y³x ≥ k)` для подібних активів, як-от MUSD/USDC, призначену мінімізувати прослизання під час обміну між токенами з близькою вартістю.

Ціни визначаються співвідношенням токенів у кожному пулі й автоматично оновлюються з кожною угодою.  

### Прослизання

Прослизання виникає, коли фактична ціна обміну відрізняється від заявленої через одну з причин:

- Інші угоди виконуються раніше за вашу
- Брак ліквідності для вибраних активів

Під час використання Mezo Swap ви можете встановити максимально допустиме прослизання (за замовчуванням: 0,5% для стабільних пар, 1% для волатильних пар).

![Приклад прослизання](/docs/images/mainnet/slippage-example.png)

Якщо ринкові умови зміняться понад ваш допуск, транзакцію буде скасовано, щоб захистити вас від невигідних угод. Великі угоди матимуть більше прослизання через їхній вплив на ціну в пулі.

Щоб переглянути загальну доступну ліквідність, перейдіть до [Mezo Pools](https://mezo.org/explore/pools), де ви знайдете всі пули з відповідною статистикою, зокрема загальну ліквідність (TVL).

## Комісії

- **Комісії протоколу**: 0,02% для стабільних пулів, 0,3% для волатильних пулів (сплачуються постачальникам ліквідності)
- **Комісії мережі**: стандартна плата за газ для виконання транзакції обміну ончейн

Коли ви переглядаєте попередні дані обміну в застосунку Mezo, ви бачите відповідні комісії, прослизання, витрати мережі та курс обміну.
