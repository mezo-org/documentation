Вузли Mezo — ключові компоненти мережі з повністю відкритим кодом. [Mezo Validator Kit](./validator-kit) встановлює [клієнт mezod](https://github.com/mezo-org/mezod) та інші компоненти, потрібні для запуску вузла як валідатора, RPC-вузла або seed-вузла. Набір спрощує кілька варіантів розгортання, як-от Docker, нативний демон і Helm для Kubernetes.

- Див. [mezod](https://github.com/mezo-org/mezod) на GitHub.
- Використовуйте [Validator Kit](./validator-kit), щоб запустити власний локальний seed-вузол.

## Вимоги до обладнання

Вимоги до обладнання відрізняються залежно від типу вузла. Мінімальні вимоги для кожного типу вузла наведено в розділі [Вимоги до обладнання](./validator-kit#вимоги-до-обладнання).

## Валідатори

Валідатори Mezo запускають вузли, які перевіряють транзакції, пропонують і засвідчують нові блоки та беруть участь у механізмі консенсусу. Перш ніж їхні вузли зможуть працювати як валідатори, валідатори Mezo мають подати заявку на [Proof of Authority (PoA)](./validator-kit#налаштування-валідатора).

Схвалені валідатори можуть дізнатися, як запустити вузол-валідатор, з інструкцій до [Validator Kit](./validator-kit).

## RPC-вузли

RPC-вузли можна використовувати, щоб створити локальний ендпоінт для розробки або як частину платформи блокчейн-інфраструктури як послуги (IaaS). Процес налаштування seed-вузла такий самий, як і для вузла-валідатора, але запитувати Proof of Authority (PoA) не потрібно.

Щоб запустити RPC-вузол, виконайте інструкції з посібника з налаштування [Validator Kit](./validator-kit), але застосуйте додаткові кроки конфігурації, описані в розділі налаштування [RPC-вузла](./validator-kit#налаштування-rpc-вузла).

## Seed-вузли

Seed-вузли допомагають вузлам мережі знаходити пірів. Процес налаштування seed-вузла такий самий, як і для вузла-валідатора, але запитувати Proof of Authority (PoA) не потрібно.

Щоб запустити seed-вузол, виконайте інструкції з посібника з налаштування [Validator Kit](./validator-kit), але пропустіть подання заявки на PoA і задайте параметру `p2p.seed_mode` у файлі config.toml вузла значення `true`. Докладніше див. у розділі [Network seed nodes](https://github.com/mezo-org/validator-kit?tab=readme-ov-file#network-seed-nodes).
