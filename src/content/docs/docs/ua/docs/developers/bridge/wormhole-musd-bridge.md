Міст MUSD працює на основі протоколу Wormhole Native Token Transfer (NTT), який забезпечує безпечні крос-чейн перекази зі збереженням взаємозамінності токенів. Докладніше про міст MUSD див. на сторінці [MUSD Bridge](/docs/ua/docs/users/borrow/musd-bridge).
