Усі активи Mezo (BTC, MEZO і токени контрактів у Mainnet) додано до списку дозволених у контракті PoolsVoter. Тепер будь-хто може створювати gauges для голосування для пулів, обидва активи яких є в цьому списку.

Повний перелік адрес токенів зі списку дозволених, які можна додавати як стимули до gauges, наведено в [довіднику контрактів](/docs/ua/docs/users/resources/contracts-reference#адреси-контрактів-portal).

## Створення gauge для пулу

1. Відкрийте [контракт PoolsVoter в Mezo Explorer](https://explorer.mezo.org/address/0x48233cCC97B87Ba93bCA212cbEe48e3210211f03) і під'єднайте гаманець.

2. Відкрийте вкладку **Contract**, виберіть **Write proxy**, а потім — `createPoolGauge`.

3. Як параметр `_poolFactory` використайте одну з таких адрес:
   - **Базові пули:** `0x83FE469C636C4081b87bA5b3Ae9991c6Ed104248`
   - **CL-пули:** `0xBB24AF5c6fB88F1d191FA76055e30BF881BeEb79`

4. Введіть адресу пулу в поле `_pool`.

5. Виконайте транзакцію. Якщо пул є в огляді пулів, він також має з'явитися в інтерфейсі голосування.
