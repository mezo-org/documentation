Mezo로 네이티브 비트코인을 입금하면 보통 약 1.5시간 이내에 자금이 표시됩니다. 입금은 계정에 도착하기 전에 다음 여러 단계를 거칩니다.

1. **온체인 컨펌** — 비트코인 트랜잭션이 비트코인 네트워크에서 컨펌되어야 합니다(입금 금액에 따라 1–6회의 컨펌 필요).
2. **브리지 공개(reveal)** — 컨펌되면 tBTC 봇이 입금을 감지하여 tBTC 브리지에 공개합니다. 보통 빠르게 진행되지만, 드물게 최대 5시간이 걸릴 수 있습니다.
3. **이더리움에서 발행** — tBTC 브리지가 입금을 처리하고 이더리움에서 tBTC를 발행합니다. 보통 약 1–1.5시간이 걸립니다.
4. **Mezo로 브리지** — tBTC가 발행되면 Mezo로 브리지되어 BTC가 계정에 도착합니다. 약 15–20분이 걸립니다.

드문 예외적인 경우에는 이 과정이 더 오래 걸릴 수 있습니다.

## 입금 상태 확인 방법

1시간 30분이 지나도 입금이 Mezo에 표시되지 않으면 tBTC 브리지용 제3자 블록 탐색기인 [tbtcscan](https://tbtcscan.com/)에서 상태를 확인할 수 있습니다.

![tBTCScan 입금 검색 인터페이스](/docs/images/tbtc/tbtc1.webp)

<Steps>
1. **트랜잭션 ID 찾기** – 지갑이나 지갑 기록에서 비트코인 트랜잭션 해시를 찾으세요.

2. **tBTCScan의 Deposits 탭 방문하기** – 이 제3자 도구는 실시간 브리지 입금 데이터를 보여 줍니다.

3. **트랜잭션 검색하기** – 검색창에 트랜잭션 해시를 입력하세요.

4. **상태 확인하기:**
   - **결과 없음** → 입금이 아직 브리지에 공개되지 않았습니다. 보통 온체인 컨펌 후 20분 이내에 공개되지만, 드물게 최대 5시간이 걸릴 수 있습니다.
   - **MINTING IN PROGRESS** → 입금이 공개되었고 이더리움에서 tBTC가 발행되는 중입니다. 보통 약 1–1.5시간이 걸립니다.
   - **MINTING FINALIZED** → 이더리움에서 tBTC 발행이 완료되었습니다. 15–20분 이내에 Mezo 계정에 입금이 표시되는 것이 정상입니다.
</Steps>

:::tip
tBTCScan에서 연속으로 검색할 때 새 결과를 표시하려면 검색할 때마다 페이지를 새로 고쳐야 합니다.
:::

![tBTCScan 입금 상태 결과](/docs/images/tbtc/tbtc2.webp)

## 입금이 표시되지 않으면 어떻게 하나요?

tbtcscan에 MINTING FINALIZED로 표시되었는데도 15분이 지나도록 Mezo 계정에 입금이 표시되지 않거나, 5시간이 지나도 tbtcscan에 결과가 없다면 [Mezo Discord](https://discord.gg/mezo)에서 티켓을 열어 다음 정보와 함께 지원팀에 문의하세요.

- 트랜잭션 해시
- Mezo 로그인에 사용하는 계정의 주소(또는 Mezo 계정 ID)
