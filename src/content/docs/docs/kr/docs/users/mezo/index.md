MEZO는 Mezo의 네이티브 토큰입니다. 인센티브의 방향에 영향을 미치고 체인이 창출하는 가치를 포착합니다.

## MEZO란?

MEZO는 Mezo 네트워크의 전략적 조정 자산 역할을 합니다. 순수한 담보로서 BTC가 하는 역할을 대체하지 않으며, 비트코인 활동이 창출하는 가치를 증폭하고 그 방향에 영향을 미칩니다.

MEZO의 용도는 다음과 같습니다.

- **투표력 부스트** — MEZO를 veMEZO로 잠가 veBTC 투표 가중치를 최대 5x까지 높이세요
- **리베이스 보상 획득** — veMEZO 보유자는 주간 에미션에서 희석 방지 리베이스를 받습니다

## MEZO와 veMEZO 비교

|  | MEZO | veMEZO |
|---|---|---|
| 정의 | 유동성이 있고 전송 가능한 토큰 | 잠긴 MEZO를 나타내는 NFT |
| 획득 방법 | 구매, 수익 획득 또는 에어드롭 수령 | MEZO를 1주~4년 동안 잠금 |
| 용도 | 보유 또는 거래 | veBTC 투표력 부스트, MEZO Gauges 투표, 리베이스 획득 |

## 주요 특성

- **두 가지 역할** — veMEZO는 스테이킹 게이지에서 veBTC 가중치를 곱하는 동시에, [veBTC 부스트 게이지](/docs/kr/docs/users/mezo-earn/lock/vemezo/matching-market)와 [MEZO Gauges](/docs/kr/docs/users/mezo-earn/vote/mezo-gauges)에서 독자적으로 투표합니다. 자체 거버넌스 가중치는 없습니다.
- **단독 스테이킹 게이지 투표 불가** — veMEZO는 veBTC 없이 스테이킹 게이지에 투표할 수 없습니다.
- **시간 가중** — 잠금 기간이 길수록 veMEZO 가중치가 높아집니다
- **NFT로 전송 가능** — veMEZO 포지션은 전송하거나 병합할 수 있는 ERC-721 NFT입니다
