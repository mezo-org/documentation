Mezo Passport에서 바로 Mezo의 다른 사용자에게 자산을 보낼 수 있습니다. 받는 사람은 지갑 주소, 비트코인 주소 또는 Mezo ID로 지정할 수 있습니다.

:::note
Passport를 통해 자산을 보내면 Mezo에서 토큰이 전송되며, 비트코인 네트워크로 자산이 전송되지는 않습니다. Mezo 밖으로 자산을 브리지하려면 [브리지](/docs/kr/docs/users/mainnet/bridges)를 참조하세요.
:::

## 받는 사람 유형

Mezo Passport의 보내기 양식은 세 가지 유형의 받는 사람을 지원합니다.

- **지갑 주소** — Mezo의 표준 `0x…` 주소를 입력하세요.
- **비트코인 주소** — 비트코인 주소를 입력하세요. Mezo가 이를 Mezo 네트워크의 해당 지갑으로 자동 변환합니다.
- **Mezo ID** — Mezo ID를 입력하세요. 변환된 지갑 주소가 입력 필드 아래에 표시되므로 보내기 전에 받는 곳을 확인할 수 있습니다.

비트코인 주소나 Mezo ID를 입력하면 변환된 `0x…` 지갑 주소가 확인 단계로 입력 필드 아래에 표시됩니다. 계속 진행하기 전에 항상 이 주소를 확인하세요.

## 자산 보내기

<Steps>
1. [Mezo App](https://mezo.org/overview)을 열고 로그인하세요.

2. 페이지 상단에서 **Passport** 드롭다운을 여세요.

3. **Send**를 클릭해 보내기 양식을 여세요.

4. 받는 사람의 지갑 주소, 비트코인 주소 또는 Mezo ID를 입력하세요.

5. 비트코인 주소나 Mezo ID를 입력했다면 입력 필드 아래에 표시된 변환된 지갑 주소를 확인하세요.

6. 자산을 선택하고 보낼 금액을 입력하세요. 금액 옆에 실시간 USD 환산 금액이 표시됩니다.

7. 트랜잭션 세부 정보를 검토하고 **Send**를 클릭해 확정하세요.
</Steps>

트랜잭션이 완료되면 "Transaction sent" 메시지와 [Mezo Explorer](https://explorer.mezo.org)에서 트랜잭션을 볼 수 있는 링크가 포함된 확인 화면이 표시됩니다. **Done**을 클릭하면 앱으로 돌아갑니다.
