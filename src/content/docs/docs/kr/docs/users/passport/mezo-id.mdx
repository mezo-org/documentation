Mezo ID는 Mezo 네트워크의 지갑에 연결된, 사람이 읽을 수 있는 식별자입니다. 사용자는 전체 `0x…` 지갑 주소를 공유하는 대신 Mezo ID를 공유해 자산을 받을 수 있습니다.

## 작동 방식

누군가 [보내기 양식](/docs/kr/docs/users/passport/send-assets)에 사용자의 Mezo ID를 입력하면 Mezo가 이를 자동으로 해당 지갑 주소로 변환합니다. 변환된 주소는 확인 단계로 표시되므로 보내는 사람은 트랜잭션을 완료하기 전에 받는 곳을 확인할 수 있습니다.

비트코인 주소를 입력할 때도 같은 변환 과정이 적용되며, Mezo는 이를 네트워크상의 연결된 지갑에 매핑합니다.

## Mezo ID 사용하기

- **자산 받기** — 전체 지갑 주소 대신 Mezo ID를 다른 Mezo 사용자와 공유하세요.
- **자산 보내기** — Passport의 보내기 양식에 받는 사람의 Mezo ID를 입력하세요. 확정하기 전에 변환된 지갑 주소를 확인하세요.
