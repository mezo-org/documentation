## 토큰 컨트랙트

Mezo Explorer에서 다음 토큰을 지갑에 추가할 수 있습니다. 탐색기에서 토큰 주소를 열고 MUSD 토큰 주소 옆에 있는 **Add token to MetaMask** 버튼을 클릭하세요.

일부 토큰 컨트랙트는 `TransparentUpgradableProxy` 컨트랙트입니다. 이 경우 프록시 뒤에 있는 토큰 주소가 아니라 프록시 주소를 브라우저 지갑에 수동으로 추가하세요. 예를 들어 MetaMask에서는 [토큰 가져오기](https://support.metamask.io/manage-crypto/portfolio/how-to-import-a-token-in-metamask-portfolio/) 안내를 따르세요. 이러한 토큰은 해당 토큰으로 첫 전송과 승인을 완료하기 전까지 [Mezo Explorer](https://explorer.mezo.org/)의 EOA에 표시되지 않습니다.

### MUSD 토큰 및 브리지

MUSD 브리지는 Wormhole의 Native Token Transfer(NTT) 프로토콜로 구동되며, 토큰의 대체 가능성을 유지하면서 안전한 크로스체인 전송을 지원합니다. NTT를 사용하면 소스 체인에서 토큰을 잠그고 대상 체인에서 발행하거나, 다시 브리지할 때 토큰을 소각하고 잠금 해제할 수 있습니다. 토큰을 브리지하려면 [Portal UI](https://portalbridge.com/)를 사용하세요.

NTT에 대한 자세한 내용은 [Wormhole 공식 문서](https://wormhole.com/docs/products/native-token-transfers/overview/)를 참조하세요.

### MUSD Monitor로 대출 상태 확인하기
더 자세히 모니터링하려면 [mezotools.cc](https://mezotools.cc)를 사용할 수 있습니다.

- Trove 상태와 담보 비율을 실시간으로 확인합니다.
- 시스템 전체의 최근 환매 및 청산 내역을 조회합니다.
- Mezo 온체인 오라클에서 BTC 및 MUSD 가격을 직접 추적합니다.
