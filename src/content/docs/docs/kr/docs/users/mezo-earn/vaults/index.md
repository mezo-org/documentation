Mezo 볼트는 자산을 DeFi 전반에 투입하여 수익을 창출하는 전략입니다. 볼트에 예치하고, 포지션을 나타내는 영수증 토큰을 받은 다음, 전략 운용자가 수익을 최적화하도록 맡기세요.

이용 가능한 볼트는 [mezo.org/earn/vaults](https://mezo.org/earn/vaults)에서 확인하세요.

---

## 볼트의 작동 방식

1. **볼트 선택** — Mezo에서 이용 가능한 볼트를 살펴보세요. 볼트마다 전략과 수익원이 다릅니다
2. **자산 예치** — 필요한 토큰(예: MUSD, BTC)을 볼트에 예치하세요
3. **영수증 토큰 수령** — 볼트에서 내 지분을 나타내는 토큰을 받습니다
4. **전략 운용자의 최적화** — 볼트 전략 운용자가 설명된 전략에 따라 자산을 투입하여 수익을 창출합니다
5. **수익 얻기** — 수익을 누적하고, 원하는 경우 스테이킹하여 추가 보상을 얻으세요

## 볼트 테이블 이해하기

| 열 | 의미 |
|--------|---------------|
| **Vault** | 볼트 전략의 이름과 설명 |
| **TVL** | 총 예치 자산(Total Value Locked) — 볼트에 예치된 총 자산 |
| **APY** | 연간 수익률(Annual Percentage Yield) — 예상 연간 수익 |
| **Reward** | 볼트에서 얻는 토큰 |
| **Strategist** | 볼트 전략을 관리하는 팀 또는 프로토콜 |

## 볼트 유형

### Mezo 볼트

[MUSD Savings Vault](/docs/kr/docs/users/mezo-earn/vaults/musd-savings-vault)와 [USDC Lending Vault](/docs/kr/docs/users/mezo-earn/vaults/usdc-lending-vault)처럼 Mezo가 만들고 관리하는 볼트입니다.

### 외부 볼트

[Ditto MUSD Savings Vault](/docs/kr/docs/users/mezo-earn/vaults/ditto-musd-savings-vault)는 Mezo에서 MUSD를 받고 dMUSD를 발행합니다. Ditto Network가 스왑, 브리지, 그리고 이더리움의 Spark Savings에 대한 초기 배분을 처리합니다. 환매 시 Mezo에서 MUSD가 반환되며, 환매는 비동기적으로 처리됩니다.

파트너 프로토콜(예: August, UWI, Upshift)이 만든 볼트는 자체 전략에 자산을 투입합니다. 이러한 볼트는 볼트 페이지에 추천 배너로 표시될 수도 있으며, 예치를 위해 파트너 플랫폼으로 연결됩니다.

## 위험

### 전략 위험
볼트마다 자산을 투입하는 방식이 다릅니다. 예치하기 전에 기본 전략을 이해하세요. 일부 전략은 다른 전략보다 위험이 더 큽니다.

### 스마트 컨트랙트 위험
볼트는 여러 스마트 컨트랙트와 상호작용합니다. Mezo 볼트는 감사를 받았지만, 모든 스마트 컨트랙트에는 고유한 위험이 있습니다. 감당할 수 있는 금액만 예치하세요.

### 외부 볼트 위험
외부 볼트는 서드파티 프로토콜이 관리합니다. Mezo는 이러한 전략을 통제하지 않습니다. 예치하기 전에 파트너의 문서와 감사 보고서를 검토하세요.
