## 수수료

[Mezo Pools](https://mezo.org/explore/pools)는 거래 쌍별로 최적화된 동적 수수료 모델을 사용합니다.

### 표준 수수료율

- **변동성 풀**: 0.30%
- **스테이블 풀**: 0.02%

### 맞춤 풀 수수료

일부 풀에는 거버넌스가 설정한 맞춤 수수료율이 적용될 수 있습니다. 이러한 특별 수수료율은 일반적으로 다음에 적용됩니다.

- **전략적 파트너십 풀**
- **출시 기간 중 프로모션 풀**
- **거래량이 많은 기관 거래 쌍**

### 수수료 징수 방식

트레이더가 Mezo Pool에서 스왑을 실행하면 다음과 같이 진행됩니다.

1. **수수료 차감**: 수수료가 입력 토큰 금액에서 자동으로 차감됩니다.
   - 예: 스테이블 풀에서 1,000 MUSD를 스왑하면 수수료로 0.2 MUSD가 차감됩니다.
2. **즉시 분리**: 징수된 수수료는 전용 PoolFees 컨트랙트로 즉시 이전됩니다.
   - 수수료는 풀의 핵심 유동성 준비금과 절대 섞이지 않습니다

### 수수료는 어떤 토큰으로 지불되나요?

수수료는 항상 각 스왑에서 판매되는 토큰(입력 토큰)으로 징수됩니다. LP는 쌍을 이루는 두 토큰 모두로 수수료를 얻습니다.

- 트레이더가 Token A → Token B로 스왑하면 수수료는 Token A로 징수됩니다
- 트레이더가 Token B → Token A로 스왑하면 수수료는 Token B로 징수됩니다
- 풀 지분에 따라 두 토큰 모두로 수수료가 누적되며 청구할 수 있습니다

예: MUSD/tBTC 풀의 경우

- 트레이더가 MUSD → BTC로 스왑: MUSD가 수수료로 징수됩니다(모든 LP 대상)
- 트레이더가 BTC → MUSD로 스왑: BTC가 수수료로 징수됩니다(모든 LP 대상)
- LP는 MUSD 수수료와 BTC 수수료 모두에서 몫을 얻습니다

### 수수료 청구하기

1. Mezo Pools 인터페이스에서 내 포지션으로 이동하세요
2. "Claim Fees"를 클릭하세요
3. 트랜잭션을 확인하세요
4. 수수료가 지갑으로 바로 전송됩니다

### 수수료 계산 예시

#### 예시 1: 변동성 풀(BTC/MUSD)

- **일일 거래량**: $1,000,000
- **수수료율**: 0.30%
- **일일 발생 수수료**: $3,000
- **내 지분**: 풀의 5%
- **내 일일 수수료**: 약 $150

#### 예시 2: 스테이블 풀(MUSD/USDC)

- **일일 거래량**: $5,000,000
- **수수료율**: 0.02%
- **일일 발생 수수료**: $1,000
- **내 지분**: 풀의 2%
- **내 일일 수수료**: 약 $20

### 자주 묻는 질문

#### 수수료는 어떤 통화/토큰으로 지불되나요?
수수료는 각 스왑의 입력 토큰(판매되는 토큰)으로 지불됩니다. USDC/MEZO 풀에서 USDC → MEZO 스왑은 USDC 수수료를, MEZO → USDC 스왑은 MEZO 수수료를 발생시킵니다. LP는 두 토큰 모두로 수수료가 누적되며 이를 청구합니다.

#### 누적된 수수료를 잃을 수도 있나요?
아니요. 수수료는 PoolFees 컨트랙트에 별도로 보관되며 LP 토큰 보유자만 청구할 수 있습니다.

#### 수수료가 자동으로 복리 적용되나요?
아니요. 복리 효과를 얻으려면 수수료를 직접 청구하고 다시 예치해야 합니다.
