투표를 통해 에미션의 흐름을 지정할 수 있으며, 그 대가로 투표를 배분한 게이지에서 발생하는 거래 수수료와 인센티브를 비례하여 나눠 받습니다. 이 가이드에서는 전체 과정을 단계별로 안내합니다.

## 사전 요구 사항

시작하기 전에 다음을 갖추었는지 확인하세요.

- Mezo에 연결된 호환 지갑(MetaMask, Rabby 또는 WalletConnect를 지원하는 지갑)
- 활성 veBTC 포지션(스테이킹 게이지에 투표하는 경우)
- 또는 활성 veMEZO 포지션(veBTC 부스트 게이지에 투표하는 경우)
- 가스 수수료로 사용할 충분한 BTC

아직 veBTC 잠금이 없다면 [BTC 잠금 방법](/docs/kr/docs/users/mezo-earn/lock/vebtc/how-to-lock-btc)을 참조하세요.

veMEZO 포지션을 만들려면 [MEZO 잠금 방법](/docs/kr/docs/users/mezo-earn/lock/vemezo/how-to-lock-mezo)을 참조하세요.

## veBTC로 투표하기

veBTC 보유자는 스테이킹 게이지에 투표하여 에미션을 지정하고 수수료를 얻습니다.

### 투표하기

보상을 얻으려면 투표력을 특정 게이지에 배분하세요. 배분은 변경하기 전까지 에포크(각 7일)가 바뀌어도 그대로 유지됩니다.

<Steps>
1. **Vote** 탭에서 활성 veBTC 포지션을 확인하세요. 투표에 사용할 veBTC 포지션 옆의 **Allocate**를 클릭하세요.

2. 지원하려는 게이지마다 배분할 투표력의 비율을 입력하세요. 예를 들어 BTC/MUSD 풀에 50%, MUSD/mUSDC 풀에 30%, mcbBTC/BTC 풀에 20%를 배분할 수 있습니다.

3. 배분 내용을 검토하고 준비가 되면 오른쪽 사이드바에서 **Submit Votes**를 클릭하세요. 트랜잭션에 서명하면 완료 후 현재 에포크에 투표가 등록됩니다.
</Steps>

:::note[기억하세요]
각 잠금은 에포크당 한 번만 투표할 수 있습니다. 투표가 컨펌되면 다음 에포크 전환까지 배분이 고정됩니다. 배분은 에포크가 바뀌어도 유지되며, 변경하거나 초기화하기 전까지 계속 수수료와 인센티브를 얻습니다.
:::

## veMEZO로 투표하기

veMEZO 보유자는 veBTC 부스트 게이지에 투표하여 인센티브를 받는 대가로 BTC 포지션에 부스트를 제공하고, [MEZO Gauges](/docs/kr/docs/users/mezo-earn/vote/mezo-gauges)에 투표하여 Mezo 외부의 MUSD 풀로 MEZO 에미션을 지정합니다. 두 투표는 서로 독립적입니다. 해당 흐름은 [MEZO Gauges에서 투표하는 방법](/docs/kr/docs/users/mezo-earn/vote/mezo-gauges/how-to-vote)을 참조하세요.

### 부스트 게이지에 투표하기

<Steps>
1. **Boost Gauges** 섹션으로 이동하여 부스트를 원하는 모든 veBTC 포지션을 확인하세요.

2. 각 게이지에서 다음 항목을 검토하세요.
   - 현재 게시된 인센티브
   - 해당 게이지에 이미 지정된 veMEZO 수량
   - 내 veMEZO 배분에 따른 예상 수익

3. 각 부스트 게이지에 지정할 veMEZO 투표력의 비율을 입력하세요.

4. **Submit Votes**를 클릭하고 트랜잭션에 서명하세요.
</Steps>

### 얻는 보상

veMEZO 투표를 부스트 게이지에 지정하면 다음과 같습니다.

- 해당 게이지에 게시된 인센티브를 veMEZO 투표 지분에 비례하여 나눠 받습니다
- veBTC 보유자는 부스트를 받아 유효 투표력이 증가합니다

참고: veMEZO 투표자는 자신이 부스트하는 veBTC 포지션에서 발생하는 거래 수수료, MUSD 수익, 브리지 수수료를 받지 **않습니다**. 이러한 보상은 veBTC 보유자에게 돌아갑니다. veMEZO 투표자는 부스트 게이지에 명시적으로 게시된 인센티브만 얻습니다.

## 부스트 극대화하기(veBTC 보유자용)

veBTC와 veMEZO를 모두 보유하고 있다면 투표력을 극대화할 수 있습니다.

### 옵션 1: 셀프 부스트

veMEZO 투표를 내 veBTC 포지션의 부스트 게이지에 지정하세요.

<Steps>
1. 내 veBTC 포지션의 부스트 게이지로 이동하세요
2. veMEZO 투표력을 해당 게이지에 배분하세요
3. **Submit Votes**를 클릭하세요
4. veBTC 포지션에 **Poke**를 실행하여 새 부스트를 활성화하세요
</Steps>

### 옵션 2: 외부 부스트 유치하기

veBTC 부스트 게이지에 인센티브를 게시하여 다른 사용자의 veMEZO 투표를 유치하세요.

<Steps>
1. 내 veBTC 포지션의 부스트 게이지로 이동하세요
2. **Add Incentives**를 클릭하세요
3. 토큰(모든 ERC-20 토큰)을 인센티브로 예치하세요
4. veMEZO 보유자가 인센티브를 보고 투표를 지정할 수 있습니다
5. 새 veMEZO 투표를 받은 후 포지션에 **Poke**를 실행하세요
</Steps>

## 중요: 변경 후 Poke 실행

veMEZO 상황이 바뀌어도 부스트는 자동으로 업데이트되지 않습니다. veBTC 포지션에 **Poke**를 실행하여 부스트된 가중치를 갱신해야 합니다.

**Poke가 필요한 경우:**
- 부스트 게이지에 새 veMEZO 투표를 받은 경우
- 내 veMEZO를 내 포지션에 지정한 경우
- veMEZO 리베이스 배분을 청구한 경우
- veMEZO 잠금을 연장한 경우

**Poke 방법:**
1. 내 veBTC 포지션으로 이동하세요
2. **Poke**를 클릭하세요
3. 트랜잭션에 서명하세요

새로운 부스트된 가중치가 즉시 적용됩니다.
