## 자주 묻는 질문

**BTC 잠금을 조기에 해제할 수 있나요?**

아니요. 잠금은 만료될 때까지 해제할 수 없습니다. 잠금 기간을 신중하게 선택하세요.

**투표하지 않으면 어떻게 되나요?**

게이지에서 수수료나 에미션을 받지 못합니다. 하지만 모든 veBTC 보유자에게 분배되는 브리지 수수료는 계속 받습니다.

**veBTC 포지션을 여러 개 보유할 수 있나요?**

네. 잠글 때마다 별도의 veBTC NFT가 생성됩니다. 원하면 나중에 병합할 수 있습니다.

**잠긴 BTC를 담보로 사용할 수 있나요?**

아니요. 기초 BTC의 잠금을 해제하지 않는 한 veBTC NFT는 Mezo의 MUSD 대출 시스템에서 담보로 사용할 수 없습니다.
