veBTC는 Mezo 네트워크에 잠긴 BTC를 토큰화(NFT)한 것입니다. BTC를 잠그면 거버넌스 권한과 프로토콜 수수료의 일부를 받습니다.

## veBTC란?

Mezo에서 BTC를 잠그면 잠긴 포지션을 나타내는 veBTC NFT를 받습니다. 이 NFT가 제공하는 혜택은 다음과 같습니다.

- 생태계 전반의 에미션 배분을 결정하는 **투표력**
- 체인 활동과 브리지에서 발생하는 **프로토콜 수수료**
- Mezo의 경제적 미래를 만들어 가는 **거버넌스 권한**

---

## 투표력의 작동 방식

veBTC 가중치는 두 가지 요소, 즉 잠긴 BTC의 양(BTC가 많을수록 투표력이 커짐)과 잠금 기간(잠금 기간이 길수록 더 높은 가중치가 유지됨)에 따라 결정됩니다.

투표력은 시간이 지남에 따라 선형적으로 감소합니다. 1 BTC를 28일 동안 잠근 사용자는 1 veBTC로 시작하며, 14일 후에는 0.5로 감소하고 만료 시점에 0이 됩니다. 잠금은 언제든지 연장하여 최대 투표력을 유지할 수 있습니다.

### 잠금 매개변수

| 매개변수 | 값 |
|-----------|-------|
| 최소 잠금 | 1일 |
| 최대 잠금 | 28일 |
| 잠금 감소 | 선형 — 가중치가 0이 될 때까지 계속 감소 |

## 얻을 수 있는 수익

### 패시브 수익(모든 veBTC 보유자)

모든 veBTC 보유자는 투표 가중치에 비례하여 **체인 및 브리지 수수료**의 일부를 자동으로 받습니다. 이는 veBTC를 보유하기만 하면 쌓이는 패시브 수익이며, 투표할 필요가 없습니다.

### 액티브 수익(투표 필요)

[게이지에 투표](/docs/kr/docs/users/mezo-earn/vote)하면 투표 배분에 따라 추가 보상을 받습니다.

- 투표한 풀에서 발생하는 **스왑 수수료**(LP가 해당 게이지에 스테이킹한 경우)
- MUSD Savings Rate 게이지에 투표한 경우 **MUSD 이자/수수료 수익**
- 프로토콜이나 사용자가 특정 게이지로 투표를 유도하기 위해 제공하는 **인센티브**

게이지에 배분하는 투표 가중치가 클수록 해당 게이지의 수수료와 인센티브에서 받는 몫도 커집니다.

:::note[중요]
투표 배분은 에포크가 바뀌어도 유지되며 변경할 때까지 계속 수익을 얻습니다. 매주 다시 투표할 필요가 없습니다. 아래 [에포크](#에포크)를 참조하세요.
:::

## 에포크

Mezo Earn은 **에포크라고 하는 7일 주기**로 운영됩니다. 각 에포크는 목요일 00:00 UTC에 시작됩니다.

### 에포크가 중요한 이유

- **투표는 유지됩니다.** 투표 배분은 변경하거나 초기화할 때까지 에포크가 바뀌어도 그대로 이어집니다. 각 잠금은 에포크당 한 번만 투표할 수 있으므로, 확정된 배분은 다음 에포크 전환 전까지 변경할 수 없습니다.
- **에포크 N에 행사한 투표**가 에포크 N+1의 에미션 배분을 결정합니다
- **에포크 N에 발생한 수수료**는 에포크 N에 행사한 투표를 기준으로 분배됩니다

### 잠금 기간과 에포크 정렬

잠금 기간은 달력상의 날짜가 아니라 에포크 경계에 맞춰 정렬됩니다. 잠금을 생성하면 **잠금 기간이 가장 가까운 전체 주 단위로 내림 처리됩니다**.

즉, 다음과 같습니다.

- 에포크 중간에 생성한 28일 잠금은 잠그는 시점에 따라 실제 기간이 약 21–28일이 됩니다
- 잠금은 항상 에포크 전환 시점(목요일 00:00 UTC)에 만료됩니다

**예시:** 에포크 중간에 최대 28일 잠금을 선택하면, 해당 주의 남은 시간을 기준으로 실제 잠금 기간이 줄어들어 잠그는 시점에 따라 약 21–28일의 잠금이 됩니다.

이러한 정규화를 통해 모든 잠금이 에포크 경계에서 깔끔하게 만료되며, 시스템 전반의 투표 가중치 계산이 단순해집니다.

| 에포크 매개변수 | 값 |
|-----------------|-------|
| 기간 | 7일 |
| 시작 시간 | 목요일 00:00 UTC |
| 잠금 정렬 | 전체 주 단위로 내림 처리 |
