## 사전 요구 사항

BTC를 잠그기 전에 다음을 갖추었는지 확인하세요.

- Mezo에 입금된 BTC
- 연결된 지갑
- 가스 수수료로 쓸 충분한 BTC

자세한 안내는 [시작하기](/docs/kr/docs/users/getting-started/deposit-assets) 섹션을 참조하세요.

---

## Lock 페이지로 이동

<Steps>
1. Mezo App을 여세요

2. 왼쪽 사이드바("Earn" 아래)에서 **Lock**을 클릭하세요

3. 잠글 수 있는 자산이 표시됩니다
</Steps>

---

## 잠금 시작

사용 가능한 잔액이 표시된 BTC 자산 카드를 찾아 **Lock**을 클릭하세요. 포지션을 설정할 수 있는 잠금 설정 모달이 나타납니다.

**금액:** 잠글 BTC 금액을 입력하세요. 사용 가능한 잔액 한도 내에서 원하는 만큼 잠글 수 있습니다.

**기간:** 잠금 기간을 1일에서 28일 사이로 선택하세요. 잠금 기간이 길수록 높은 투표력이 더 오래 유지됩니다. 화면에는 예상 초기 veBTC 투표력이 표시되며, 이는 잠금이 시작될 때의 가중치를 나타냅니다.

:::note[참고]
잠금 기간은 에포크 경계에 맞춰 정렬되며 가장 가까운 전체 주 단위로 내림 처리됩니다. 에포크 중간에 최대 기간으로 잠그면 실제 기간은 21–28일이 됩니다. 자세한 내용은 [에포크](/docs/kr/docs/users/mezo-earn/lock/vebtc#에포크)를 참조하세요.
:::

## 트랜잭션 확인

잠금 세부 정보를 검토하세요.

- BTC 금액
- 잠금 기간
- 초기 veBTC 가중치
- 잠금 만료일

**Confirm Lock**을 클릭하고 지갑에서 트랜잭션을 승인한 다음 블록체인 컨펌을 기다리세요.

---

## 포지션 확인

컨펌이 완료되면 Lock 페이지에서 다음과 같은 잠금 세부 정보를 확인할 수 있습니다.

- 현재 투표력(시간이 지남에 따라 감소)
- 잠금 만료일
- 잠금 연장 옵션
