매칭 마켓은 veBTC와 veMEZO가 서로 짝을 이루는 방식입니다. BTC 보유자는 MEZO를 보유하지 않고도 부스트를 이용할 수 있고, MEZO 보유자는 많은 BTC를 보유하지 않고도 수익을 얻을 수 있습니다.

## 해결하는 문제

Mezo의 이중 토큰 시스템에서 투표력을 극대화하려면 veBTC와 veMEZO가 모두 필요합니다. 하지만 모든 사람이 둘 다 보유하고 있지는 않습니다.

- **BTC 비중이 큰 사용자**는 5x 부스트를 원하지만 MEZO가 없을 수 있습니다
- **MEZO 비중이 큰 사용자**는 veMEZO가 있지만 투표에 사용할 BTC가 부족합니다

매칭 마켓은 이 두 집단을 연결합니다.

---

## 작동 방식

모든 veBTC 포지션에는 고유한 부스트 게이지가 있습니다. 이 게이지는 에미션을 배분하지 않으며, 해당 veBTC 포지션이 받는 veMEZO 부스트의 양을 결정합니다.

### 흐름

1. **veBTC 보유자가 BTC를 잠급니다** → 부스트 게이지가 연결된 veBTC NFT를 받습니다
2. **veBTC 보유자가 인센티브를 게시합니다** → veMEZO 투표를 유치하기 위해 부스트 게이지에 토큰(모든 ERC-20 토큰)을 예치합니다
3. **veMEZO 보유자가 투표합니다** → 매력적인 부스트 게이지에 veMEZO 가중치를 배분합니다
4. **부스트가 적용됩니다** → 받은 veMEZO 투표에 따라 veBTC 포지션의 배수가 증가합니다
5. **인센티브가 청구됩니다** → veMEZO 투표자는 에포크가 끝나면 인센티브 중 자신의 몫을 청구합니다

## 시장의 양측

### BTC 비중이 큰 경우

부스트를 원하지만 MEZO가 충분하지 않습니다. 선택지는 다음과 같습니다.

- veBTC 게이지에 인센티브를 게시하여 veMEZO 투표를 유치합니다
- 직접 MEZO를 잠그는 대신 부스트 비용을 지불합니다
- 부스트의 시세는 시장이 결정합니다

### MEZO 비중이 큰 경우

veMEZO는 있지만 BTC가 부족합니다. 선택지는 다음과 같습니다.

- 인센티브가 충분한 veBTC 게이지에 투표하여 수익을 얻습니다
- 비용을 지불할 의향이 있는 BTC 보유자에게 서비스로 부스트를 제공합니다
- 많은 BTC 노출 없이도 MEZO로 수익을 얻습니다

---

## 중요한 이유

매칭 마켓은 부스트를 가격이 매겨지고 거래 가능한 서비스로 바꿉니다.

- **부스트에 시장 가격이 생깁니다.** 가격은 수요와 공급으로 결정됩니다
- **두 토큰을 모두 보유하지 않아도** 시스템의 혜택을 누릴 수 있습니다
- **자본 효율성이 향상됩니다.** BTC 보유자는 BTC에, MEZO 보유자는 MEZO에 집중할 수 있습니다

매칭 마켓이 없다면 사용자는 효과적으로 참여하기 위해 두 토큰을 비례적으로 보유해야 합니다. 매칭 마켓은 이러한 마찰을 없애 줍니다.

## 핵심 개념

| 용어 | 정의 |
|---|---|
| 부스트 게이지 | 각 veBTC NFT에 연결되어 veMEZO 투표를 받는 게이지 |
| 인센티브 | veMEZO 투표를 유치하기 위해 veBTC 보유자가 게시하는 토큰 |
| 부스트 제공자 | 인센티브를 받기 위해 다른 사람의 부스트 게이지에 투표하는 veMEZO 보유자 |
| 부스트 수요자 | veMEZO 투표를 유치하기 위해 인센티브를 게시하는 veBTC 보유자 |
