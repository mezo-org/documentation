import { Steps } from '@astrojs/starlight/components';

다른 사용자가 내 대출(Trove)을 대상으로 MUSD를 환매하여 대출이 전액 상환되면 부채는 정리되지만, 남은 담보는 청구할 때까지 MUSD 스마트 컨트랙트에 보관됩니다. 담보는 안전하며 언제든지 회수할 수 있습니다.

일반적으로 Borrow 페이지에 "Loan redeemed" 알림이 표시되며, 이를 통해 인터페이스에서 바로 담보를 청구할 수 있습니다. 아래 스크린샷과 같이 알림 오른쪽에 있는 버튼을 클릭하면 됩니다.

![Borrow 페이지의 Loan redeemed 알림](/docs/images/musd/loan-redeemed.webp)

이 알림이 보이지 않으면 Mezo Explorer에서 BorrowerOperations 컨트랙트의 `claimCollateral` 함수를 호출하여 직접 담보를 청구할 수 있습니다. 아래 단계를 따르세요.

<Steps>

1. **BorrowerOperations 컨트랙트로 이동하기**

   [Mezo Explorer의 BorrowerOperations 컨트랙트](https://explorer.mezo.org/address/0x44b1bac67dDA612a41a58AAf779143B181dEe031)로 이동하세요.

2. **"Contract" 탭 클릭하기**

   Transactions, Token transfers, Tokens와 나란히 있는 탭 막대에서 **Contract**를 클릭하세요.

   그러면 **Code**, **Read proxy**, **Write contract**, **Write proxy**의 네 가지 하위 탭이 나타납니다.

3. **"Write proxy" 클릭하기**

   **Write proxy** 탭을 클릭하세요. 이 탭에는 기반이 되는 BorrowerOperations 구현 컨트랙트의 모든 쓰기 함수가 표시됩니다.

   :::caution
   반드시 **Write proxy**("Write contract"가 아님)를 선택하세요. 프록시 탭에 실제 BorrowerOperations 로직이 반영됩니다.
   :::

4. **지갑 연결하기**

   컨트랙트 함수 영역 상단에 "Disconnected"라고 표시된 노란색/주황색 배너와 **Connect wallet** 버튼이 보입니다.

   **Connect wallet**을 클릭하고 지갑(예: MetaMask)에서 연결을 승인하세요. 해당 주소만 담보를 청구할 수 있으므로, 환매된 Trove를 보유했던 것과 같은 지갑 주소로 연결해야 합니다.

5. **claimCollateral 함수 찾기**

   컨트랙트 함수 목록을 아래로 스크롤하여 다음 항목을 찾으세요.

   **7. claimCollateral**

   클릭하여 함수를 펼치세요. 입력 파라미터가 필요 없으며, 전액 환매 후 내 주소에 따로 보관된 담보를 모두 청구합니다.

6. **"Write" 클릭하기**

   지갑이 연결된 상태에서 `claimCollateral` 함수 아래의 **Write** 버튼을 클릭하세요.

   지갑에서 트랜잭션을 확인하라는 메시지가 표시됩니다. 가스 수수료를 검토하고 확인하세요. 트랜잭션이 완료되면 담보(BTC)가 지갑으로 바로 전송됩니다.

</Steps>
