[MUSD](https://mezo.org/feature/musd) 브리지는 Wormhole의 Native Token Transfer(NTT) 프로토콜을 사용하여 Mezo, 이더리움, Base 네트워크 간의 전송을 지원합니다. 이 브리지는 안전한 크로스체인 기능을 제공하면서 토큰의 대체 가능성을 유지합니다.

## 작동 방식

MUSD 브리지는 Wormhole의 Native Token Transfer 프로토콜을 사용해 크로스체인 전송을 처리합니다.

- **Mezo에서 이더리움/Base로**: MUSD 토큰이 Mezo에서 잠기고, 대상 체인에서 같은 양의 토큰이 발행됩니다
- **이더리움/Base에서 Mezo로**: MUSD 토큰이 소스 체인에서 소각되고, Mezo에서 같은 양의 토큰이 잠금 해제됩니다

이 메커니즘은 사용자가 네트워크 간에 토큰을 자유롭게 옮길 수 있게 하면서도 모든 체인에 걸친 총 공급량이 일정하게 유지되도록 보장합니다.

## 브리지 옵션

MUSD 토큰을 브리지할 때 사용할 수 있는 사용자 인터페이스는 두 가지입니다.

### Mezo dApp

[Mezo dApp](https://mezo.org)은 Mezo와 이더리움 네트워크 간에 MUSD 토큰을 전송할 수 있는 네이티브 브리지 환경을 제공합니다.

<Steps>
1. Mezo dApp에 **지갑을 연결하세요**

2. Mezo에서 브리지하려면 **"Withdraw"를 클릭**하고, Mezo로 브리지하려면 **"Deposit"**을 클릭하세요

3. **MUSD 토큰을 선택**하고 금액을 입력하세요

4. 지갑에서 **트랜잭션을 확인하세요**

5. 양쪽 체인에서 **컨펌을 기다리세요**
</Steps>

### Portal Bridge UI

MUSD 토큰을 Base 또는 이더리움으로 브리지할 때는 [Portal UI](https://portalbridge.com/)를 사용할 수도 있습니다.

<Steps>
1. Portal 인터페이스에 **지갑을 연결하세요**

2. **소스 체인과 대상 체인을 선택하세요**(Mezo ↔ 이더리움 ↔ Base)

3. 브리지할 토큰으로 **MUSD를 선택하세요**

4. 브리지할 **금액을 입력하세요**

5. 수수료와 예상 소요 시간을 포함한 **트랜잭션 세부 정보를 검토하세요**

6. 지갑에서 **트랜잭션을 확인하세요**

7. 양쪽 체인에서 **컨펌을 기다리세요**
</Steps>

두 인터페이스 모두 기반 NTT 컨트랙트와의 복잡한 상호작용을 모두 처리하는 사용하기 쉬운 환경을 제공합니다.
