Mezo App에서 계정을 만들면 보상을 관리하고, 자산을 브리지하고, MUSD를 대출받아 발행하고, Mezo Market에 액세스할 수 있습니다.

<YouTube id="b7SnEPSZjFE" title="Mezo에서 계정을 만드는 방법" />

<Steps>
1. [Mezo App](https://mezo.org/overview)으로 이동하세요.

2. **Sign in** 버튼을 클릭하세요.

3. **Sign up**을 클릭하고 브라우저 지갑으로 로그인하세요. 이더리움 지갑을 사용하려면 로그인 창 하단의 **Sign in with Ethereum instead**를 클릭하세요.

4. 지갑을 연결하고 트랜잭션을 확인하여 가입 과정을 완료하세요.
</Steps>

로그인하고 트랜잭션에 서명하면 지갑이 계정에 연결됩니다. 다른 주소에서도 BTC를 브리지할 수 있지만, 계정은 연결된 지갑으로 관리됩니다.
