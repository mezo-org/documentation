**Get Gas** 기능을 사용하면 지갑에 BTC가 전혀 없더라도 Mezo에서 트랜잭션(가스) 수수료를 충당할 소량의 BTC를 얻을 수 있습니다. 이 기능은 **가스 없는 스왑**을 실행해 소량의 MUSD 또는 MEZO를 정확히 **0.0001 BTC**로 교환하며, 이는 네트워크에서 여러 트랜잭션을 처리하기에 충분한 양입니다.

스왑에 가스가 들지 않으므로(메타 트랜잭션 기반) 이 기능을 사용하는 데 BTC를 미리 보유하고 있을 필요가 없습니다.

## 언제 표시되나요?

지갑의 BTC 잔액이 **0.000001 BTC** 미만으로 떨어지면 Mezo App에 **"Get Gas"** 버튼이 자동으로 표시됩니다. 따라서 BTC를 추가로 브리지하거나 외부 거래소를 이용하지 않고도 언제든 가스를 충전할 수 있습니다.

## 지원 토큰

Get Gas 스왑에서 지원하는 토큰은 **MUSD**와 **MEZO**입니다. 즉, MEZO만 가지고 체인에 들어온 사용자도 추가 자산을 브리지할 필요 없이 무료 스왑으로 가스용 BTC를 받을 수 있습니다.

## 가스 받는 방법

<Steps>

1. **Get Gas 모달 열기**

   BTC 잔액이 부족하면 앱에 표시되는 **"Get Gas"** 버튼을 클릭하세요.

2. **토큰 선택**

   소스 토큰으로 MUSD 또는 MEZO를 선택하세요. 모달에 스왑 예상 비용이 표시됩니다.

3. **견적 검토**

   앱은 정확히 **0.0001 BTC**를 받는 데 필요한 MUSD 또는 MEZO 수량을 견적으로 제시합니다. 출력 수량이 고정되어 있으므로 토큰 가격과 관계없이 항상 예측 가능한 양의 가스를 받습니다.

4. **스왑 확인**

   **"Get Gas"**를 클릭해 스왑을 시작하세요. 지갑에서 다음 두 메시지에 서명하라는 요청이 표시됩니다.
   - **permit 서명**(토큰 승인)
   - **execute 서명**(스왑 권한 부여)

   이 서명에는 가스 수수료가 필요하지 않습니다.

5. **확인 대기**

   앱이 트랜잭션을 제출하고 확인 여부를 자동으로 조회합니다. 확인이 완료되면 트랜잭션 해시가 포함된 성공 화면이 표시됩니다.

</Steps>

## 작동 방식

Get Gas 기능은 **메타 트랜잭션**을 사용해 사용자에게 가스를 요구하지 않고 스왑을 실행합니다.

1. **Permit**: 선택한 토큰의 필요 수량을 릴레이가 사용할 수 있도록 허용하는 오프체인 메시지에 서명합니다.
2. **릴레이**: 백엔드 릴레이 서비스가 사용자를 대신해 스왑 트랜잭션을 제출하고 가스 비용을 부담합니다.
3. **스왑**: 트랜잭션이 온체인에서 실행되어 토큰이 **0.0001 BTC**로 스왑되며, 이 BTC는 지갑으로 바로 입금됩니다.

이러한 설계 덕분에 MUSD 또는 MEZO를 보유하고 있는 한 언제든 가스를 받을 수 있으며, 시작하는 데 BTC가 필요하지 않습니다.

## 주요 세부 정보

| 항목 | 값 |
|---|---|
| **출력 수량** | 0.0001 BTC (고정) |
| **사용 가능한 토큰** | MUSD, MEZO |
| **필요한 가스** | 없음 (메타 트랜잭션을 통한 가스 없는 방식) |
| **표시 조건** | BTC 잔액 0.000001 BTC 미만 |

:::note
MUSD 또는 MEZO 기준 비용은 현재 풀 가격에 따라 달라집니다. 모달에 표시되는 견적은 스왑 시점의 실시간 환율을 반영합니다.
:::
