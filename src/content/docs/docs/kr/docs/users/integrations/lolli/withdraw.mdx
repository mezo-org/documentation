## 최소 출금 금액
### Lolli에서 Mezo로:
최소 출금 금액: 0.0003 BTC (30,000 sats)

### Mezo에서 비트코인 레이어 1로:
최소 출금 금액: 0.01 BTC (1,000,000 sats)

:::note[중요]
Mezo 지갑에 1M sats가 쌓이기 전에는 비트코인 레이어 1로 출금할 수 없습니다. 그동안에도 자금은 Mezo 생태계 안에서 결제, 수익 얻기, 대출에 사용할 수 있습니다.
:::


## 1단계: 출금 시작하기

<Steps>
1. Lolli 계정에 로그인하세요

2. "Rewards"로 이동하세요

3. "Withdraw to Mezo"를 클릭하세요

4. "sats to BTC"를 선택하세요(USD 옵션은 곧 지원 예정)
</Steps>

## 2단계: 지갑 만들기 또는 연결하기

**아직 지갑이 없는 경우:**

<Steps>
1. "Create new wallet"을 클릭하면 지갑 제공업체로 이동합니다(초보자에게는 Taho를 권장합니다)

2. 설정 안내를 따르세요
   :::danger[매우 중요: 복구 문구를 보호하세요]
   복구 문구(단어 12~24개)를 받게 됩니다.
   - 이 단어들을 순서대로 적어 두세요
   - 적은 종이를 안전한 곳에 보관하세요(컴퓨터에 저장하지 마세요)
   - 절대 스크린샷을 찍거나 다른 사람과 공유하지 마세요
   :::

3. 지갑 설정을 완료하세요
</Steps>

**이미 지갑이 있는 경우:**

<Steps>
1. "Connect existing wallet"을 클릭하세요

2. 목록에서 지갑을 선택하세요

3. 연결을 승인하세요
</Steps>

## 3단계: Mezo 계정에 연결하기

<Steps>
1. "Connect your Mezo account"를 클릭하면 mezo.org로 이동합니다

2. "Sign In"을 클릭하고 지갑으로 연결하세요

3. 메시지가 표시되면 Lolli 연결을 승인하세요
</Steps>

## 4단계: 출금 확정하기

<Steps>
1. 출금 세부 정보(금액, 받는 주소, 수수료)를 검토하세요

2. "Withdraw to Mezo"를 클릭하세요

3. 지갑에서 트랜잭션을 확인하세요

4. 컨펌을 기다리세요(일반적으로 5~30분 소요)
</Steps>

## 5단계: 자금 도착 확인하기

mezo.org/overview로 이동해 지갑을 연결하면 BTC 잔액이 표시됩니다. 축하합니다! 이제 자기 수탁 상태가 되었으며 Mezo를 사용할 준비가 되었습니다.
