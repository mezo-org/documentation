[Safe](https://safe.global/)(구 Gnosis Safe)는 암호화폐 분야에서 가장 널리 사용되는 멀티시그 지갑입니다. Mezo에는 [safe.mezo.org](https://safe.mezo.org)에 네이티브 Safe 배포가 있으며, [Den](https://www.onchainden.com/)이 관리합니다.

멀티시그(다중 서명) 지갑은 트랜잭션이 실행되기 전에 여러 사람의 승인을 요구합니다. 한 사람이 단일 개인 키로 자금을 관리하는 대신, 그룹이 "서명자 5명 중 3명이 승인해야 함"과 같은 규칙을 정합니다.

<LinkButton href="https://safe.mezo.org" target="_blank">Mezo에서 Safe 열기</LinkButton>

## 시작하기

<Steps>

1. [safe.mezo.org](https://safe.mezo.org)로 이동하세요.

2. 지갑을 연결하세요.

3. **Create new Safe Account**를 클릭하세요.

4. 공동 서명자의 지갑 주소를 추가하세요.

5. 확인 임계값, 즉 트랜잭션을 실행하는 데 필요한 승인 수(예: 3명 중 2명)를 설정하세요.

6. 검토한 후 Safe를 배포하세요.

</Steps>

배포가 완료되면 Safe를 통해 Mezo에서 BTC와 기타 토큰을 보내고 받을 수 있으며, 모든 트랜잭션에는 설정한 승인 임계값이 적용됩니다.

## 기능

- **다중 서명 보안** — 트랜잭션이 실행되기 전에 여러 서명자의 승인을 요구합니다.
- **모듈 및 가드** — 지출 한도, 복구, 자동화된 트랜잭션 등을 위한 플러그형 모듈로 Safe를 사용자 지정할 수 있습니다.
- **생태계 액세스** — 내장 앱 브라우저를 사용해 Safe에서 바로 Mezo의 dApp과 상호 작용할 수 있습니다.
- **계정 모니터링** — 지갑을 연결하지 않고도 모든 Safe 계정을 모니터링할 수 있습니다.
