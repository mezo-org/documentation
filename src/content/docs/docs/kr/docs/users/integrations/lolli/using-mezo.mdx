# Mezo에서 수익을 얻고, 결제하고, 저축하는 방법

## 옵션 1: 그냥 HODL하기(가장 간단한 선택)

sats는 지갑에 그대로 있으며 사용자가 완전히 관리합니다.

## 옵션 2: 비트코인을 담보로 대출받기

BTC를 팔지 않고도 달러를 이용할 수 있습니다. 비트코인 익스포저를 유지하면서 유동성을 확보하세요.

:::note[주요 세부 사항]
- 연 1%(APR)부터 시작하는 고정 이자율
- 상환 기한 없음 — 원할 때 종료
- 신용 조회 없음, 모든 과정이 온체인에서 진행
- 최소 대출 금액 $2,000 MUSD
- 최소 110%의 담보 비율을 유지해야 합니다($1,000 MUSD를 대출받으려면 $1,100 상당의 BTC가 필요합니다)
:::

### 대출받는 방법:

<Steps>
1. mezo.org/borrow로 이동해 지갑을 연결하세요

2. 원하는 대출 금액을 MUSD로 입력하세요

3. 대출 조건을 검토하세요.
   * 이자율(현재 1% 고정)
   * 담보 비율
   * 청산 가격
   * 수수료: 0.5% 발행 수수료 + 200 MUSD 가스 예치금(대출 종료 시 반환)

4. "Borrow"를 클릭하고 트랜잭션을 확인하세요

5. 지갑에 MUSD가 표시되고, BTC는 담보로 잠깁니다
</Steps>

**MUSD로 할 수 있는 일:**

* Mezo Market에서 Bitrefill을 통해 결제
* 다른 자산으로 스왑
* DeFi 프로토콜에서 활용

### 대출 관리하기:

mezo.org/borrow에서 담보 비율을 모니터링하세요. BTC 가격이 하락하면 담보 비율도 낮아지므로, 청산을 피하려면 110%보다 높게 유지하세요. 대출을 종료하려면 mezo.org/borrow로 돌아가 "Repay"를 클릭하고, MUSD 전액과 누적 이자를 상환한 뒤 확정하세요. BTC 담보와 200 MUSD 가스 예치금이 반환됩니다.

## 옵션 3: sats로 결제하기

비트코인으로 Amazon, Airbnb, Uber, DoorDash, Visa 선불카드 등 수백 개 가맹점의 기프트 카드를 구매하세요. 최소 구매 금액은 $25 MUSD입니다.

### 1단계: BTC를 MUSD로 스왑하기

<Steps>
1. mezo.org/swap으로 이동하세요

2. BTC → MUSD를 선택하고 금액을 입력하세요

3. 가스 수수료용으로 약 $2 상당의 BTC를 남겨 두세요

4. 환율을 검토하고 "Swap"을 클릭하세요

5. 지갑에서 확인하세요
</Steps>

### 2단계: 기프트 카드 구매하기

<Steps>
1. mezo.org/market으로 이동하세요

2. "Bitrefill Gift Cards"를 클릭하세요

3. 금액을 선택하세요(최소 $25)

4. "Purchase"를 클릭하고 MUSD로 확정하세요

5. 바우처 코드를 받으세요
</Steps>

### 3단계: 기프트 카드 사용하기

<Steps>
1. 바우처 코드를 복사하세요

2. Bitrefill.com으로 이동해 원하는 기프트 카드를 찾으세요

3. 결제 단계에서 "Pay with voucher code"를 선택하세요

4. 코드를 붙여 넣고 구매를 완료하세요
</Steps>

## 옵션 4: MUSD 볼트로 수익 얻기

MUSD를 예치해 수익을 얻으세요. 자금에 계속 접근할 수 있으면서 스테이블코인으로 수익을 내는 가장 쉬운 방법입니다.

### 방법:

<Steps>
1. mezo.org/vaults로 이동해 이용 가능한 MUSD 볼트를 살펴보세요

2. 각 볼트의 다음 항목을 검토하세요.
   * 잠금 기간(있는 경우)
   * 보상률
   * 한도

3. 원하는 볼트를 클릭하세요

4. "Deposit"을 클릭하고 MUSD 금액을 입력하세요

5. 트랜잭션을 확인하세요

6. 이제 자동으로 수익을 얻게 됩니다
</Steps>

:::note[중요]
선택한 볼트에 잠금 기간이 있는지 확인하세요. 해당 기간 동안 그 자금이 필요하지 않은지 확인하세요.
:::
