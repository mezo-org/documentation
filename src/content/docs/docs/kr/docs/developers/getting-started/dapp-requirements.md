---
title: dApp 요구 사항
topic: developers
---


네트워크는 무허가형이어서 누구나 Mezo 메인넷에 배포할 수 있지만, Mezo Market에 소개되고 홍보 지원을 받으려면 Mezo의 dApp이 다음 요구 사항을 충족해야 합니다.
* **MUSD 통합:** dApp은 Mezo 생태계의 네이티브 담보 기반 스테이블코인인 [MUSD](https://mezo.org/feature/musd)를 통합해야 합니다. 통합에는 결제 수단으로 MUSD 지원, 주요 유동성 자산으로 MUSD 사용, 또는 dApp의 다른 핵심 기능 내 MUSD 활용 등이 포함될 수 있습니다.
* **감사 보고서:** dApp은 제3자 보안 감사를 완료해야 합니다. 감사 보고서는 [Supernormal Foundation](https://www.supernormal.foundation/page)에 제출해야 합니다.
* **메인넷 기능:** dApp은 Mezo 메인넷에 완전히 배포되어 정상적으로 작동해야 합니다.
