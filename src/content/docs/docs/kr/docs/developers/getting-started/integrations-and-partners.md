여러 조직이 Mezo와 협력하여 자사의 dApp과 서비스를 네트워크에 제공하고 있습니다.

## Goldsky

Goldsky는 web3 빌더를 위한 인덱서로, 서브그래프 호스팅과 실시간 데이터 복제 파이프라인을 제공합니다. Goldsky는 `mezo-testnet` 슬러그로 [Mezo 테스트넷에서 사용할 수 있습니다](https://docs.goldsky.com/chains/supported-networks).

- **[Goldsky 문서](https://docs.goldsky.com/)**

## Stork

Stork는 데이터 제공자와 온체인 및 오프체인 애플리케이션 간의 초저지연 연결을 지원하는 오라클 프로토콜입니다. Stork의 가장 일반적인 사용 사례는 DeFi를 위한 실시간 가격 피드 형태의 시장 데이터를 가져와 사용하는 것입니다. Stork는 [Mezo 테스트넷에서 사용할 수 있습니다](https://docs.stork.network/resources/contract-addresses/evm#mezo).

- **[Stork 문서](https://docs.stork.network/)**
- **[Mezo 테스트넷에 배포된 컨트랙트](https://docs.stork.network/resources/contract-addresses/evm#mezo)**

## Supra 

Supra는 빠르고 안전하며 탈중앙화되고 확장 가능한 데이터 솔루션으로 여러 블록체인 생태계의 dApp을 지원하도록 설계된 크로스체인 오라클 네트워크입니다. Supra의 [분산 오라클 합의(DORA)](https://docs.supra.com/oracles/data-feeds#distributed-oracle-agreement-dora)는 Mezo 테스트넷에서 사용할 수 있습니다. 올바른 pull 컨트랙트 및 스토리지 컨트랙트 주소는 Supra의 [사용 가능한 네트워크](https://docs.supra.com/oracles/data-feeds/pull-oracle/networks) 페이지를 참조하세요.

- **[Supra 문서](https://docs.supra.com/)**

## Pyth

[Pyth Network](https://pyth.network/)는 최대 규모의 퍼스트파티 오라클 네트워크 중 하나로, Mezo를 비롯한 여러 체인에 실시간 데이터를 제공합니다. Pyth는 사용자가 필요할 때 가격 업데이트를 온체인으로 가져올 수 있는 혁신적인 저지연 [풀(pull) 오라클 설계](https://docs.pyth.network/documentation/pythnet-price-feeds/on-demand)를 도입했습니다. 이를 통해 온체인 환경의 누구나 데이터 포인트에 효율적으로 접근할 수 있습니다. Pyth Network는 400ms마다 가격을 업데이트하므로 Pyth는 가장 빠른 온체인 오라클 중 하나입니다.

Pyth 컨트랙트:
- Mezo 메인넷(프록시): [0x2880aB155794e7179c9eE2e38200202908C17B43](https://explorer.mezo.org/address/0x2880aB155794e7179c9eE2e38200202908C17B43)
- Mezo 테스트넷(프록시): [0x2880aB155794e7179c9eE2e38200202908C17B43](https://explorer.test.mezo.org/address/0x2880aB155794e7179c9eE2e38200202908C17B43)

dApp에서 Pyth를 사용하는 방법은 [Pyth 문서](https://docs.pyth.network/home)를 참조하세요.

## Onchain Den

Den은 온체인 조직을 위한 자기 수탁형 다중 서명 지갑을 제공하며, Mezo에서 사용할 수 있습니다. Onchain Den은 Mezo와 협력하여 [safe.mezo.org](http://safe.mezo.org/)에서 SAFE 인프라도 제공했습니다.

- **[Den 문서](https://docs.onchainden.com/overview/den)**
