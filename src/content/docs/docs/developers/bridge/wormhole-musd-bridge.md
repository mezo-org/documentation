The MUSD bridge is powered by Wormhole's Native Token Transfer (NTT) protocol, which enables secure cross-chain transfers while maintaining token fungibility. For more information about MUSD bridge, see the [MUSD Bridge](/docs/users/borrow/musd-bridge) page.
