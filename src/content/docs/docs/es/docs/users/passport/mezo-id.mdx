  usuarios en la red Mezo.

---

Un Mezo ID es un identificador legible por humanos vinculado a una billetera en la red Mezo. En lugar de compartir una dirección de billetera `0x…` completa, los usuarios pueden compartir su Mezo ID para recibir activos.

## Cómo funciona

Cuando alguien introduce tu Mezo ID en el [formulario de envío](/docs/es/docs/users/passport/send-assets), Mezo lo resuelve automáticamente a la dirección de tu billetera. La dirección resuelta se muestra como paso de confirmación para que el remitente pueda verificar el destino antes de completar la transacción.

El mismo proceso de resolución se aplica cuando se introduce una dirección de Bitcoin: Mezo la asocia con la billetera correspondiente en la red.

## Usar tu Mezo ID

- **Recibir activos**: comparte tu Mezo ID con otros usuarios de Mezo en lugar de la dirección completa de tu billetera.
- **Enviar activos**: introduce el Mezo ID del destinatario en el formulario de envío de Passport. Verifica la dirección de billetera resuelta antes de confirmar.
