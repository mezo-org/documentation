## Preguntas frecuentes

**¿Puedo desbloquear mi BTC antes de tiempo?**

No. Los bloqueos son permanentes hasta su vencimiento. Elige la duración con cuidado.

**¿Qué pasa si no voto?**

No ganarás comisiones ni emisiones de los gauges. Sin embargo, seguirás recibiendo las comisiones de puente que se distribuyen a todos los titulares de veBTC.

**¿Puedo tener varias posiciones de veBTC?**

Sí. Cada bloqueo crea un NFT veBTC independiente. Más adelante puedes fusionarlos si lo deseas.

**¿Puedo usar mi BTC bloqueado como colateral?**

No. Tu NFT veBTC no se puede usar como colateral en el sistema de préstamos de MUSD de Mezo sin desbloquear el BTC subyacente.
