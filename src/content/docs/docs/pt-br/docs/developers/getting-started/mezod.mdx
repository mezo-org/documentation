O Mezod é a implementação de referência do cliente da cadeia do Mezo, uma blockchain com foco no Bitcoin, projetada para a propriedade dos usuários, transferências confiáveis pela ponte com tBTC, BTC como gás, modelo de staking duplo e compatibilidade com EVM.

## Visão geral

O Mezo é uma cadeia baseada no Cosmos SDK, compatível com EVM, que roda sobre o mecanismo de consenso Comet BFT. O código-base do cliente Mezod foi criado a partir de um fork da versão LGPL do Evmos e fortemente modificado para atender aos requisitos específicos do Mezo.

### Principais recursos

- **Design com foco no Bitcoin**: integração nativa com BTC e pagamentos de gás em BTC
- **Compatibilidade com EVM**: suporte completo à Ethereum Virtual Machine
- **Ponte com tBTC**: transferências cross-chain confiáveis de Bitcoin
- **Modelo de staking duplo**: mecanismos de recompensas e de validação
- **Propriedade dos usuários**: governança e controle descentralizados

## Configuração para desenvolvimento

### Pré-requisitos

- Go 1.21+ (consulte o [`go.mod`](https://github.com/mezo-org/mezod/blob/main/go.mod) para ver a versão exata)
- Git
- Make
- Docker (opcional, para desenvolvimento em contêineres)

### Instalação

<Steps>
1. Clone o repositório:
   ```bash
   git clone https://github.com/mezo-org/mezod.git
   cd mezod
   ```

2. Instale as dependências Go:
   ```bash
   go mod download
   ```

3. Compile o cliente:
   ```bash
   make build
   ```
</Steps>

### Ambiente de desenvolvimento

<Steps>
1. **Desenvolvimento local**:
   ```bash
   # Start local development node
   make dev

   # Run tests
   make test

   # Lint code
   make lint
   ```

2. **Desenvolvimento com Docker**:
   ```bash
   # Build Docker image
   docker build -t mezod .

   # Run containerized node
   docker run -p 26657:26657 -p 8545:8545 mezod
   ```
</Steps>

## Configuração da cadeia

### Parâmetros de rede

O Mezod oferece suporte a várias configurações de rede:

- **Mainnet**: rede Mezo de produção
- **Testnet**: rede pública de testes
- **Local**: rede de desenvolvimento

### Arquivos de configuração

Principais arquivos de configuração:
- `config.toml`: configuração do nó
- `app.toml`: ajustes específicos da aplicação
- `client.toml`: configuração do cliente

Exemplo de configuração:

```toml
# config.toml
[consensus]
timeout_commit = "1s"
timeout_propose = "3s"

[p2p]
laddr = "tcp://0.0.0.0:26656"
external_address = "YOUR_EXTERNAL_IP:26656"
persistent_peers = "peer1@ip1:26656,peer2@ip2:26656"

[api]
enable = true
address = "tcp://0.0.0.0:1317"
```

## Integração com EVM

### Compatibilidade com Ethereum

O Mezod oferece compatibilidade total com EVM, o que permite:

- Implantar contratos inteligentes Ethereum
- Usar ferramentas do Ethereum (Hardhat, Truffle etc.)
- Interagir com contratos usando bibliotecas Web3

### Conexão via Web3

```javascript
import { ethers } from 'ethers';

// Connect to Mezo network
const provider = new ethers.JsonRpcProvider('https://rpc.mezo.org');

// Get network info
const network = await provider.getNetwork();
console.log('Network:', network);

// Deploy contract
const factory = new ethers.ContractFactory(abi, bytecode, signer);
const contract = await factory.deploy();
await contract.waitForDeployment();
```

### Gás e taxas

- **BTC como gás**: pague as taxas de transação em Bitcoin
- **Preços dinâmicos**: os preços do gás se ajustam conforme as condições da rede
- **Modelo de gás da EVM**: compatível com os cálculos de gás do Ethereum

## Tipos de nó

### Nó completo

Um nó completo que armazena toda a blockchain:

```bash
# Start full node
mezod start
```

### Cliente leve

Um cliente leve para dispositivos móveis e ambientes com recursos limitados:

```bash
# Start light client
mezod start --mode light
```

### Nó de arquivo

Um nó que armazena todos os dados históricos:

```bash
# Start archive node
mezod start --mode archive
```

## Endpoints RPC

### RPC do Cosmos SDK

- **Porta**: 26657
- **Endpoints**: métodos RPC padrão do Cosmos SDK
- **WebSocket**: atualizações em tempo real

```bash
# Query node status
curl http://localhost:26657/status
```

### EVM RPC

- **Porta**: 8545
- **Endpoints**: JSON-RPC compatível com Ethereum
- **Métodos**: eth_getBalance, eth_sendTransaction etc.

```bash
# Query EVM balance
curl -X POST -H "Content-Type: application/json" \
  --data '{"jsonrpc":"2.0","method":"eth_getBalance","params":["0x...", "latest"],"id":1}' \
  http://localhost:8545
```

## Implantação

### Implantação em produção

**Requisitos de hardware**:
- Mínimo: 8GB de RAM, SSD de 100GB
- Recomendado: 16GB de RAM, SSD NVMe de 500GB

**Etapas**:

<Steps>
1. Configure o firewall e as portas de rede

2. Defina controles de acesso adequados

3. Implante a stack de monitoramento

4. Inicie o nó com a configuração de produção
</Steps>

### Implantação com Docker

```bash
# Production Docker deployment
docker run -d \
  --name mezod \
  -p 26657:26657 \
  -p 8545:8545 \
  -v /data:/root/.mezod \
  mezod:latest start
```

## Solução de problemas

### Problemas comuns

1. **Problemas de conexão**: verifique os endpoints RPC e a conectividade de rede
2. **Problemas de sincronização**: verifique a sincronização da blockchain
3. **Problemas de gás**: monitore os preços do gás e faça os ajustes necessários

### Comandos de depuração

```bash
# Check node status
mezod status

# View logs
mezod logs

# Reset node (caution: deletes data)
mezod unsafe-reset-all
```
