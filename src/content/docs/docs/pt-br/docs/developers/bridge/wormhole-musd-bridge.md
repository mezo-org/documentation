title: Wormhole MUSD Bridge
topic: developers

A ponte do MUSD é baseada no protocolo Native Token Transfer (NTT) da Wormhole, que permite transferências cross-chain seguras mantendo a fungibilidade dos tokens. Para mais informações sobre a ponte do MUSD, consulte a página [MUSD Bridge](/docs/pt-br/docs/users/borrow/musd-bridge).
