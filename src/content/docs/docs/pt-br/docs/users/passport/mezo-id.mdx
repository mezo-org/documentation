Um Mezo ID é um identificador legível por humanos vinculado a uma carteira na rede Mezo. Em vez de compartilhar um endereço de carteira `0x…` completo, os usuários podem compartilhar seu Mezo ID para receber ativos.

## Como funciona

Quando alguém insere seu Mezo ID no [formulário de envio](/docs/pt-br/docs/users/passport/send-assets), o Mezo o converte automaticamente no endereço da sua carteira. O endereço obtido é exibido como uma etapa de confirmação, para que o remetente possa conferir o destino antes de concluir a transação.

O mesmo fluxo de resolução se aplica quando um endereço Bitcoin é inserido: o Mezo o associa à carteira correspondente na rede.

## Como usar seu Mezo ID

- **Receber ativos**: compartilhe seu Mezo ID com outros usuários do Mezo em vez do endereço completo da sua carteira.
- **Enviar ativos**: insira o Mezo ID do destinatário no formulário **Send** do Passport. Confira o endereço de carteira obtido antes de confirmar.
