Os cofres do Mezo (Mezo Vaults) são estratégias geradoras de rendimento que alocam seus ativos em DeFi para obter retornos. Deposite em um cofre, receba um token de recibo que representa sua posição e deixe o estrategista otimizar o rendimento.

Acesse [mezo.org/earn/vaults](https://mezo.org/earn/vaults) para conhecer os cofres disponíveis.

---

## Como os cofres funcionam

1. **Selecione um cofre**: veja os cofres disponíveis no Mezo, cada um com estratégias e fontes de rendimento diferentes
2. **Deposite o ativo**: deposite o token exigido (por exemplo, MUSD, BTC) no cofre
3. **Receba o token de recibo**: obtenha um token que representa sua participação no cofre
4. **O estrategista otimiza**: o estrategista do cofre aloca os ativos para gerar rendimento de acordo com a estratégia descrita
5. **Ganhe**: acumule rendimento e, se quiser, faça staking para obter recompensas adicionais

---

## Entenda a tabela de cofres

| Coluna | O que significa |
|--------|---------------|
| **Vault** | Nome e descrição da estratégia do cofre |
| **TVL** | Valor total bloqueado (Total Value Locked): o total de ativos depositados no cofre |
| **APY** | Rendimento percentual anual (Annual Percentage Yield): seu retorno anual estimado |
| **Reward** | O(s) token(s) que você ganha com o cofre |
| **Strategist** | A equipe ou o protocolo que gerencia a estratégia do cofre |

## Tipos de cofres

### Cofres do Mezo

Cofres criados e gerenciados pelo Mezo, como o [MUSD Savings Vault](/docs/pt-br/docs/users/mezo-earn/vaults/musd-savings-vault) e o [USDC Lending Vault](/docs/pt-br/docs/users/mezo-earn/vaults/usdc-lending-vault).

### Cofres externos

O [Ditto MUSD Savings Vault](/docs/pt-br/docs/users/mezo-earn/vaults/ditto-musd-savings-vault) aceita MUSD no Mezo e emite dMUSD. A Ditto Network cuida dos swaps, das transferências pela ponte e de uma alocação inicial no Spark Savings no Ethereum. Os resgates devolvem MUSD no Mezo e são processados de forma assíncrona.

Cofres criados por protocolos parceiros (por exemplo, August, UWI, Upshift) que alocam ativos nas suas próprias estratégias. Eles também podem aparecer como banners em destaque na página de cofres, com links para a plataforma do parceiro para depósitos.

## Riscos

### Risco de estratégia
Cada cofre aloca ativos de uma forma diferente. Entenda a estratégia subjacente antes de depositar: algumas estratégias têm mais risco do que outras.

### Risco de contratos inteligentes
Os cofres interagem com vários contratos inteligentes. Embora os cofres do Mezo sejam auditados, todo contrato inteligente tem um risco inerente. Deposite apenas valores com os quais você se sinta confortável.

### Risco de cofres externos
Os cofres externos são gerenciados por protocolos de terceiros. O Mezo não controla essas estratégias. Analise a documentação e as auditorias do parceiro antes de depositar.
