## Perguntas frequentes

**Posso desbloquear meu BTC antes do prazo?**

Não. Os bloqueios são permanentes até a expiração. Escolha a duração com cuidado.

**O que acontece se eu não votar?**

Você não ganhará taxas nem emissões dos gauges. No entanto, continuará recebendo as taxas de ponte distribuídas a todos os detentores de veBTC.

**Posso ter várias posições de veBTC?**

Sim. Cada bloqueio cria um NFT veBTC separado. Você pode mesclá-los depois, se quiser.

**Posso usar meu BTC bloqueado como colateral?**

Não. Seu NFT veBTC não pode ser usado como colateral no sistema de empréstimos em MUSD do Mezo sem desbloquear o BTC subjacente.
