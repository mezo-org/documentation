सभी Mezo एसेट (BTC, MEZO और मेननेट कॉन्ट्रैक्ट टोकन) PoolsVoter कॉन्ट्रैक्ट में व्हाइटलिस्ट किए जा चुके हैं। अब कोई भी ऐसे पूल के लिए वोटिंग गेज बना सकता है जिनके दोनों एसेट व्हाइटलिस्ट में हों।

गेज पर इंसेंटिव के रूप में जोड़े जा सकने वाले व्हाइटलिस्ट किए गए टोकन एड्रेस की पूरी सूची के लिए, [कॉन्ट्रैक्ट रेफ़रेंस](/docs/in/docs/users/resources/contracts-reference#portal-कॉन्ट्रैक्ट-एड्रेस) देखें।

## पूल गेज बनाना

1. [Mezo Explorer पर PoolsVoter कॉन्ट्रैक्ट](https://explorer.mezo.org/address/0x48233cCC97B87Ba93bCA212cbEe48e3210211f03) पर जाएं और अपना वॉलेट कनेक्ट करें।

2. **Contract** टैब पर क्लिक करें, फिर **Write proxy** चुनें और `createPoolGauge` चुनें।

3. `_poolFactory` पैरामीटर के लिए, इनमें से कोई एक एड्रेस इस्तेमाल करें:
   - **बेसिक पूल:** `0x83FE469C636C4081b87bA5b3Ae9991c6Ed104248`
   - **CL पूल:** `0xBB24AF5c6fB88F1d191FA76055e30BF881BeEb79`

4. `_pool` में पूल का एड्रेस डालें।

5. ट्रांज़ैक्शन एक्ज़ीक्यूट करें। अगर पूल, पूल अवलोकन में सूचीबद्ध है, तो उसे वोट UI में भी दिखना शुरू हो जाना चाहिए।
