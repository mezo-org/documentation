Mezo ID, Mezo नेटवर्क पर किसी वॉलेट से जुड़ा, पढ़ने में आसान पहचानकर्ता है। एसेट पाने के लिए यूज़र पूरा `0x…` वॉलेट एड्रेस शेयर करने के बजाय अपना Mezo ID शेयर कर सकते हैं।

## यह कैसे काम करता है

जब कोई [Send फ़ॉर्म](/docs/in/docs/users/passport/send-assets) में आपका Mezo ID डालता है, तो Mezo उसे अपने-आप आपके वॉलेट एड्रेस में बदल देता है। बदला गया एड्रेस पुष्टि के एक स्टेप के रूप में दिखाया जाता है, ताकि भेजने वाला ट्रांज़ैक्शन पूरा करने से पहले जांच सके कि एसेट सही जगह जा रहे हैं।

बिटकॉइन एड्रेस डालने पर भी यही प्रक्रिया लागू होती है — Mezo उसे नेटवर्क पर उससे जुड़े वॉलेट से मैप कर देता है।

## अपने Mezo ID का इस्तेमाल

- **एसेट पाना** — अपने पूरे वॉलेट एड्रेस के बजाय दूसरे Mezo यूज़र के साथ अपना Mezo ID शेयर करें।
- **एसेट भेजना** — Passport के Send फ़ॉर्म में प्राप्तकर्ता का Mezo ID डालें। कन्फ़र्म करने से पहले बदले गए वॉलेट एड्रेस की जांच करें।
