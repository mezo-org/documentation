title: Wormhole MUSD Bridge
topic: developers
---

Cầu nối MUSD hoạt động dựa trên giao thức Native Token Transfer (NTT) của Wormhole, cho phép chuyển token xuyên chuỗi một cách an toàn mà vẫn duy trì tính khả hoán (fungibility) của token. Để biết thêm thông tin về cầu nối MUSD, hãy xem trang [MUSD Bridge](/docs/vn/docs/users/borrow/musd-bridge).
