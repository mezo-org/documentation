Отслеживайте активность сети Mezo, метрики MUSD и данные по токенам с помощью этих официальных и созданных сообществом ресурсов.

## Официальные дашборды

- [MUSD в Mezo (Dune)](https://dune.com/scoffie/musd-on-mezo) — предложение MUSD, активность выпуска и метрики использования
- [Обзор сети (Dune)](https://dune.com/scoffie/chainoverviewmezo) — статистика и активность на уровне сети
- [DexScreener](https://dexscreener.com/search?q=0xdD468A1DDc392dcdbEf6db6e34E89AA338F9F186) — торговые пары токенов и торговые данные

## Ресурсы сообщества

Дашборды, созданные и/или поддерживаемые сообществом Mezo. Если у вас есть дашборд, который вы хотели бы добавить на эту страницу, напишите в Discord или создайте PR с этим добавлением.
