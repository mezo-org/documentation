# Обзор

[Mezo Swap](https://mezo.org/overview?modal=swap) — встроенная децентрализованная биржа (DEX) экосистемы Mezo. Она позволяет беспрепятственно обменивать такие активы, как BTC, MUSD и USDC, без посредников, книг заявок и без выхода из экономики BitcoinFi. Работу функции обеспечивают [Mezo Pools](/docs/ru/docs/users/mezo-earn/pools): мгновенные децентрализованные свопы токенов выполняются за счёт резервов ликвидности на смарт-контрактах.

## Ключевые возможности

- **Без разрешений**: обменивайте поддерживаемые активы круглосуточно и без выходных, не завися от посредников и одобрений.
- **Низкое проскальзывание**: стабильные пулы (например, MUSD и USDC) используют специальную кривую, чтобы минимизировать влияние на цену при обмене схожих активов.
- **Мгновенная ликвидность**: торговля всегда доступна благодаря модели автоматического маркетмейкера (AMM) — книги заявок и маркетмейкеры не нужны.
- **Вознаграждения LP**: предоставляйте ликвидность в пулы и получайте долю комиссий за своп. LP-токены отражают ваш пропорциональный доход.
- **Ончейн-прозрачность**: каждый своп, каждая комиссия и каждая позиция ликвидности записываются в блокчейн и доступны для просмотра всем.

## Поддерживаемые активы

Сейчас Mezo Swap поддерживает обмен между следующими активами. По мере добавления новых токенов список будет обновляться:

- BTC
- MUSD
- USDC
- USDT

## Как это работает

### Механизм ценообразования

Mezo Swap использует модель автоматического маркетмейкера (AMM) с двумя разными ценовыми кривыми:

- **Волатильные пулы** используют формулу постоянного произведения `(x × y = k)` для таких активов, как BTC/USDC; она оптимизирована для определения цены между некоррелированными активами.
- **Стабильные пулы** используют специальную кривую stable swap `(x³y + y³x ≥ k)` для схожих активов, таких как MUSD/USDC; она предназначена для минимизации проскальзывания при обмене токенов с близкой стоимостью.

Цены определяются соотношением токенов в каждом пуле и автоматически обновляются после каждой сделки.  

### Проскальзывание

Проскальзывание возникает, когда фактическая цена свопа отличается от котировки по одной из причин:

- до вашей сделки были выполнены другие сделки;
- недостаточно ликвидности по выбранным активам.

В Mezo Swap можно задать максимально допустимое проскальзывание (по умолчанию 0,5% для стабильных пар и 1% для волатильных).

![Пример проскальзывания](/docs/images/mainnet/slippage-example.png)

Если рыночные условия изменятся сильнее допустимого значения, транзакция будет отменена, чтобы защитить вас от невыгодной сделки. Крупные сделки сталкиваются с большим проскальзыванием из-за их влияния на цену в пуле.

Чтобы посмотреть общую доступную ликвидность, перейдите в [Mezo Pools](https://mezo.org/explore/pools) — там собраны все пулы со статистикой, включая общую ликвидность (TVL).

## Комиссии

- **Комиссии протокола**: 0,02% для стабильных пулов, 0,3% для волатильных пулов (выплачиваются поставщикам ликвидности)
- **Комиссии сети**: стандартная комиссия за газ за выполнение транзакции свопа в блокчейне

При предварительном просмотре свопа в приложении Mezo отображаются соответствующие комиссии, проскальзывание, сетевые расходы и курс обмена.
