## FAQ

**Можно ли разблокировать BTC досрочно?**

Нет. Блокировки действуют без возможности отмены до окончания срока. Выбирайте срок внимательно.

**Что будет, если я не буду голосовать?**

Вы не будете получать комиссии и эмиссию от гейджей. Однако вы по-прежнему будете получать комиссии за переводы через мост, которые распределяются между всеми держателями veBTC.

**Можно ли иметь несколько позиций veBTC?**

Да. Каждая блокировка создаёт отдельный veBTC NFT. При желании позже их можно объединить.

**Можно ли использовать заблокированные BTC в качестве залога?**

Нет. Ваш veBTC NFT нельзя использовать как залог в системе займов MUSD в Mezo, не разблокировав базовые BTC.
