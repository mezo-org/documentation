[Safe](https://safe.global/) (ранее Gnosis Safe) — самый распространённый мультисиг-кошелёк в криптоиндустрии. У Mezo есть собственное развёртывание Safe на [safe.mezo.org](https://safe.mezo.org), которым управляет [Den](https://www.onchainden.com/).

Мультисиг-кошелёк (кошелёк с несколькими подписями) требует, чтобы транзакцию одобрили несколько человек, прежде чем она будет выполнена. Вместо того чтобы один человек контролировал средства с помощью единственного закрытого ключа, группа задаёт правила, например «3 из 5 подписантов должны одобрить».

<LinkButton href="https://safe.mezo.org" target="_blank">Открыть Safe в Mezo</LinkButton>

## Начало работы

<Steps>

1. Перейдите на [safe.mezo.org](https://safe.mezo.org).

2. Подключите кошелёк.

3. Нажмите **Create new Safe Account**.

4. Добавьте адреса кошельков соподписантов.

5. Задайте порог подтверждения — количество одобрений, необходимых для выполнения транзакции (например, 2 из 3).

6. Проверьте настройки и разверните свой Safe.

</Steps>

После развёртывания вы можете отправлять и получать BTC и другие токены в Mezo через свой Safe, причём каждая транзакция потребует заданного вами порога одобрений.

## Возможности

- **Защита несколькими подписями** — транзакции выполняются только после одобрения несколькими подписантами.
- **Модули и guard-контракты** — настраивайте свой Safe с помощью подключаемых модулей для лимитов расходов, восстановления, автоматизированных транзакций и многого другого.
- **Доступ к экосистеме** — взаимодействуйте с dApp в Mezo прямо из своего Safe через встроенный браузер приложений.
- **Наблюдение за аккаунтами** — отслеживайте любой аккаунт Safe без подключения кошелька.
