Вы можете отправлять активы другим пользователям Mezo прямо из Mezo Passport. Получателя можно указать по адресу кошелька, адресу Bitcoin или Mezo ID.

:::note
Отправка активов через Passport переводит токены внутри Mezo — она не отправляет активы в сети Bitcoin. Если вы хотите вывести активы из Mezo через мост, см. страницу [Мосты](/docs/ru/docs/users/mainnet/bridges).
:::

## Типы получателей

Форма отправки в Mezo Passport поддерживает три типа получателей:

- **Адрес кошелька** — введите стандартный адрес `0x…` в Mezo.
- **Адрес Bitcoin** — введите адрес Bitcoin. Mezo автоматически сопоставит его с соответствующим кошельком в сети Mezo.
- **Mezo ID** — введите Mezo ID. Найденный адрес кошелька отобразится под полем ввода, чтобы вы могли проверить получателя перед отправкой.

Если вы вводите адрес Bitcoin или Mezo ID, найденный адрес кошелька `0x…` появляется под полем ввода для подтверждения. Всегда проверяйте этот адрес, прежде чем продолжить.

## Отправка активов

<Steps>
1. Откройте [приложение Mezo](https://mezo.org/overview) и войдите в аккаунт.

2. Откройте раскрывающееся меню **Passport** в верхней части страницы.

3. Нажмите **Send**, чтобы открыть форму отправки.

4. Введите адрес кошелька, адрес Bitcoin или Mezo ID получателя.

5. Если вы ввели адрес Bitcoin или Mezo ID, проверьте найденный адрес кошелька, который отображается под полем ввода.

6. Выберите актив и введите сумму для отправки. Рядом с суммой в реальном времени отображается её эквивалент в долларах США.

7. Проверьте данные транзакции и нажмите **Send**, чтобы подтвердить.
</Steps>

После завершения транзакции откроется экран подтверждения с сообщением «Transaction sent» и ссылкой для просмотра транзакции в [Mezo Explorer](https://explorer.mezo.org). Нажмите **Done**, чтобы вернуться в приложение.
