Mezo ID — это удобочитаемый идентификатор, привязанный к кошельку в сети Mezo. Вместо того чтобы сообщать полный адрес кошелька `0x…`, пользователи могут поделиться своим Mezo ID, чтобы получать активы.

## Как это работает

Когда кто-то вводит ваш Mezo ID в [форме отправки](/docs/ru/docs/users/passport/send-assets), Mezo автоматически сопоставляет его с адресом вашего кошелька. Найденный адрес отображается для подтверждения, чтобы отправитель мог проверить получателя перед завершением транзакции.

Так же это работает, если ввести адрес Bitcoin: Mezo сопоставляет его со связанным кошельком в сети.

## Использование Mezo ID

- **Получение активов** — сообщайте другим пользователям Mezo свой Mezo ID вместо полного адреса кошелька.
- **Отправка активов** — введите Mezo ID получателя в форме отправки Passport. Перед подтверждением проверьте найденный адрес кошелька.
