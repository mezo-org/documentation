---
title: Как забрать залог после полного выкупа
description: >-
  Пошаговое руководство по возврату оставшегося залога после полного выкупа
  вашего займа в MUSD (Trove).
topic: users
---

import { Steps } from '@astrojs/starlight/components';

Когда другой пользователь выкупает MUSD за счёт вашего займа (Trove) и заём полностью погашается, ваш долг списывается, но оставшийся залог остаётся в смарт-контрактах MUSD, пока вы его не заберёте. Ваш залог в безопасности, и вернуть его можно в любое время.

Обычно на странице Borrow появляется уведомление «Loan redeemed», которое позволяет забрать залог прямо в интерфейсе. Для этого нажмите кнопку справа от уведомления, как показано на снимке экрана ниже.

![Уведомление «Loan redeemed» на странице Borrow](/docs/images/musd/loan-redeemed.webp)

Если вы не видите этого уведомления, залог можно забрать вручную, вызвав функцию `claimCollateral` контракта BorrowerOperations через Mezo Explorer. Выполните следующие шаги.

<Steps>

1. **Откройте контракт BorrowerOperations**

   Перейдите к [контракту BorrowerOperations в Mezo Explorer](https://explorer.mezo.org/address/0x44b1bac67dDA612a41a58AAf779143B181dEe031).

2. **Откройте вкладку «Contract»**

   На панели вкладок рядом с Transactions, Token transfers и Tokens нажмите **Contract**.

   Появятся четыре вложенные вкладки: **Code**, **Read proxy**, **Write contract** и **Write proxy**.

3. **Нажмите «Write proxy»**

   Откройте вкладку **Write proxy**. На ней доступны все функции записи базового контракта реализации BorrowerOperations.

   :::caution
   Обязательно выберите **Write proxy** (а не «Write contract»): вкладка прокси отражает фактическую логику BorrowerOperations.
   :::

4. **Подключите кошелёк**

   В верхней части области с функциями контракта вы увидите жёлто-оранжевый баннер с надписью «Disconnected» и кнопкой **Connect wallet**.

   Нажмите **Connect wallet** и подтвердите подключение в кошельке (например, MetaMask). Подключайтесь с того же адреса кошелька, которому принадлежал выкупленный Trove: забрать его залог может только этот адрес.

5. **Найдите функцию claimCollateral**

   Прокрутите список функций контракта вниз, пока не дойдёте до:

   **7. claimCollateral**

   Нажмите на неё, чтобы развернуть функцию. Входные параметры не нужны — функция просто возвращает весь залог, отложенный для вашего адреса после полного выкупа.

6. **Нажмите «Write»**

   Убедившись, что кошелёк подключён, нажмите кнопку **Write** под функцией `claimCollateral`.

   Кошелёк предложит подтвердить транзакцию. Проверьте комиссию за газ и подтвердите. После завершения транзакции ваш залог (BTC) будет отправлен прямо на ваш кошелёк.

</Steps>
