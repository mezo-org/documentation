Мост [MUSD](https://mezo.org/feature/musd) позволяет переводить токены между сетями Mezo, Ethereum и Base с помощью протокола Native Token Transfer (NTT) от Wormhole. Этот мост сохраняет взаимозаменяемость токена и обеспечивает безопасные кросс-чейн переводы.

## Как это работает

Мост MUSD использует протокол Native Token Transfer от Wormhole для кросс-чейн переводов:

- **Из Mezo в Ethereum/Base**: токены MUSD блокируются в Mezo, а эквивалентное количество токенов выпускается в целевой сети
- **Из Ethereum/Base в Mezo**: токены MUSD сжигаются в исходной сети, а эквивалентное количество токенов разблокируется в Mezo

Этот механизм гарантирует, что общее предложение во всех сетях остаётся неизменным, а пользователи могут свободно перемещать свои токены между сетями.

## Варианты перевода

Для перевода токенов MUSD через мост доступны два пользовательских интерфейса.

### Mezo dApp

[Mezo dApp](https://mezo.org) обеспечивает нативный перевод токенов MUSD через мост между сетями Mezo и Ethereum.

<Steps>
1. **Подключите кошелёк** к Mezo dApp

2. **Нажмите «Withdraw»**, чтобы перевести средства из Mezo, или **«Deposit»**, чтобы перевести их в Mezo

3. **Выберите токен MUSD** и укажите сумму

4. **Подтвердите транзакцию** в кошельке

5. **Дождитесь подтверждения** в обеих сетях
</Steps>

### Интерфейс Portal Bridge

Для перевода токенов MUSD в Base или Ethereum можно также использовать [интерфейс Portal](https://portalbridge.com/):

<Steps>
1. **Подключите кошелёк** к интерфейсу Portal

2. **Выберите исходную и целевую сети** (Mezo ↔ Ethereum ↔ Base)

3. **Выберите MUSD** в качестве токена для перевода

4. **Укажите сумму**, которую хотите перевести

5. **Проверьте данные транзакции**, включая комиссии и ожидаемое время

6. **Подтвердите транзакцию** в кошельке

7. **Дождитесь подтверждения** в обеих сетях
</Steps>

Оба интерфейса удобны в использовании и берут на себя всё сложное взаимодействие с базовыми контрактами NTT.
