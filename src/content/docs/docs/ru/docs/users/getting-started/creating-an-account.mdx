Вы можете создать аккаунт в приложении Mezo, чтобы управлять вознаграждениями, переводить активы через мосты, занимать и выпускать MUSD, а также пользоваться Mezo Market.

<YouTube id="b7SnEPSZjFE" title="Как создать аккаунт в Mezo" />

<Steps>
1. Перейдите в [приложение Mezo](https://mezo.org/overview).

2. Нажмите кнопку **Sign in**.

3. Нажмите **Sign up** и войдите с помощью браузерного кошелька. Если вы хотите использовать Ethereum-кошелёк, нажмите **Sign in with Ethereum instead** внизу окна входа.

4. Подключите кошелёк и подтвердите транзакцию, чтобы завершить регистрацию.
</Steps>

:::tip[Хотите внести средства?]
Регистрируйтесь с Ethereum-кошельком (EVM). Нативный мост для внесения BTC (Native BTC Bridge-in) закрыт, поэтому с Bitcoin-кошельков больше нельзя вносить средства в Mezo. См. [Внесение активов](/docs/ru/docs/users/getting-started/deposit-assets).
:::

После того как вы войдёте и подпишете транзакцию, кошелёк будет привязан к аккаунту. Аккаунтом управляет подключённый кошелёк.
