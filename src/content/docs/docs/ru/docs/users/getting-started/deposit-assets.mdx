С помощью EVM-кошелька в основную сеть Mezo можно внести tBTC и другие поддерживаемые токены ERC-20 из Ethereum.

:::caution[Нативный мост для внесения BTC закрыт]
С 13 октября 2026 г. нативный мост для внесения BTC (Native BTC Bridge-in) закрыт, и приложение Mezo больше не принимает депозиты с Bitcoin-кошельков (UniSat, OKX, Xverse). Вывод через мост напрямую в BTC по-прежнему доступен. Чтобы перевести BTC в Mezo, вносите tBTC из Ethereum. Такой депозит зачисляется за несколько минут, и минимальной суммы для него нет.

Если вы храните BTC в Bitcoin-кошельке, создайте аккаунт Mezo с EVM-кошельком и управляйте депозитами с него. Если ваш аккаунт Mezo уже использует Bitcoin-кошелёк, вы можете оставить активы в Mezo, переведя их на EVM-кошелёк: в приложении Mezo откройте **Transact > Send** и введите адрес своего EVM-кошелька вида `0x…` (см. [Отправка активов](/docs/ru/docs/users/passport/send-assets)). Кроме того, активы по-прежнему можно вывести через мост напрямую в BTC. См. [Вывод средств](/docs/ru/docs/users/mainnet/bridges#вывод-средств).
:::

## Перед началом работы

- Войдите с помощью EVM-кошелька, например MetaMask. С Bitcoin-кошельков вносить средства в Mezo нельзя.
- Проверьте, какие активы поддерживаются. Адреса токенов этих активов можно сверить на странице [Справочник контрактов](/docs/ru/docs/users/resources/contracts-reference#контракты-токенов).
- Все транзакции в основной сети Mezo оплачиваются в BTC. tBTC, внесённые из Ethereum, поступают в Mezo в виде BTC, поэтому рекомендуется пополнить аккаунт tBTC, чтобы у вас был газ для оплаты транзакций. Если у вас в Mezo есть только MUSD или MEZO, воспользуйтесь функцией [Get Gas](/docs/ru/docs/users/getting-started/get-gas).

## Внесение активов

<Steps>
1. Перейдите в [приложение Mezo](https://mezo.org/overview) и войдите с помощью EVM-кошелька.

2. Нажмите **Deposit**. Откроется форма депозита, в которой уже выбран tBTC.

3. Выберите актив, который хотите перевести через мост, и укажите сумму.

4. Нажмите **Review** и проверьте данные перевода.

5. Если всё в порядке, подтвердите транзакцию в кошельке. Если вы вносите этот токен впервые, кошелёк сначала попросит выдать на него разрешение (approve).
</Steps>

После завершения транзакции начинается перевод через мост. Пройдёт несколько минут, прежде чем вы получите активы в основной сети.
