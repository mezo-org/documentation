Mezo Enclaves — это путь для институциональных депозитов, позволяющий организациям с регуляторными требованиями к хранению активов размещать BTC в Mezo без использования стандартного моста.

## Как работают Enclaves

Организации, на которые распространяются правила хранения активов, могут не иметь возможности вносить BTC через стандартный мост Mezo. Enclaves решают эту проблему: BTC представлены в Mezo, а базовые биткоины остаются в схемах хранения, отвечающих регуляторным требованиям.

Главное:

- каждый Enclave отдельно вносится в список разрешённых мультисигом управления Mezo;
- депозиты через Enclaves подкреплены соответствующими юридическими соглашениями, которые определяют суммы перевода через мост и ограничения на использование;
- все депозиты через Enclaves по-прежнему обеспечены реальными UTXO биткоина в сети Bitcoin.

## Как проверить обеспечение BTC в Enclaves

Каждый депозит через Enclave обеспечен UTXO в блокчейне Bitcoin. Эти UTXO фиксируются в транзакции депозита через трёхсторонний мост и хранятся в ончейн-состоянии, поэтому базовое обеспечение в BTC прозрачно и проверяемо.

Разработчики могут запрашивать данные UTXO Enclaves с помощью функции `getTripartyUtxos`, чтобы проверить обеспечение в биткоинах любой позиции Enclave. Технические подробности — в [документации по мосту для разработчиков](/docs/ru/docs/developers/bridge/mezo-bridge).
