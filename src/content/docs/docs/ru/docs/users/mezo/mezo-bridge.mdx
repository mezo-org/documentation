MEZO Bridge позволяет переводить токены между Mezo и рядом сетей, включая Ethereum, Base, BSC и Solana, с помощью протокола Native Token Transfer (NTT) от Wormhole. Этот мост сохраняет взаимозаменяемость токена и обеспечивает безопасные кросс-чейн переводы.

## Как это работает

MEZO Bridge использует протокол Native Token Transfer от Wormhole для кросс-чейн переводов:

- **Из Mezo в другие сети**: токены MEZO блокируются в Mezo, а эквивалентное количество токенов выпускается в целевой сети (Ethereum, Base, BSC или Solana)
- **Из других сетей в Mezo**: токены MEZO сжигаются в исходной сети, а эквивалентное количество токенов разблокируется в Mezo

Этот механизм гарантирует, что общее предложение во всех сетях остаётся неизменным, а пользователи могут свободно перемещать свои токены между сетями.

## Варианты перевода

Для перевода токенов MEZO через мост доступны два пользовательских интерфейса.

### Mezo dApp

[Mezo dApp](https://mezo.org) обеспечивает нативный перевод токенов MEZO через мост только между сетями Mezo и Ethereum.

**Чтобы перевести токены из Mezo в Ethereum (вывод):**

<Steps>
1. **Подключите кошелёк** к Mezo dApp

2. **Нажмите «Withdraw»**, чтобы перевести токены из Mezo

3. **Выберите токен MEZO** и укажите сумму для вывода

4. **Подтвердите транзакцию** в кошельке

5. **Дождитесь подтверждения** в обеих сетях
</Steps>

**Чтобы перевести токены из Ethereum в Mezo (депозит):**

<Steps>
1. **Подключите кошелёк** к Mezo dApp

2. **Нажмите «Deposit»**, чтобы перевести токены в Mezo

3. **Выберите токен MEZO** и укажите сумму для внесения

4. **Подтвердите транзакцию** в кошельке

5. **Дождитесь подтверждения** в обеих сетях
</Steps>

### Интерфейс Wormhole Portal Bridge

Для перевода токенов MEZO в Base, BSC, Solana или Ethereum используйте [интерфейс Portal](https://portalbridge.com/):

<Steps>
1. **Подключите кошелёк** к интерфейсу Portal

2. **Выберите исходную и целевую сети** (Mezo ↔ Ethereum, Base, BSC или Solana)

3. **Выберите MEZO** в качестве токена для перевода

4. **Укажите сумму**, которую хотите перевести

5. **Проверьте данные транзакции**, включая комиссии и ожидаемое время

6. **Подтвердите транзакцию** в кошельке

7. **Дождитесь подтверждения** в обеих сетях
</Steps>

Оба интерфейса удобны в использовании и берут на себя всё сложное взаимодействие с базовыми контрактами NTT.
