Управление (governance) в сети Mezo позволяет держателям veBTC определять параметры протокола и потоки эмиссии. Управление привязано к BTC: veMEZO усиливает силу голоса veBTC, но не имеет собственного веса в управлении.

## Параметры протокола

Следующие параметры определяют распределение эмиссии MEZO:

| Параметр | Описание | Статус |
|---|---|---|
| Соотношение Chain Splitter | Доля эмиссии для валидаторов (20%) и для экосистемы (80%) | Фиксировано, закреплено решением управления |
| Соотношение Ecosystem Splitter | Доля эмиссии для гейджей стейкинга (90%) и для гейджей экосистемы (10%) | Фиксировано, закреплено решением управления |
| Максимальный множитель буста | Максимальный буст veMEZO для veBTC | Сейчас 5x |

Соотношения Splitter сейчас фиксированы, и изменить их голосованием нельзя. В будущем они могут стать настраиваемыми с помощью новых механизмов управления.

## Ограничения управления

- **Голосование, привязанное к BTC** — голосовать по предложениям управления могут только держатели veBTC. veMEZO усиливает силу голоса veBTC, но не даёт собственных прав в управлении. При этом veMEZO самостоятельно голосует за [гейджи буста veBTC](/docs/ru/docs/users/mezo-earn/lock/vemezo/matching-market) и [MEZO Gauges](/docs/ru/docs/users/mezo-earn/vote/mezo-gauges), которые направляют эмиссию, а не задают параметры протокола.

## Дальнейшее развитие

Структуры управления могут развиваться и включать:

- формальные механизмы предложений и голосования (например, Governor Bravo);
- дополнительные параметры, изменяемые управлением;
- выбор валидаторов через голосование за гейджи (gauges) в рамках proof-of-stake.

Подробности будут объявлены по мере доработки функций управления.
