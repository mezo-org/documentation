topic: developers

Мост MUSD работает на основе протокола Wormhole Native Token Transfer (NTT), который обеспечивает безопасные кросс-чейн переводы при сохранении взаимозаменяемости токенов. Подробнее о мосте MUSD — на странице [MUSD Bridge](/docs/ru/docs/users/borrow/musd-bridge).
