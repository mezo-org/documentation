Узлы Mezo — важнейшие компоненты сети, и их код полностью открыт. [Mezo Validator Kit](./validator-kit) устанавливает [клиент mezod](https://github.com/mezo-org/mezod) и всё остальное, что нужно для запуска узла в роли валидатора, RPC-узла или seed-узла. Этот набор упрощает несколько вариантов развёртывания: Docker, нативный демон и Helm для Kubernetes.

- См. репозиторий [mezod](https://github.com/mezo-org/mezod) на GitHub.
- Используйте [Validator Kit](./validator-kit), чтобы запустить собственный локальный seed-узел.

## Требования к оборудованию

Требования к оборудованию зависят от типа узла. Минимальные требования для каждого типа узла приведены в разделе [Требования к оборудованию](./validator-kit#требования-к-оборудованию).

## Валидаторы

Валидаторы Mezo отвечают за работу узлов, которые проверяют транзакции, предлагают и подтверждают новые блоки и участвуют в механизме консенсуса. Прежде чем их узлы смогут участвовать в сети в качестве валидаторов, валидаторы Mezo должны подать заявку на [Proof of Authority (PoA)](./validator-kit#настройка-валидатора).

Одобренные валидаторы могут узнать, как запустить узел-валидатор, следуя инструкциям [Validator Kit](./validator-kit).

## RPC-узлы

RPC-узлы можно использовать для создания локального эндпоинта для разработки или как часть платформы блокчейн-инфраструктуры как услуги (IaaS). Процесс настройки seed-узла такой же, как для узла-валидатора, но запрашивать Proof of Authority (PoA) не нужно.

Чтобы запустить RPC-узел, следуйте инструкциям руководства по настройке [Validator Kit](./validator-kit), но выполните дополнительные шаги настройки, описанные в разделе [Настройка RPC-узла](./validator-kit#настройка-rpc-узла).

## Seed-узлы

Seed-узлы помогают в обнаружении пиров в сети. Процесс настройки seed-узла такой же, как для узла-валидатора, но запрашивать Proof of Authority (PoA) не нужно.

Чтобы запустить seed-узел, следуйте инструкциям руководства по настройке [Validator Kit](./validator-kit), но пропустите подачу заявки на PoA и установите для параметра `p2p.seed_mode` в файле config.toml узла значение `true`. Подробнее см. в разделе [Network seed nodes](https://github.com/mezo-org/validator-kit?tab=readme-ov-file#network-seed-nodes).
