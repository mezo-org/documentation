Валидаторы могут каждую неделю получать эмиссию MEZO, но только если их гейдж (gauge) валидатора получает голоса в каждой эпохе. Если за гейдж не голосуют, валидатор не получит никакой эмиссии. В этом руководстве описано, как управлять получателями вознаграждений, голосовать за свой гейдж валидатора и получать вознаграждения.

## Обзор

У каждого валидатора есть связанный с ним гейдж в [контракте ValidatorsVoter](https://explorer.mezo.org/address/0xe99a9ad5Ed26BD30e4DB25397f378817e9b9515a). Вознаграждения получают через контракт ValidatorsVoter, указывая адрес гейджа валидатора.

У каждого гейджа есть единственный адрес получателя (beneficiary), которому разрешено получать вознаграждения. По умолчанию получателем является адрес оператора валидатора, зарегистрированный в [контракте Proof of Authority (PoA)](https://explorer.mezo.org/address/0x7B7C000000000000000000000000000000000011?tab=read_contract#ca1e7819).

:::note[График высвобождения вознаграждений]
Распределённые вознаграждения за эпоху становятся доступны для получения не сразу — они высвобождаются постепенно в течение эпохи. Например, если вознаграждения распределены на гейдж в начале эпохи N, то 100% вознаграждений за эпоху N будут доступны в конце этой эпохи.
:::

## Смена получателя вознаграждений

Валидаторы могут назначить другой адрес для получения вознаграждений в MEZO. Это удобно, чтобы разделить операционные функции и функции казначейства.

Чтобы сменить получателя вознаграждений:

1. **Подключите кошелёк с адресом оператора**
   Используйте кошелёк, связанный с адресом оператора вашего валидатора.

2. **Определите адрес своего гейджа**
   Вызовите `ValidatorsVoter.validatorToGauge()`, передав в качестве параметра адрес оператора.

3. **Смените получателя**
   Вызовите `Gauge.switchRewardsBeneficiary()`, передав в качестве параметра адрес нового получателя.
   - Контракт: ваш собственный контракт Gauge (полученный на шаге 2)
   - Метод: `switchRewardsBeneficiary(address newBeneficiary)`

4. **Получайте вознаграждения с нового адреса получателя**
   После смены получателя все последующие получения вознаграждений должны выполняться с кошелька нового получателя.

:::caution[Рекомендация]
Перед переходом на нового получателя рекомендуется получить все доступные вознаграждения на текущий адрес. Если сменить получателя, не получив вознаграждения, они останутся привязаны к старому адресу получателя, и их нужно будет получать отдельно.
:::

## Голосование за свой гейдж валидатора

Голосование необходимо для получения эмиссии MEZO: гейдж валидатора, не получивший ни одного голоса в эпохе, не получит никаких вознаграждений за эту эпоху. Валидаторы могут голосовать за собственный гейдж, чтобы направлять на него эмиссию MEZO. Голоса за гейджи валидаторов **не зависят** от других голосов за гейджи в Mezo Earn. Например, если вы уже проголосовали 100% своей силы голоса за гейдж пула, вы всё равно можете проголосовать 100% силы голоса за свой гейдж валидатора (или за гейдж другого валидатора).

veBTC — основной актив, используемый для голосования. С помощью veMEZO можно дать буст силе вашего голоса. После того как голос отдан, он автоматически переносится на последующие эпохи, если его явно не сбросить.

:::note[Poke вашей позиции]
Перед голосованием может потребоваться выполнить poke позиции, чтобы её данные были актуальны. Poke существующего голоса полезен и в том случае, если сила голоса вашего veBTC выросла (например, после пополнения): он обновляет вес вашего голоса с учётом новой силы. Подробнее см. в [документации по poke](/docs/ru/docs/users/mezo-earn/vote/claiming-fees-emissions/#poke).
:::

### Как голосовать

1. **Найдите свой гейдж валидатора**
   Вызовите функцию `validatorToGauge` в [контракте ValidatorsVoter (Read Proxy)](https://explorer.mezo.org/address/0xe99a9ad5Ed26BD30e4DB25397f378817e9b9515a?tab=read_proxy), передав в качестве параметра адрес своего валидатора.

2. **Отдайте голос**
   Вызовите функцию `vote` в [контракте ValidatorsVoter (Write Proxy)](https://explorer.mezo.org/address/0xe99a9ad5Ed26BD30e4DB25397f378817e9b9515a?tab=write_proxy). Параметр `tokenId` — это ID вашего veBTC NFT. Если вы голосуете только за собственный гейдж валидатора, можно указать вес `100` (что соответствует 100% вашей силы голоса).

### Стимулирование вашего гейджа

Валидаторы могут размещать стимулы на своём гейдже буста veBTC на платформах вроде [Matchbox](https://matchbox.markets/), чтобы привлечь голоса veMEZO, которые дают буст силе голоса их veBTC.
Затем эту усиленную силу голоса veBTC можно использовать, чтобы направить больше голосов на гейдж валидатора и тем самым увеличить эмиссию MEZO.

В Mezo Earn также есть отдельный механизм стимулов для гейджей валидаторов, но этот конкретный сценарий сейчас недоступен в Matchbox.

## Получение вознаграждений

Чтобы получить вознаграждения в MEZO, выполните следующие шаги:

1. **Подключите кошелёк с адресом оператора**
   Используйте кошелёк, связанный с адресом оператора вашего валидатора.

2. **Определите адрес своего гейджа**
   Вызовите `ValidatorsVoter.validatorToGauge()`, передав в качестве параметра адрес оператора.
   - Контракт: [ValidatorsVoter](https://explorer.mezo.org/address/0xe99a9ad5Ed26BD30e4DB25397f378817e9b9515a)
   - Метод: `validatorToGauge(address validator)`

3. **Получите вознаграждения**
   Вызовите `ValidatorsVoter.claimRewards()`, передав в качестве параметра адрес своего гейджа.
   - Контракт: [ValidatorsVoter](https://explorer.mezo.org/address/0xe99a9ad5Ed26BD30e4DB25397f378817e9b9515a)
   - Метод: `claimRewards(address gauge)`
