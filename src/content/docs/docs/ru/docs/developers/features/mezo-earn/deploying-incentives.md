Все активы Mezo (BTC, MEZO и токены контрактов основной сети) добавлены в белый список контракта PoolsVoter. Теперь любой может создавать гейджи (gauges) для голосования по пулам, оба актива которых входят в белый список.

Полный список адресов токенов из белого списка, которые можно добавлять в качестве стимулов на гейджи, см. в [справочнике по контрактам](/docs/ru/docs/users/resources/contracts-reference#адреса-контрактов-portal).

## Создание гейджа пула

1. Перейдите к [контракту PoolsVoter в Mezo Explorer](https://explorer.mezo.org/address/0x48233cCC97B87Ba93bCA212cbEe48e3210211f03) и подключите кошелёк.

2. Откройте вкладку **Contract**, затем выберите **Write proxy** и функцию `createPoolGauge`.

3. В качестве параметра `_poolFactory` укажите один из следующих адресов:
   - **Базовые пулы:** `0x83FE469C636C4081b87bA5b3Ae9991c6Ed104248`
   - **CL-пулы:** `0xBB24AF5c6fB88F1d191FA76055e30BF881BeEb79`

4. Введите адрес пула в поле `_pool`.

5. Выполните транзакцию. Если пул отображается в обзоре пулов, он должен появиться и в интерфейсе голосования.
