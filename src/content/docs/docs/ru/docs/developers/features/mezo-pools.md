Mezo Pools позволяют пользователям обменивать токены и предоставлять ликвидность с помощью оптимизированной механики пулов. Mezo поддерживает две архитектуры пулов: **базовые пулы** (AMM с постоянным произведением и стабильной кривой) и **пулы концентрированной ликвидности (CL)** с настраиваемыми ценовыми диапазонами.

## Базовые пулы

Базовые пулы используют AMM в стиле Aerodrome с ценообразованием по формуле постоянного произведения (волатильные пулы) или по стабильной кривой (стабильные пулы).

- **Фабрика пулов:** `0x83FE469C636C4081b87bA5b3Ae9991c6Ed104248`
- **Комиссии за своп:** 0,30% для волатильных пулов, 0,02% для стабильных пулов
- **Тип позиции:** взаимозаменяемые LP-токены (ERC-20)

### Поддерживаемые базовые пулы

| Пул | Тип | Адрес |
|------|------|---------|
| MUSD/BTC | Волатильный | `0x52e604c44417233b6CcEDDDc0d640A405Caacefb` |
| MUSD/mUSDC | Стабильный | `0xEd812AEc0Fecc8fD882Ac3eccC43f3aA80A6c356` |
| MUSD/mUSDT | Стабильный | `0x10906a9E9215939561597b4C8e4b98F93c02031A` |

### Процесс свопа в базовых пулах

**Контракт-маршрутизатор:** `0x16A76d3cd3C1e3CE843C6680d6B37E9116b5C706`

1. Пользователь выдаёт маршрутизатору разрешение (approve) на токен
2. Вызывается функция маршрутизатора `swapExactTokensForTokens(...)` с массивом пути
3. Выходной токен возвращается в кошелёк

## Пулы концентрированной ликвидности (CL)

Пулы CL позволяют поставщикам ликвидности вносить средства в пределах заданных ценовых диапазонов, концентрируя капитал там, где идёт торговля. Реализация CL в Mezo основана на [Slipstream от Velodrome](https://velodrome.finance/docs/slipstream).

- **Фабрика CL:** `0xBB24AF5c6fB88F1d191FA76055e30BF881BeEb79`
- **Тип позиции:** невзаимозаменяемые (NFT стандарта ERC-721 через NonfungiblePositionManager)
- **Модель цены:** `sqrtPriceX96` (число с фиксированной точкой Q64.96), как в Uniswap V3

### Поддерживаемые пулы CL

| Пул | Шаг тиков | Комиссия по умолчанию | Адрес |
|------|-------------|-------------|---------|
| BTC/MUSD-200 | 200 | 0,30% | См. обозреватель блоков |

### Шаг тиков и комиссии

Пулы CL создаются с определённым шагом тиков, который задаёт гранулярность ценовых диапазонов. Пулы с шагом тиков меньше 100 относятся к стабильным, со значением 100 и выше — к волатильным.

| Шаг тиков | Комиссия по умолчанию |
|---|---|
| 1 | 0,01% |
| 10 | 0,05% |
| 50 | 0,05% |
| 100 | 0,05% |
| 200 | 0,30% |
| 2 000 | 1,00% |

Собственные комиссии можно задать через подключаемый модуль `swapFeeModule` на фабрике. Модуль `unstakedFeeModule` управляет долей комиссий за своп, перенаправляемой от позиций вне стейкинга к позициям в стейкинге (по умолчанию 10%).

### Процесс свопа в пулах CL

**Маршрутизатор свопов CL:** `0x37cDd11919ec3860eaD9efB8673d7476E5326225`

1. Пользователь выдаёт маршрутизатору свопов CL разрешение (approve) на токен
2. Вызывается `exactInputSingle(...)` или `exactInput(...)` с ключом пула (token0, token1, tickSpacing) и параметрами свопа
3. Выходной токен возвращается в кошелёк

### Управление позициями CL

**NonfungiblePositionManager:** `0x509Bc221df2B83927c695FA0bb0f5B21053C874c`

Позиции управляются как NFT стандарта ERC-721. Основные операции:

- `mint(...)` — создать новую позицию с ценовым диапазоном (tickLower, tickUpper) и внести токены
- `increaseLiquidity(...)` — добавить ликвидность в существующую позицию
- `decreaseLiquidity(...)` — вывести ликвидность из позиции
- `collect(...)` — получить накопленные комиссии за своп

### Стейкинг и гейджи

Позиции CL можно разместить в стейкинг в гейджах (gauges), чтобы получать эмиссию MEZO. Ликвидность в стейкинге, находящаяся в диапазоне, приносит и комиссии за своп, и эмиссию. Механизм комиссий для позиций вне стейкинга перенаправляет часть комиссий от позиций вне стейкинга к позициям в стейкинге.

- **Фабрика гейджей CL:** `0xfc41E1AAe0e58E8bDC32e85d8C995A902FEdEb13`

### Ключевые возможности

- **Контроль проскальзывания:** доступен во фронтенде или через параметры `amountOutMinimum` / `sqrtPriceLimitX96`
- **Встроенный оракул TWAP:** каждый пул CL поддерживает оракул средневзвешенной по времени цены
- **Динамические комиссии:** подключаемые модули комиссий позволяют задать собственную логику комиссий для каждого пула
